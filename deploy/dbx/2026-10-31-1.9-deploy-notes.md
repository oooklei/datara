# DBX 在 1.9 服务器 (192.168.1.9 = bobi-host) 的部署说明

## 稽核结论
- 目标机：真实 Linux 主机 `bobi-host`（Ubuntu 22.04，x86_64），docker-ce 29.8.2，本机有 Docker Hub 镜像可拉取发布镜像。
- 镜像 `t8y2/dbx:latest` 元数据核对：Arch=amd64、OS=linux、入口 `dbx-web`、暴露 `4224/tcp`，与架构一致。
- 源码构建路线（`deploy/Dockerfile`）需联网拉取 npm/cargo，生产服务器若不便构建则采用「发布镜像」路线（本部署采用）。

## 目录
- 代码/源码：`/lei/apps/dbx`（从开发机拷贝的仓库，含 deploy/、crates/、apps/ 等）
- 部署配置：`/lei/apps/dbx/deploy-1.9/`（docker-compose.yml + .env + 本文件）
- 运行数据：`/lei/apps/dbx/data`（dbx.db、secret.key、插件、连接配置）
- 备份目录：`/lei/apps/dbx/backups`

## 启动
```bash
cd /lei/apps/dbx/deploy-1.9
docker compose up -d
```
访问：浏览器打开 `http://192.168.1.9:4224`，用 `.env` 中的 `DBX_PASSWORD` 登录。

## 验证
```bash
curl -s -o /dev/null -w '%{http_code}\n' http://192.168.1.9:4224/   # 期望 200
docker compose ps
docker compose logs -f
```
（未授权 API 返回 401，确认鉴权生效。）

## 数据与备份
- `/app/data` 映射到宿主机 `/lei/apps/dbx/data`，含加密密钥 `secret.key`，
  务必连同 `dbx.db` 一起备份（丢失密钥将无法解密连接凭据）。

## 经 1Panel 管理（可选）
1.9 服务器已装 1Panel（:3215）。本容器使用宿主机同一 docker socket，因此会出现在
1Panel「容器」列表中，可直接在 1Panel 内查看/重启。若希望作为 1Panel「应用」纳管
（含反向代理、备份策略），可用仓库内的 `deploy/1panel/` 元数据在 1Panel 应用商店本地导入。

## 升级
```bash
cd /lei/apps/dbx/deploy-1.9
docker compose pull && docker compose up -d
```

## 安全建议（生产）
- 改 `.env` 中的 `DBX_PASSWORD` 为强密码后 `docker compose up -d`。
- 如需更严格，设置 `DBX_SECRET_KEY_FILE` 指向密钥文件；公网暴露前务必加 HTTPS 反代与访问控制。
