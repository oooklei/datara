## 一、指令正文（即时生效）

**D-PARALLEL-2：1.9 远程测试并发上限由 `1` 提升为 `2`（双线并行），即时生效，至另行指令或熔断回收为止。**

### 1. 并发的唯一硬红线 —— 共享可变表互斥

- 根因认定：`playwright.config.ts` 的 `workers:1` + `fullyParallel:false` 只是**表观**串行；深层约束是 **`rebuild_llm_model` 为共享可变表**——「默认位/删除保护」类断言在并发下互相污染，故单槽串行本质是**对该表的全局节流阀**。
- 因此红线为：**任一时刻，只允许 1 条线触碰 `rebuild_llm_model`（及其断言面）**。不触该表的域不构成冲突。

### 2. 线别划分（两条线，互斥域）

| 线 | 域定义 | 允许的 RT（示例） | 互斥约束 |
|---|---|---|---|
| **线 A（llm_model 域）** | 触碰 `rebuild_llm_model` 及其默认位/删除保护断言 | `RT-IMPL-V4-01-A-GROUP`（现 ACTIVE 租约） | 独占该表；**不得**与任何其它触表 RT 同窗 |
| **线 B（非 llm_model 域）** | 不触 `rebuild_llm_model` | `RT-IMPL-V4-02a-SSHNODE-DOMAIN`、`RT-IMPL-V4-07-QC-BATCH-A`、`RT-IMPL-V4-16-MONITOR-COMPONENT`、`RT-IMPL-V4-08-OPENAPI-CONTRACT` | 与线 A 可并行；线 B 内仍按 `serial_order` 逐项 |

> 注：`RT-IMPL-V4-03-C-GROUP` 记名 trae（见 D-EXCEPTION-TRAE 异常件），其归属待重派落定后再定线。

### 3. 开展前必须「按契约登记」（强制前置）

**未完成契约登记的 RT 一律不得开跑**。登记要件：

1. **Flow**：落 `LEASE_*`/队列事件并更新投影（`remote-test-queue.json` / `snapshot.json`），线别写入 `lane` 字段（`A` / `B`）。
2. **Integration**：落**独立租约**，且 `isolated_tree` 与 `evidence_dir` **互不重叠**（线 A、线 B 各持一套，禁共用目录）。
3. **O10 制品身份**：各线首执行前须同步制品并绑定 commit（或路径清单+sha256）；未绑定结果不得计入 ENV_VERIFIED。
4. **并发安全声明**（执行席在登记件内明示）：本 RT **不触碰 `rebuild_llm_model`**；无全局计数断言；全部数据以唯一后缀自命名；断言仅作用于自建行。

### 4. 路径隔离判定（无相互覆盖冲突的判定标准）

两条线同窗成立，须同时满足：

- [ ] `isolated_tree` 不重叠；
- [ ] `evidence_dir` 不重叠；
- [ ] 至少一条线不触 `rebuild_llm_model`；
- [ ] 两线均无跨用例全局计数/共享 fixture 断言；
- [ ] 命名唯一（时间戳/随机后缀），无固定名复用。

### 5. 熔断与回退

- 若任一 RT 出现**并发互污**（因并行导致的失败/污染），Ops **立即回收为单槽串行**（并发上限降回 `1`），并在下一轮出复盘件；相关 RT 需重跑。
- 熔断为 Ops 单方动作，无需等待裁定席。

### 6. 看门狗（并行期不豁免）

- 两条线**各自独立心跳**，实施线阈值仍为 **30 分钟**静默即判治理异常（控制/审计线 60 分钟）。
- 线 A、线 B 的心跳互不抵扣；任一线静默超阈值，按 D-EXCEPTION 口径升级。
