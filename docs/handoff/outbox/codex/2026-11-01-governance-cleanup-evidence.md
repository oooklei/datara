# C7 治理清理契约证据卡

## 当前实现

- 标签、质量规则、标准、指标、质量报告、质量告警策略均有项目范围删除 API。
- 项目删除先执行治理图清理，再删除成员/项目；审计事件保留但释放项目引用。
- 质量规则删除保留运行历史并清空 `rule_id`，避免悬挂引用。
- 跨项目治理引用返回 409，禁止误删他项目数据。
