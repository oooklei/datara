# dbx 统一后退役的前端代码

本目录保留 2026-10-29 从 `datara-newweb/src` 移出的旧页面、独立服务与对应测试，供追溯。正式路由、菜单与全局 AI 挂载已移除，运行时代码不得再引用本目录。

归档范围：数据源管理、datara IDE 嵌入页、数仓建模、血缘分析、元数据目录、资产地图、LLM 配置、全局 AI 助手，以及这些页面独占的 API 契约。`sqlIdeApi.ts` 的最后一个运行时消费者已切到 dbx 网关，因此一并归档。`datasourceApi.ts` 仍被脚本资源编辑器、节点配置和项目看板消费，在替换这些依赖前保留在运行时代码中。

本目录是历史代码归档，不是需求或状态权威。
