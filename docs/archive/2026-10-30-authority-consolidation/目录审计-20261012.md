# Datara 目录审计记录（2026-10-12）

## 结论

根目录 `Datara/` 是旧证据目录，不是第二份源码。它只包含 `docs/increments/i12_proofs`，已迁移到根目录 `docs/increments/i12_proofs`，原嵌套目录已移除。

## 保留目录

| 目录 | 结论 | 原因 |
|---|---|---|
| `datara-backend` | 保留 | 当前后端源码、测试、迁移与工具 |
| `datara-web` | 保留 | 当前前端源码、构建和部署验证 |
| `docs` | 保留 | 当前设计、验证、用例和治理文档 |
| `infra` | 保留 | 部署、样例数据和基础设施配置 |
| `prototype` | 保留并标注只读历史原型 | 当前 mock 数据、页面注释和字典仍引用它 |
| `release` | 保留并标注发布证据 | I9 发布包与安装验证仍引用它 |
| `deploy` | 保留并标注历史取证脚本 | I8/I9 诊断与部署取证仍可追溯 |
| `.aoci`、`.gstack`、`.playwright-mcp` | 保留 | 工具治理和自动化运行资产 |

## 已迁移/清理

- `Datara/docs/increments/i12_proofs/**` → `docs/increments/i12_proofs/**`
- 删除空的嵌套 `Datara/` 目录
- 删除根级历史构建包 `datara-dist.tar.gz`
- 删除缓存目录 `.pytest_cache`、`.ruff_cache`
- 删除开发日志 `datara-backend/_uvicorn.log`、`datara-backend/tools/etl_run.log`、`datara-backend/tools/etl_e5_run.log`、`datara-web/_vite.log`、`datara-web/dev-server.log`

源码、产品文档、取证截图、发布包和原型资产未删除。后续新增临时包、日志和缓存不得进入项目根目录；如需保留，必须放入带日期的证据输出目录并登记。
