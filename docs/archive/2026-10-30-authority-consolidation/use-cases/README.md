# 用例文档目录与统一模板（I12 任务中心四分类工作流）

本目录存放 I12 四类工作流的用例文档（每类 5 例，共 20 例），文档与 1.9 实测一一对应。

## 目录结构

```
docs/use-cases/
├── README.md          # 本文件：统一模板与规范
├── sync/              # 同步类 S1~S5（库→库全量/增量、文件→库、反向反推源）
├── etl/               # ETL 类 E1~E5（清洗/聚合/分层/混合加工）
├── stream/            # 流类 F1~F5（kafka 窗口/join/看板/触发，走 /stream-jobs）
└── general/           # 普通类 G1~G5（shell/python/http/ssh/出仓，不含跨工作流调度壳）
```

## 命名规范

- 文件名：`I12-{sync|etl|stream|general}-{S|E|F|G}{1~5}-{短名}.md`，例：`I12-sync-S1-ods_order全量初载.md`
- 工作流名：`i12_{类}{编号}_{短名}`，例：`i12_S1_ods_order_load`（`i12_` 前缀隔离，便于 1.9 清点与回归）
- 目标表：业务语义优先沿用源表名；本增量新建的表带 `i12_` 前缀

## 验收口径（三证齐全）

每个用例判定通过的最低标准：

| 证据 | 手段 | 判定 |
|---|---|---|
| 库证 | 查库 SQL 对账（行数和/抽样值/溯源断言） | 结果与第 7 章期望一致 |
| API 证 | `curl` 实例终态与关键产出字段 | `status=success` 且字段齐备 |
| 页面证 | 1.9 页面实例状态 + 日志关键字 + 截图 | 无 ERROR / 无 Traceback |

## 通用环境约定

- 环境：1.9（192.168.1.9），后端 `:8000/api/v1`（经 `:8090` 代理），前端 `http://192.168.1.9:8090`（hash 路由，画布 `/#/dag?tab=edit&type=wf|stream&doc=<wf_id>`）
- 登录：`POST /api/v1/login`，体 `{"user_name","user_pwd"}` → `data.token`，后续请求 `Authorization: Bearer <token>`
- 建工作流：`POST /api/v1/workflow-definitions` `{"name"}` → `data.id`
- 日志：容器 `/datara/logs/{instance_id}/{task_id}.log`（master/worker 同路径约定，宿主机挂载 `/mnt/lei/datara/logs`）

## 类收口标准（每类 5 例完成后）

全部用例三证齐全 + 日志无异常 + 验证单（`I12-验证单.md` P2 对应段）逐条留痕，方视为该类收口。
