## 一、本轮唯一代码改动（P0 根因修复）

### 1.1 现象

门 1 全量 pytest 首轮实跑：**5 failed / 2593 passed / 8 skipped**（889s）。5 处失败全部落在 failover 族：

```
FAILED tests/rebuild/test_r8a_failover.py::test_running_recovery_marks_fault_then_submitted_and_redispatches  - assert 0 == 1
FAILED tests/rebuild/test_r8a_failover.py::test_duplicate_leader_same_attempt_dispatches_once                - assert 0 == 1
FAILED tests/rebuild/test_r8a_failover.py::test_recovery_failure_is_rescanned_and_all_ten_instances_recovered - assert 0 == 9
FAILED tests/rebuild/test_r8a_failover_fence.py::test_failover_smoke_redispatch_uses_leader_fence            - redis.exceptions.ConnectionError: Error 11001 connecting to redis:6379
FAILED tests/rebuild/test_r8a_fault_matrix.py::test_failover_redispatches_running_task_after_worker_becomes_unreachable - assert 0 == 1
```

### 1.2 根因（已闭环，非「模块级注册表污染」）

日志取证推翻了最初判断。`-k "r8a and failover" -v` 输出：

```
[ERROR] [master.failover] 实例恢复失败，已加入同 leader 重扫: run-1 ConnectionError('Error 11001 connecting to redis:6379. getaddrinfo failed.')
```

即 `_recover_one` → `_redispatch_smoke` → `queue.add_task` / `queue.add_task_fenced` 的**真实实现**被执行（`get_client().xadd/eval(...)`），monkeypatch 未生效。

**顺序依赖实验（决定性证据）**：

| 收集顺序 | 结果 |
|---|---|
| `test_component_catalog.py` → `test_r8a_failover_fence.py` | 1 passed |
| `test_r8a_failover_fence.py` → `test_component_catalog.py` | **1 failed（Redis ConnectionError）** |

**机制**：

1. `test_r8a_failover_fence.py` L6 在**模块导入期** `from common import queue`，绑定模块对象 **A**；
2. `test_component_catalog.py` L43-44 在**收集期**（模块导入期）执行 `sys.modules.pop('common')` / `pop('common.*')`，随后 `from api.main import create_app` 触发**重新 import**，生成新模块对象 **B**；
3. `master/failover.py::_redispatch_smoke` 用的是**函数内延迟 import** `from common import queue`，调用时从 `sys.modules` 取到 **B**（真实实现）；
4. `monkeypatch.setattr(queue, "add_task_fenced", ...)` 打在 **A** 上 → 静默失效 → 连真实 Redis。

> 该文件 docstring 声称「无论 pytest 收集顺序如何本用例都能拿到真实 app」，但它**只 pop 不恢复**，污染泄漏给同进程后续用例。
> 旁证：`tests/test_graph_rules.py` L473/L621 注释已记载同一污染导致「模型模块分裂」。

### 1.3 修复（最小改动，隔离污染源）

`datara-backend/tests/test_component_catalog.py` L36-55：pop 前保存 `common.*` 快照，`api.main` 导入后恢复原视图。

```python
_saved_common = {
    n: m for n, m in sys.modules.items() if n == "common" or n.startswith("common.")
}
for _n in list(_saved_common):
    sys.modules.pop(_n, None)
try:
    from api.main import create_app  # noqa: E402
finally:
    for _n in [n for n in sys.modules if n == "common" or n.startswith("common.")]:
        sys.modules.pop(_n, None)
    sys.modules.update(_saved_common)
```

diff 统计：`1 file changed, 17 insertions(+), 6 deletions(-)`，纯注释 + sys.modules 视图恢复，**未触碰任何生产代码**。
