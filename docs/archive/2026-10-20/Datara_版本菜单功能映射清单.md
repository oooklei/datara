# Datara 数据治理平台 · 菜单功能 × 三版本映射清单

> 依据最新代码左侧导航（`datara-web/src/App.vue` 菜单定义，与前端路由 `routes.ts` 一致）逐项罗列。
> 版本代号：**V1 可运行版** / **V2 普通版** / **V3 全部版**。
> 口径：V1 覆盖离线 + 实时 + 表级血缘的全流程闭环；V2 补齐数据标准、指标体系、工作流增强、脚本远程、一键部署，血缘升为全量（表级+字段级）；V3 纳入数据安全、运维监控、远程 Agent、开放服务与信创全栈。

---

## 一、总览

| 一级 | 二级（路径） | V1 可运行版 | V2 普通版 | V3 全部版 |
|---|---|---|---|---|
| **总览** | 工作台 `/` | 统计卡片 + 入口卡片 + 资产地图简化版 | 整合指标看板、待办入口 | 全量门户（安全/运维/共享入口聚合） |

## 二、数据集成

| 一级 | 二级（路径） | V1 可运行版 | V2 普通版 | V3 全部版 |
|---|---|---|---|---|
| **数据集成** | 数据源管理 `/ds/list` | 台账 + 连接测试 + 连接池 + schema 探测（收敛类型：万里/高斯/达梦/MySQL/Oracle + 数仓） | 按收敛类型补全驱动适配 | 全类型接入 + 凭证安全 |
| | 任务中心 `/dag`（顶部页签：工作流/同步/ETL/流/运行监控/告警） | — | — | — |
| | ├ 同步任务 | 选表向导/单表同步/自动建表/自动分区/字段映射/增量全量/数据量核对 | 核对报告、同步策略细化 | 全量同步模式 + 多引擎适配 |
| | ├ ETL 任务 | 拖拽算子编排 + 任务→图自动派生 | 算子扩充、字段映射面板增强 | UDF 与高级算子 |
| | ├ 流数据处理 | Kafka CDC / SQL 流计算 / 窗口 / 融合组件 | 实时链路上生产、深化调试 | CEP 复杂事件 + 业务实时场景 |
| | ├ 运行监控（含同步进度看板 `/batch/board`） | 实时进度/结果/耗时 | 失败重跑入口 | 全量监控 + 容量趋势 |
| | ├ 告警与 SLA `/dag/alarm` | 失败/恢复/完成基础告警 | SLA 监控/超时告警 | 多渠道告警收敛升级 |
