# I13 统一基础设施硬化执行计划

设计：`docs/increments/I13-统一基础设施硬化设计.md`

## Task 1：基线校准

1. 对齐最新 `origin/feat/ide` 与 192.168.1.9 实际实现；
2. 核对组件目录、基线工作台、血缘增量已实现能力；
3. 建立文档权威顺序和 IDE 冻结保护。

## Task 2：运行基础设施真实性

1. Kafka 纳入默认 Compose 并绑定持久卷、健康检查和 worker 启动依赖；
2. 监控上报增加时间戳和已知节点索引；
3. 集群监控移除随机/虚构数据；运行时页面消除重复轮询定时器。

## Task 3：告警闭环

1. 实现 system/webhook/email 通道适配器；
2. 失败状态真实落库；
3. 提供只读告警 API，真实模式消息中心接入持久化记录。

## Task 4：验证与记录

1. 本机只跑静态门；
2. 同步差异至 1.9 隔离目录并跑全量后端、前端和 Compose 门；
3. 启动隔离栈或对现役只读探针联调；
4. 回写验证单、遗留风险与发布建议。
