# 浏览器内SQL开发系统｜需求规格说明书（最终修订版）

## 一、项目概述

B/S架构浏览器端SQL在线开发工作台，对标 DBeaver Web、Datagrip Web Console，面向数据开发、DBA、分析师；核心能力：多数据库实例连接、SQL智能编写、多语句分号分隔逐条执行、结果预览、库表资源浏览、脚本管理、系统变量全局替换。

> 约束：数据库实例均为预连通校验通过实例，用户仅选择实例，不自行填写连接信息。

## 二、页面整体布局

```
┌─────────────────────────────────────────────────────────────┐
│ Top 顶部栏：实例选择｜实例属性｜全局参数配置｜执行历史按钮    │
├───────────────────┬─────────────────────────────────────────┤
│                   │ 右下：IDE编辑器（黑底Monaco）            │
│ 左下：资源Explorer│  ────────────────────────────────────── │
│ 懒加载树结构      │ 结果Tab面板（每次执行生成独立结果Tab）   │
└───────────────────┴─────────────────────────────────────────┘
```

## 三、模块详细需求

### 模块1：Top顶部栏

#### 1.1 数据库实例下拉

- 下拉列表仅展示**连通性预校验通过**的实例；展示：实例名称、数据库类型标签（MySQL8 / Doris / PG 等）
- 联动：选中实例，刷新左侧资源树、切换IDE上下文，展示实例基础属性（数据库类型、版本、默认Schema、连接超时、事务隔离级别）

#### 1.2 全局配置：全局参数面板

点击【全局参数】按钮弹出抽屉面板，维护**对接大平台的系统变量**，变量在SQL编辑器内支持自动补全，运行时做变量替换。

> 变量在SQL内语法：`${变量名}`

##### 全局参数清单

| 参数分类 | 参数名称 | 说明 |
|---|---|---|
| 环境配置参数 | env | 环境标识：dev/staging/prod |
| 数据库连接参数 | doris_host | Doris集群地址 |
| | dw_user | 数据仓库账号 |
| | dw_pwd | 数据仓库密码 |
| 告警配置 | alarm_mail | 告警接收邮箱 |
| 任务控制 | max_retry | 最大重试次数 |
| 内置时间参数 | ${biz_date} | 业务日期 |
| | ${today} | 今日日期 yyyy-MM-dd |
| | ${date(-1)} | 前一日 |
| | ${date(-7)} | 7天前 |
| | ${month_start} | 当月第一天 |
| | ${month_end} | 当月最后一天 |
| | ${last_month_start} | 上月第一天 |
| | ${last_month_end} | 上月最后一天 |
| | ${lyear} | 上一年 |
| | ${hour} | 当前小时 |
| | ${timestamp} | 时间戳 |
| | ${yyyyMMdd_HHmmss} | 年月日时分秒 |

##### 环境参数组

环境分组：`dev` / `staging` / `prod`，切换环境组自动加载该环境下整套全局参数。

> 编辑器能力：输入 `${` 自动弹出变量补全提示；执行SQL时后端完成变量渲染替换。

#### 1.3 执行历史按钮

点击【执行历史】弹出抽屉面板，列表按执行时间倒序排列，**每条历史记录支持行级操作**：

每条记录字段：执行时间、关联实例、SQL摘要、执行耗时、状态（成功/失败）、返回/影响行数。

单条历史行操作：
1. **查看**：抽屉内展开完整SQL语句 + 执行日志（异常堆栈、警告信息）
2. **编辑**：将本条历史SQL加载至IDE编辑器，作为当前脚本继续编辑
3. **再执行**：直接复用SQL与当前实例，重新发起执行
4. **删除**：删除本条历史记录（二次确认）

> 限制：执行历史只持久化SQL文本、执行元信息；不持久化大数据结果集。

#### 1.4 顶部全局辅助按钮

主题切换、快捷键帮助。

### 模块2：左下 数据库资源Explorer（资源树）

> 核心优化：**懒加载Explorer，非一次性全量加载所有节点**，避免大量库表场景前端卡死。节点只在用户点击展开时才向后端请求子节点数据。

#### 2.1 树节点层级（精简层级，懒加载）

```
实例（点击展开 → 请求Schema列表）
├─ Schema1（点击展开 → 请求Tables/Views列表）
│  ├─ Tables（点击展开 → 请求该Schema下所有表）
│  │  ├─ table_a（hover弹出浮窗菜单）
│  │  └─ table_b（hover弹出浮窗菜单）
│  └─ Views（点击展开 → 请求视图列表）
│     └─ view_1
```

> 节点说明：
> - 不再一次性预加载字段、索引；**点击表/视图节点才加载字段列表**
> - 字段节点单独懒加载；字段节点仅hover展示Tooltip，**无右键菜单**
> - 过滤搜索：顶部输入框，实时模糊筛选，仅对已加载节点过滤；搜索未加载节点时，触发后端检索接口返回匹配结果。

#### 2.2 字段节点 hover Tip

鼠标悬停在字段节点上，弹出只读Tooltip提示框：

内容：字段名、数据类型、长度、是否主键、是否非空、注释；Tooltip内置【复制】按钮，一键复制字段名。**字段节点无操作菜单**。

#### 2.3 Table / View 悬浮弹出菜单

> 所有预制SQL仅填充编辑器，不会自动执行。

| 菜单选项 | 功能说明 | 自动预制SQL |
|---|---|---|
| 查询数据（可限定行数） | 执行SELECT预览，弹窗可配置Limit值 | `SELECT * FROM ${schema}.${table} LIMIT ${N};` |
| 编辑数据 | 打开在线表格编辑器，支持新增临时行、修改单元格、删除行；**全部在事务内提交/回滚** | 先加载当前表数据；变更后生成 UPDATE/INSERT/DELETE 语句 |
| 结构 | 查看表DDL、字段类型、主键、索引、注释 | `SHOW CREATE TABLE` / 对应数据库方言DDL |
| 行数统计 | 统计表总行数 | `SELECT COUNT(*) FROM ${schema}.${table};` |
| 创建列 | 表单填写字段名、类型、长度、默认值，生成ALTER语句 | `ALTER TABLE ${table} ADD COLUMN ...` |
| 创建索引 | 表单配置索引名、字段、唯一/普通，生成索引DDL | `CREATE INDEX ...` |
| 导入数据 | 上传本地CSV，配置映射关系，生成批量插入语句 | LOAD DATA / 批量INSERT |
| 删除表（无条件删除） | 直接生成DROP TABLE语句，强提醒 | `DROP TABLE ${schema}.${table};` |
| 删除表（稽核校验） | 后台先校验：是否有外键、是否有数据、是否核心业务表；不通过禁止执行，通过生成DROP | 先执行校验SQL，再DDL |
| 截断表（无条件截断） | 生成TRUNCATE语句，高危二次确认 | `TRUNCATE TABLE ${schema}.${table};` |
| 截断表（稽核校验） | 后台校验表数据量、关联依赖；通过才可执行TRUNCATE | 先稽核再执行 |

> Schema点击：自动切换会话默认命名空间。

### 模块3：右下 IDE编辑器 + 执行结果Tab面板

#### 3.1 IDE编辑器（Monaco Editor，黑底）

##### 3.1.1 代码智能能力

1. 语法高亮：SQL关键字、内置函数、表名、字段、字符串、注释、错误标记分色；全局变量 `${xxx}` 单独高亮。
2. 自动补全：SQL关键字、当前Schema表/视图、字段、全局变量；输入 `${` 唤起变量补全列表。
3. 实时语法警示：前端轻量语法解析 + 后端预解析；红色波浪线语法错误；黄色风险警告（不带limit、大表全查等）。

##### 3.1.2 IDE顶部工具栏（文本编辑图标按钮）

工具栏按钮（带图标）：

| 图标按钮 | 功能说明 |
|---|---|
| ▶️ 运行 | **多语句支持：分号 `;` 分隔，逐条顺序执行**；支持选中片段执行；返回行数由用户 SQL 自带 LIMIT 控制（驻留层 SCREEN_ROW_CAP=2000 兜底截断，rowsTotal 全量计数，超出部分经结果分页重放获取） |
| ⏹️ 停止 | 终止正在执行的SQL任务 |
| 📄 新建 | 新建脚本（未命名SQL） |
| 📂 载入 | 从脚本库加载已保存命名脚本 |
| 💾 保存 | 保存当前脚本；未命名脚本弹出命名框 |
| 💾 另存为 | 当前脚本另存为新脚本 |
| 🪄 格式化 | SQL美化 |
| 📥 导出 | 导出当前执行结果：CSV/JSON/Excel |
| 🧹 清空编辑器 | 清空编辑器全部代码 |
| 🔘 注释/取消注释 | 选中代码批量注释 |
| ↩️ 撤销 | 编辑器撤销 |
| ↪️ 重做 | 编辑器重做 |
| 📋 复制 | 复制选中代码 |
| 📄 粘贴 | 粘贴到编辑器 |
| 🔄 切换事务模式 | 自动包裹 BEGIN / COMMIT / ROLLBACK |

> 重点规则：**多语句以分号 `;` 分隔，逐条执行**；执行过程中遇到报错立即终止后续语句执行，并标记出错语句位置。

##### 3.1.3 脚本Tab管理规则

1. 脚本分为命名脚本（后端持久化）、未命名脚本（会话临时存储，页面刷新丢失）。
2. 新建脚本默认：`未命名SQL #1`、`未命名SQL #2` 自动编号。
3. 最大驻留限制：最多同时驻留5个未命名脚本；新建超过上限弹窗提示用户先保存脚本。
4. 切换脚本Tab，IDE编辑器切换为对应脚本内容，互不覆盖。
5. 已编辑未执行的SQL自动预制命名「未命名SQL」；点击该Tab可调出对应SQL内容，多个未命名自动编号。

#### 3.2 执行结果Tab面板

1. 每次点击运行，生成独立结果Tab；Tab标题：`结果 #序号`。
2. 点击结果Tab，IDE联动切换到本次执行对应的原始SQL脚本。
3. Tab操作：关闭单个Tab、一键清空全部结果Tab。
4. **结果表格能力**
   - 基础能力：表头排序、拖拽调整列宽、单元格复制、分页加载数据集。
   - ✅ 表格内置字段过滤（前端本地过滤）
     - 每列表头增加筛选图标；点击弹出筛选面板。
     - 支持文本匹配：包含、等于、不等于、为空、非空；数字支持大于/小于。
     - 筛选逻辑：仅对**当前已经加载到前端内存的结果集**进行过滤，**不重新请求后端执行SQL**。
     - 支持多列组合筛选；可一键清空所有筛选条件，恢复原始结果。
     - 筛选状态在当前Tab内保留；切换Tab后状态隔离。
     - 边界：前端筛选只作用于当前已加载分页数据，不会跨页检索；全量筛选需要修改SQL重新执行。
   - DML/DDL执行结果：不渲染表格，展示受影响行数、执行状态、日志信息。
   - DQL查询：渲染带筛选能力的数据表格，导出弹窗提供选项：【导出全部原始结果】/【导出当前筛选子集】。
5. 支持单结果集导出（CSV / JSON / Excel）。

## 四、全场景SQL开发场景清单

1. **查询开发场景**：DQL编写、变量替换、语法提示、多语句逐条执行、limit控制、结果分页、前端字段筛选、结果导出、历史SQL复用。
2. **DML数据操作场景**：增删改语句编写；资源树可视化编辑表数据，事务提交/回滚；影响行数查看。
3. **DDL库表结构开发场景**：资源树快速生成建表、新增字段、索引、DROP/TRUNCATE；高危操作二次确认，可选稽核校验。
4. **SQL脚本管理场景**：新建/保存/另存为/载入脚本，未命名脚本上限保护、SQL格式化。
5. **变量开发场景**：全局参数+内置时间变量，编辑器补全，运行时变量渲染替换，多环境(dev/staging/prod)参数切换。
6. **执行管理场景**：SQL异步执行、任务停止；执行历史查看、编辑、重跑、删除；执行日志查看。
7. **资源浏览场景**：懒加载资源Explorer，搜索过滤；表/视图快速生成预制SQL；字段悬停查看字段属性。

## 五、非功能需求

1. **浏览器兼容**：Chrome、Edge；基于Monaco Editor。
2. **执行模型**：后端异步任务执行；分号分隔多条SQL逐条串行执行；单条失败中断后续执行；支持长查询取消。
3. **性能**：资源树懒加载，只有展开节点才请求子节点数据，避免一次性拉取大量库表造成前端卡顿；大查询结果后端分页返回；前端结果集本地筛选仅作用于已加载数据。
4. **安全**：高危DDL操作二次确认；实例权限隔离；脚本、执行历史权限隔离；变量渲染后端处理，防止注入风险。
5. **存储**：命名脚本持久化后端；未命名脚本仅前端会话存储；执行历史持久化；全局参数持久化。
6. **语法校验**：前端轻量语法提示提升交互体验，后端预解析做真实语法校验。

## 六、前端技术选型推荐

### 6.1 基础框架

**Vue3 + TypeScript + Vite**

> 理由：组件化强，适合复杂多面板布局（左右分割、多Tab抽屉）；TS保障复杂编辑器、树组件、状态管理的类型安全；Vite热更新提升开发效率。备选：React+TS；团队熟悉Vue优先Vue3。

### 6.2 代码编辑器

**Monaco Editor（VS Code内核）**

> 选型理由：
> 1. 原生支持SQL语法高亮、自定义语法提示、自定义Hover提示；可自定义 `${变量}` 语法高亮。
> 2. 原生支持撤销/重做、复制粘贴、批量注释、格式化扩展。
> 3. 支持自定义错误标记（波浪线），满足语法警告/错误提示。
> 4. 可配置黑底暗色主题，完美匹配需求IDE样式。

### 6.3 资源树组件

**vue3-tree-vue / element-plus-tree 二次封装（懒加载模式）**

> 选型要点：必须支持**懒加载回调函数**，节点展开才触发接口请求；支持节点hover事件、自定义节点Tooltip。不选用一次性全量渲染树组件，规避大库表场景性能问题。

### 6.4 UI组件库

**Element Plus**

- 抽屉（全局参数、执行历史）、弹窗、分割面板、Tab组件、表格、输入框。
- 配套图标库，补齐工具栏图标需求。

### 6.5 布局分割面板

**splitpanes**

> 用于页面左右分割（左侧资源树 / 右侧IDE区域），支持拖拽调整面板宽度，可收缩左侧资源树。

### 6.6 状态管理

**Pinia**

> 管理全局状态：当前选中实例、脚本列表（命名+未命名脚本）、执行结果Tab集合、全局参数环境变量。分离编辑器状态、资源树状态，保证切换脚本Tab时内容隔离。

### 6.7 网络请求

Axios + 后端SSE（推荐）

- SSE：用于SQL执行实时推送执行日志、进度、报错信息；长查询实时输出日志。
- Axios：常规接口：资源树懒加载、脚本CRUD、执行历史、全局参数管理。

### 6.8 结果表格组件

**vxe-table**

> 优势：原生支持表头筛选、多列组合筛选、单元格复制、拖拽列宽、表头排序、大数据虚拟滚动；完美适配前端字段筛选需求，性能优于原生Element Plus Table。

### 6.9 辅助依赖

1. **sql-formatter**：SQL代码格式化美化；支持多种数据库方言（Doris/MySQL/PG）。
2. **dayjs**：内置时间变量前端预览渲染。
3. **lodash**：防抖（资源树搜索框输入防抖）、工具函数。

### 6.10 打包部署

- 打包：Vite build
- 部署：Nginx静态资源托管；后端单独服务，接口跨域处理。

## 七、接口设计要点（简要）

1. 实例列表接口：获取已连通实例信息。
2. 资源树懒加载接口：传入实例、父节点类型、父节点名称，返回子节点列表。
3. 字段详情接口：获取表字段元信息（hover tooltip使用）。
4. SQL执行接口：接收SQL文本+实例ID，支持多语句分号逐条执行；SSE返回执行流、结果集、日志。
5. 任务终止接口：取消正在运行SQL任务。
6. 脚本CRUD接口：保存/加载/另存脚本。
7. 执行历史接口：列表、查看详情、删除历史。
8. 全局参数接口：环境组参数增删改查。
