## 1. 统一组件模型

### 1.1 状态集（对齐海豚 ExecutionStatus）

所有组件共用统一状态机，组件定义中只写特有状态：

`已提交 Submitted → 等待依赖 WaitingDependency → 运行中 Running → 成功 Success / 失败 Failure / 取消 Kill / 跳过 Skip / 容错接管 FaultTolerance / 重试中 Retry`

### 1.2 通用表单六区块（每个组件配置表单统一包含，用户意见⑩点名项）

| 区块 | 内容 | 说明 |
|---|---|---|
| ① 输入 | 上游依赖（画布连线自动带入，只读展示）；输入引用（上游输出参数/结果表，下拉选择） | 决定准入 |
| ② 输出 | 输出注册：输出参数（名/值来源）、结果表（名/所在数据源）供下游与跨节点引用 | 决定退出可交付物 |
| ③ 参数 | 参数表（键 / 值 / 来源：**全局变量 / 工作流变量 / 环境组 / 字面量 / 内置时间变量**）；引用优先级：节点参数 > 工作流变量 > 环境组 > 全局（既有裁定） | 变量联动核心 |
| ④ 条件 | 运行条件表达式（如 `${wf.period}=20261002 && ${wf.batch}=01`），周期/批次控制载体 | 不满足则置 Skip |
| ⑤ 限定约束 | 超时（时长+超时策略）、重试（次数/间隔）、失败策略（下游继续/终止工作流）、任务优先级、worker 分组（运行时节点） | 既有海豚机制参考 |
| ⑥ 排除 | 跳过条件表达式（命中即 Skip）、禁用开关 | |

> 六区块为框架级标准（F60 统一组件模型），各组件只定义**业务专属表单**，六区块自动附加。

### 1.3 页面化展示（用户意见⑩）

组件除配置外可声明 `NodeSchema.page`（页面化展示能力）：点击节点可展开为独立页面/浮窗（如 C20 流输出的实时数据展示页）。本期声明页面能力的组件见各条目标注。

### 1.4 运行实例编号与临时工作数据（用户 09-18 意见⑪⑫）

- **运行实例编号**：C1 开始节点生成 `instance_id`，作为本次运行的主键贯穿任务日志（与 F48 变量打印衔接）、临时工作数据、告警与血缘记录；回查追溯按 instance_id 一键定位。
- **临时工作数据**：工作流运行中的中间产物（上游产出供下游消费、供用户检验），三种形态：

| 形态 | 载体 | 生命周期 |
|---|---|---|
| 输出参数 / 结果集引用 | meta 库实例输出表 | 实例结束按保留策略 |
| 临时文件 | worker/运行时节点临时数据目录（既有裁定：SSH 节点必配），文件名打 `{instance_id}_` 标签 | 实例结束清理或按保留策略 |
| 临时表 | 数据源内 `{instance_id}_{node_id}_` 前缀建表 | 实例结束 drop 或转正式表 |

- **保留策略**（工作流级可配）：立即清理 / 保留 N 天 / 转正式表（升格为结果表）；F50 日志定期清理脚本同时按 `{instance_id}_` 前缀清扫过期临时表与临时文件。
- **灵活性价值**：文件读取组件（C22）+ 临时工作数据机制，让"产出 → 检验 → 再加工"的中间环节可视可查、可跨组件流转，无需都落正式表。

### 1.5 聚合组件与工作流模板（用户 09-18 意见⑬）

- **聚合组件**：声明 `NodeSchema.template` 的组件，拖入画布后先做一次性模式选择，再按内置模板**展开为普通节点链**（设计时物化）——展开后与手工编排的工作流完全无差别（实例/日志/血缘/调度同一套），运行引擎零改动（非运行时嵌套，区别于海豚 SubProcess，后者已裁定不设）
- **模板机制**：模板=预置节点/边/参数生成函数（前端框架能力，F63）；一次性展开、无持续耦合，模板升级不影响已生成工作流
- **本期范围**：通用框架归 I1（F63）；仅落地同步两模板（源表基准/目标表基准，组件 C23，I6）；流"输入→融合→输出"三件套模板等 I8 依 F35 引擎结论再定
- **价值**：取消同步独立向导页（消除人为区分，运行时本皆为工作流）；模板预置结构保留导航式引导体验；展开后可增删插节点，比固定向导灵活
- **I12 回写**：前端已注册 F63 示例管道模板 `demo_pipeline`（palette「模板」组，展开为 开始→SQL 占位→结束 三节点链，无 C 编号，引擎零改动）；流三件套模板未落地，各期维持普通节点编排

## 3. 组件定义（准入 / 退出 / 配置表单）

### A. 逻辑控制类

**C1 开始 Start**（海豚 start；dag.ts `start`）
- 准入：无（工作流入口，仅一个）
- 退出：触发下游；输出=工作流启动时间（输出参数 `startTime`）；运行实例编号 instance_id 由引擎注入运行时变量 **`${run.instanceId}`**（最高优先级不可覆盖，另注入 `${run.loopIter}` 循环迭代号），作为本次运行全局唯一主键贯穿全部任务日志/临时工作数据/告警/血缘的追溯主键（见 §1.4）
- 业务表单：无（仅六区块）

**C2 结束 End**（海豚 end；dag.ts `end`）
- 准入：所需上游全部到达终态
- 退出：工作流实例置终态；输出=工作流汇总输出参数表（引擎自动合并各上游终态节点的输出参数）
- 业务表单：无（仅六区块）
- **I12 回写**：原「汇总输出参数映射（可选）」表单未落地（代码 `end.form` 为空），汇总行为为引擎 `_exec_end` 自动合并上游 outputs

**C3 条件分支 Conditions**（海豚 conditions；前端多分支机制既有裁定；dag.ts `conditions`）
- 准入：上游完成；分支表达式变量可解析
- 退出：命中分支下游激活（Success），未命中分支置 Skip；输出=命中分支名
- 业务表单：分支列表（`branches`：分支名 name / 条件表达式 expr，每分支一个独立输出端点，默认「满足 `${var} > 0` / 不满足」两分支）；分支与连线 sourceHandle 自动同步（ports 动态端口既有实现）
- **I12 回写**：原「优先序」字段未落地（列表顺序即优先序）

**C4 切换 Switch**（海豚 switch；dag.ts `switch`）
- 准入：上游完成；判断变量可解析
- 退出：按变量值路由唯一分支，其余 Skip；输出=命中值
- 业务表单：分发分支列表（`branches`：分支名 + 匹配值表达式，`*` 为默认分支，默认 A/B/默认 三分支）
- **I12 回写**：原「判断变量下拉 + 分支值→目标节点映射表」未落地——判断变量经分支表达式引用（如 `${wf.level}=='A'`），无独立字段

**C5 并行 Fork**（海豚 fork；dag.ts `fork`）
- 准入：上游完成
- 退出：并行拉起全部下游；输出=并行度
- 业务表单：并行度（`parallel`，number，默认 2）
- **I12 回写**：原「并行说明（仅标注，拓扑即语义）」与代码不符，表单为并行度数值字段

**C6 汇聚 Join**（海豚 join；dag.ts `join`）
- 准入：全部上游完成（或失败策略允许）
- 退出：放行下游；输出=各上游状态汇总
- 业务表单：无（仅六区块）
- **I12 回写**：原「汇聚策略（全部成功/任一成功/全部到达终态）」表单未落地——语义固定全部上游完成（AND），OR 语义由 C7 承担

**C7 合并 Merge**（海豚 merge；dag.ts `merge`）
- 准入：任一上游到达终态（全部 Skip 时不触发）
- 退出：放行下游；输出=首个到达上游的输出
- 业务表单：无（六区块）

**C8 延时 Delay**（海豚 delay；dag.ts `delay`）
- 准入：上游完成
- 退出：等待时长后放行；输出=实际等待时间
- 业务表单：延时时长（`duration`，number）+ 单位（`unit`，秒/分/时，默认 60 秒）；desc 支持时间变量到点延时（如 `$[yyyyMMdd 0800]`）
- **I12 回写**：原「延时（分钟/表达式）」口径修正为时长+单位枚举（代码仅 duration/unit 两字段）

**C9 依赖 Dependent**（海豚 dependent，简化；意见②；dag.ts `dependent`）
- 准入：上游完成；所配依赖各自**最近一次实例**中节点终态=success 即通过（I7 简化语义，master 10s 轮询；周期/批次条件走变量，不在组件内做周期逻辑）
- 退出：依赖满足→Success；超时未满足→按失败策略；输出=被依赖实例状态与输出参数
- 业务表单：依赖项列表（`deps`，deps-list 编辑器：工作流→节点级联选择，存定义/节点 id（展示名冗余存储）+ 可选变量条件 `cond`（如 `wf.period=${wf.period}`））
- **I12 回写**：原「期望状态成功/失败/完成」字段未落地（通过判定固定 success）

**C10 循环 Loop**（自创，用户裁定保留；海豚无原生；dag.ts `loop`）
- 准入：上游完成；循环终止条件未满足
- 退出：每次迭代执行子路径后回环判断；终止→Success；输出=迭代次数/最后迭代输出（迭代号经 `${run.loopIter}` 引擎注入）
- 业务表单：迭代集合/参数（`collection`，如 `${loop_items}`）+ 批大小（`batchSize`，默认 100）
- **I12 回写**：原「循环类型（固定次数/变量条件）、终止条件表达式、迭代变量、迭代间隔」设计项未落地，当前表单两字段；引擎内置单实例 100 轮防死循环上限（DEFAULT_MAX_ITERATIONS）

### B. 数据计算类

**C11 SQL 组件**（海豚 SQL 任务；业务实现主体，意见③；dag.ts `sql`）
- 准入：数据源连通、上游完成、SQL 中变量可解析、（密级校验通过）
- 退出：状态 + 输出（非查询=影响行数；查询=结果集注册为输出/结果表；输出参数 var$）；**SQL 解析自动产生血缘与转换细节（F20~F23）**
- 业务表单：数据源（`datasource` 下拉，mysql/greatdb）、SQL 语句（`sql`，textarea 多语句/变量占位）、前置 SQL（`pre`）、后置 SQL（`post`）
- **I12 回写**：原「库/Schema、SQL 类型（查询/非查询/DDL）、变量预览、结果集去向、分段执行」设计项未落地，当前表单四字段；查询结果经页面化浮窗展示 worker result_preview 前 200 行；I12 §4.3 拟增库/表侧栏选择器（Task 11 实施）
- 页面化展示：SQL 结果预览（SqlPreviewPage，点击节点可打开本次运行结果集浮窗）

**C12 Shell 组件**（海豚 shell；dag.ts `shell`）
- 准入：worker 运行环境就绪、上游完成
- 退出：状态 + 退出码 + 标准输出捕获为日志；输出参数经 `parse_kv_outputs` 解析（约定 `echo KEY=VALUE` 行）
- 业务表单：脚本内容（`script`，textarea）
- **I12 回写**：原「运行目录（本地 worker/指定运行时节点）、环境变量注入」未落地（单脚本字段）

**C13 Python 组件**（海豚 python；dag.ts `python`）
- 准入：worker Python 环境就绪（版本可选 3.11）、上游完成
- 退出：同 Shell（退出码/输出参数解析）
- 业务表单：脚本内容（`script`，textarea）
- **I12 回写**：原「Python 版本、依赖清单（requirements 文本）、运行时节点选择」未落地（单脚本字段）

**C14 SSH 脚本组件**（海豚 SSH 任务；依托运行时节点 SSH 配置既有裁定；dag.ts `ssh`）
- 准入：目标运行时节点 SSH 可达（主机/端口/用户/密钥已配置且校验通过）、上游完成
- 退出：状态 + 远程退出码 + 远程输出日志；输出参数同 Shell 约定
- 业务表单：执行节点标签（`execNodeTag`，I7 支持按标签多主机路由 F53，留空则按运行时节点直连）、运行时节点（`runtimeNode`，仅标签留空时显示）、脚本内容（`script`，经 stdin 下发）
- **I12 回写**：原「执行用户覆盖（可选）」未落地；补记 I7 标签多主机路由能力

**C15 存储过程组件**（海豚 procedure；dag.ts `procedure`）
- 准入：数据源连通、过程存在、上游完成
- 退出：状态 + OUT 参数注册为输出参数 `out_{key}` + 影响行数（outputs.affected）
- 业务表单：数据源（mysql/greatdb）、目标库（`db`，留空=数据源默认库）、过程名（`procedure`）、过程参数（`args`，args-table：IN 传值 / OUT 回读）

**C16 HTTP 组件**（海豚 HTTP 任务；dag.ts `http`）
- 准入：URL 可达、上游完成
- 退出：状态 + HTTP 状态码 + 响应体（点路径提取注册输出参数）
- 业务表单：URL（`url`）、方法（`method`：GET/HEAD/POST/PUT/DELETE/PATCH）、请求头（`headers`，kv-table）、请求体类型（`bodyType`：JSON/FORM，GET/HEAD 隐藏）、请求体（`body`）、成功状态码（`successCodes`，默认 `2xx`，空=2xx）、响应提取（`extract`，kv-table 输出名→点路径）、超时（`timeout`，默认 30 秒）

**C22 文件读取组件**（海豚无，自创；用户 09-18 意见⑫裁定独立成组件；dag.ts `file`）
- 准入：文件路径或上游临时文件引用存在且可读、上游完成
- 退出：Success + 输出=数据集引用（rows_count 行数统计、字段类型推断 schema、tmp_name）；可注册为**临时工作数据**（§1.4）供下游以 `${tmp.<名>}` 引用（C17 同步读端 / C11 SQL 加工 / C20 展示）
- 业务表单：来源模式（`mode`：数据源中心文件源 / 手动参数）、文件源数据源（`datasource`，file 类型）、文件路径（`path`，/datara/files 相对）、文件类型（`format`：CSV/TXT/Excel）、编码（`encoding`：UTF-8/GBK/GB18030）、分隔符（`delimiter`）、首行是否表头（`header`）、Excel 工作表（`sheet`）、是否注册临时数据（`register`）与临时数据名（`name`）、临时数据形态（`kind`：临时表全量物化 / 结果集引用抽样 JSON / 文件登记仅路径+schema）、物化目标数据源（`targetDs`）、保留策略（`retention`：立即清理（实例终态清扫）/ 保留 N 天（`keepDays`）/ 转正式表——实例成功后 RENAME 去前缀）
- **页面化展示：数据预览检验网格**（TmpPreviewPage：t_tmp_data 抽样 / 字段类型推断 / 空值统计），供用户检验数据（意见⑫核心诉求）

### C. 数据同步类

**C17 数据同步组件**（读写器分离，海豚 DataX/SeaTunnel 式；I6 目标③载体；dag.ts `sync`）
- 准入：读端数据源连通（多 schema 时全部连通）、写端连通、目标表存在或建表权限、上游完成
- 退出：状态 + 输出参数 `read_rows / write_rows / bad_rows / rows_per_sec / batch_id(=instance_id) / schemas_included`（参与 schema 清单）；失败→按失败策略
- 业务表单（单面板分组平铺）：
  - 读端：读端类型（`readerType`：MySQL/GreatDB/CSV/TXT/Excel 文件）、读端数据源（`readerDs`）+ 读端表名（`readerTable`，连接型源）、**动态 schema 返选**（`readerSchemasText` 参与 schema 逗号分隔，留空=数据源默认库；`autoSchema` 新增 schema 自动纳入——运行时 SHOW DATABASES 差集探测同名表自动加入分支）、增量条件（`incrementalColumn` 增量列 + `incrementalExpr` 变量表达式，运行时替换后 `>` 比较）、文件源分型（路径/编码/分隔符/首行表头/Sheet）
  - 写端：写端类型（`writerType`：MySQL/GreatDB）、写端数据源（`writerDs`）、目标表名（`writerTable`）、自动建表（`autoCreate`）、写入前清空（`truncate`）
