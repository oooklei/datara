## 1. 统一组件模型

### 1.1 状态集（对齐海豚 ExecutionStatus）

所有组件共用统一状态机，组件定义中只写特有状态：

`已提交 Submitted → 等待依赖 WaitingDependency → 运行中 Running → 成功 Success / 失败 Failure / 取消 Kill / 跳过 Skip / 容错接管 FaultTolerance / 重试中 Retry`

### 1.2 通用表单六区块（每个组件配置表单统一包含，用户意见⑩点名项）

| 区块 | 内容 | 说明 |
|---|---|---|
| ① 输入 | 上游依赖（画布连线自动带入，只读展示）；输入引用（上游输出参数/结果表，下拉选择） | 决定准入 |
| ② 输出 | 输出注册：输出参数（名/值来源）、结果表（名/所在数据源）供下游与跨节点引用 | 决定退出可交付物 |
| ③ 参数 | 参数表（键 / 值 / 来源：**全局变量 / 工作流变量 / 环境组 / 字面量 / 内置时间变量**）；引用优先级：节点参数 > 工作流变量 > 环境组 > 全局（既有裁定） | 变量联动核心 |
| ④ 条件 | 运行条件表达式（如 `${wf.period}=20261002 && ${wf.batch}=01`），周期/批次控制载体 | 不满足则置 Skip |
| ⑤ 限定约束 | 超时（时长+超时策略）、重试（次数/间隔）、失败策略（下游继续/终止工作流）、任务优先级、worker 分组（运行时节点） | 既有海豚机制参考 |
| ⑥ 排除 | 跳过条件表达式（命中即 Skip）、禁用开关 | |

> 六区块为框架级标准（F60 统一组件模型），各组件只定义**业务专属表单**，六区块自动附加。

### 1.3 页面化展示（用户意见⑩）

组件除配置外可声明 `NodeSchema.page`（页面化展示能力）：点击节点可展开为独立页面/浮窗（如 C20 流输出的实时数据展示页）。本期声明页面能力的组件见各条目标注。

### 1.4 运行实例编号与临时工作数据（用户 09-18 意见⑪⑫）

- **运行实例编号**：C1 开始节点生成 `instance_id`，作为本次运行的主键贯穿任务日志（与 F48 变量打印衔接）、临时工作数据、告警与血缘记录；回查追溯按 instance_id 一键定位。
- **临时工作数据**：工作流运行中的中间产物（上游产出供下游消费、供用户检验），三种形态：

| 形态 | 载体 | 生命周期 |
|---|---|---|
| 输出参数 / 结果集引用 | meta 库实例输出表 | 实例结束按保留策略 |
| 临时文件 | worker/运行时节点临时数据目录（既有裁定：SSH 节点必配），文件名打 `{instance_id}_` 标签 | 实例结束清理或按保留策略 |
| 临时表 | 数据源内 `{instance_id}_{node_id}_` 前缀建表 | 实例结束 drop 或转正式表 |

- **保留策略**（工作流级可配）：立即清理 / 保留 N 天 / 转正式表（升格为结果表）；F50 日志定期清理脚本同时按 `{instance_id}_` 前缀清扫过期临时表与临时文件。
- **灵活性价值**：文件读取组件（C22）+ 临时工作数据机制，让"产出 → 检验 → 再加工"的中间环节可视可查、可跨组件流转，无需都落正式表。

### 1.5 聚合组件与工作流模板（用户 09-18 意见⑬）

- **聚合组件**：声明 `NodeSchema.template` 的组件，拖入画布后先做一次性模式选择，再按内置模板**展开为普通节点链**（设计时物化）——展开后与手工编排的工作流完全无差别（实例/日志/血缘/调度同一套），运行引擎零改动（非运行时嵌套，区别于海豚 SubProcess，后者已裁定不设）
- **模板机制**：模板=预置节点/边/参数生成函数（前端框架能力，F63）；一次性展开、无持续耦合，模板升级不影响已生成工作流
- **本期范围**：通用框架归 I1（F63）；仅落地同步两模板（源表基准/目标表基准，组件 C23，I6）；流"输入→融合→输出"三件套模板等 I8 依 F35 引擎结论再定
- **价值**：取消同步独立向导页（消除人为区分，运行时本皆为工作流）；模板预置结构保留导航式引导体验；展开后可增删插节点，比固定向导灵活

## 3. 组件定义（准入 / 退出 / 配置表单）

### A. 逻辑控制类

**C1 开始 Start**（海豚 start）
- 准入：无（工作流入口，仅一个）
- 退出：触发下游；输出=**运行实例编号 instance_id（本次运行全局唯一，贯穿全部任务日志/临时工作数据/告警/血缘的追溯主键，见 §1.4）**+ 工作流启动时间；下游以 `${run.instanceId}` 引用（写入日志、临时数据标记、同步批次号）
- 业务表单：无（仅六区块）

**C2 结束 End**（海豚 end）
- 准入：所需上游全部到达终态
- 退出：工作流实例置终态；输出=工作流汇总输出参数表
- 业务表单：汇总输出参数映射（可选）

**C3 条件分支 Conditions**（海豚 conditions；前端多分支机制既有裁定）
- 准入：上游完成；分支表达式变量可解析
- 退出：命中分支下游激活（Success），未命中分支置 Skip；输出=命中分支名
- 业务表单：分支列表（分支名/优先序/条件表达式），增删排序；分支与连线 sourceHandle 自动同步（既有实现）

**C4 切换 Switch**（海豚 switch）
- 准入：上游完成；判断变量可解析
- 退出：按变量值路由唯一分支，其余 Skip；输出=命中值
- 业务表单：判断变量（下拉已注册变量）、分支值→目标节点映射表、默认分支

**C5 并行 Fork**（海豚 fork）
- 准入：上游完成
- 退出：并行拉起全部下游；输出=并行度
- 业务表单：并行说明（仅标注，拓扑即语义）

**C6 汇聚 Join**（海豚 join）
- 准入：全部上游完成（或失败策略允许）
- 退出：放行下游；输出=各上游状态汇总
- 业务表单：汇聚策略（全部成功/任一成功/全部到达终态）

**C7 合并 Merge**（海豚 merge）
- 准入：任一上游到达终态
- 退出：放行下游；输出=首个到达上游的输出
- 业务表单：无（六区块）

**C8 延时 Delay**（海豚 delay）
- 准入：上游完成
- 退出：等待时长后放行；输出=实际等待时间
- 业务表单：延时（分钟/表达式，支持时间变量如 `$[yyyyMMdd 0800]` 到点延时）

**C9 依赖 Dependent**（海豚 dependent，简化；意见②）
- 准入：所依赖的"工作流+节点"周期/批次状态满足（状态匹配经工作流变量，不在组件内做周期逻辑）
- 退出：依赖满足→Success；超时未满足→按失败策略；输出=被依赖实例状态与输出参数
- 业务表单：依赖项列表（**选择哪个工作流→哪个节点**级联下拉 + 期望状态成功/失败/完成）；周期/批次匹配条件由工作流变量表达式承担（条件区块填写）

**C10 循环 Loop**（自创，用户裁定保留；海豚无原生）
- 准入：上游完成；循环终止条件未满足
- 退出：每次迭代执行子路径后回环判断；终止→Success；输出=迭代次数/最后迭代输出
- 业务表单：循环类型（固定次数/变量条件）、次数、终止条件表达式（如 `${wf.cnt}>=10`）、迭代变量（自增变量名，配合 C21）、迭代间隔

### B. 数据计算类

**C11 SQL 组件**（海豚 SQL 任务；业务实现主体，意见③）
- 准入：数据源连通、上游完成、SQL 中变量可解析、（密级校验通过）
- 退出：状态 + 输出（非查询=影响行数；查询=结果集注册为输出/结果表；输出参数 var$）；**SQL 解析自动产生血缘与转换细节（F20~F23）**
- 业务表单：数据源（类型+实例级联下拉）、库/Schema、SQL 类型（查询/非查询/DDL）、SQL 编辑器（多语句/高亮/变量占位高亮）、前置 SQL / 后置 SQL、变量预览（解析后实际值预览，防注入误替换）、结果集去向（注册输出表 / 输出参数 / 仅日志）、分段执行（分号拆分）、超时与重试（六区块）
- 页面化展示：点击节点可打开本次运行结果集浮窗（复用 IDE 结果网格）

**C12 Shell 组件**（海豚 shell）
- 准入：worker 运行环境就绪、上游完成
- 退出：状态 + 退出码 + 标准输出捕获为日志；可注册输出参数（约定 `echo KEY=VALUE` 行解析）
- 业务表单：脚本编辑器、运行目录（本地 worker / 指定运行时节点）、环境变量注入

**C13 Python 组件**（海豚 python）
- 准入：worker Python 环境就绪（版本可选 3.11）、上游完成
- 退出：同 Shell（退出码/输出参数解析）
- 业务表单：脚本编辑器、Python 版本、依赖清单（requirements 文本）、运行时节点选择

**C14 SSH 脚本组件**（海豚 SSH 任务；依托运行时节点 SSH 配置既有裁定）
- 准入：目标运行时节点 SSH 可达（主机/端口/用户/密钥已配置且校验通过）、上游完成
- 退出：状态 + 远程退出码 + 远程输出日志；输出参数同 Shell 约定
- 业务表单：运行时节点（下拉已注册节点）、脚本编辑器、执行用户覆盖（可选）、超时

**C15 存储过程组件**（海豚 procedure）
- 准入：数据源连通、过程存在、上游完成
- 退出：状态 + OUT 参数注册为输出参数 + 影响行数
- 业务表单：数据源、库、过程名（下拉/输入）、IN/OUT 参数表（键/类型/值/变量映射）

**C16 HTTP 组件**（海豚 HTTP 任务）
- 准入：URL 可达、上游完成
- 退出：状态 + HTTP 状态码 + 响应体（JSON 路径提取注册输出参数）
- 业务表单：URL/方法/请求头表/请求体（JSON/表单）、成功码列表、响应提取（JSONPath 表→输出参数）、超时

**C22 文件读取组件**（海豚无，自创；用户 09-18 意见⑫裁定独立成组件）
- 准入：文件路径或上游临时文件引用存在且可读、上游完成
- 退出：Success + 输出=数据集引用（行数统计、字段类型推断 schema）；可注册为**临时工作数据**（§1.4）供下游引用（C17 同步读端 / C11 SQL 加工 / C20 展示）
- 业务表单：来源（手动路径 / 上游临时数据引用下拉）、文件类型（CSV / TXT 自定义分隔符 / Excel）、编码、分隔符（自定义，如"双杠加点"类）、首行是否表头、Excel 工作表（sheet）选择、是否注册为临时数据（含命名）与保留策略
- **页面化展示：数据预览与检验网格**（分页预览 / 字段类型推断 / 空值统计），供用户检验数据（意见⑫核心诉求）

### C. 数据同步类

**C17 数据同步组件**（读写器分离，海豚 DataX/SeaTunnel 式；I6 目标③载体）
- 准入：读端数据源连通（多源时全部连通）、写端连通、目标表存在或建表权限、上游完成
- 退出：状态 + 读写行数/速率统计（输出参数）+ 同步批次号；失败→按失败策略
- 业务表单（分步 Tab）：
  - 读端：类型（MySQL/GreatDB/CSV/TXT 自定义分隔符/Excel）→ **动态 schema 返选**（目标表基准时勾选多 schema 同名表，union all + schema 标识列自动附加）、增量条件（时间分区字段 + 变量表达式）、抽取 SQL/表选择
  - 写端：类型（MySQL/GreatDB）、目标表/自动建表、写入模式（追加/覆盖/分区隔离）
  - 合并策略：追加 union / schema 标识列 / 分区隔离（三选一，既有裁定）
  - 字段映射：源字段→目标字段表（自动推断可改）
  - 运行参数：批大小/并发/错误阈值（脏数据容忍条数）
- 页面化展示：运行时点击节点查看实时读写速率/进度浮窗

**C23 同步编排（模板聚合组件）**（海豚无，自创；用户 09-18 意见⑬裁定，取消独立同步向导页，机制见 §1.5）
- 形态：拖入画布 → 先弹**模式选择** → 按内置模板**展开为普通节点链**（设计时物化，引擎零改动）
- 内置模板（本期两套，落地 I6）：
  - **源表基准**：读端（源库/表选择 + schema 过滤）→ 写端（目标库写入模式）→（可选）对账校验
  - **目标表基准**：schema 探测返选节点（多 schema 同名表 union all + 标识列附加，F29~F31）→ 读端 → 写端（合并策略表单，F32）→（可选）对账校验
- 准入：按展开后各节点自身准入（C17 读写端规则 / 返选前置条件）
- 退出：链路终态 + 同步批次号；实例按普通 DAG 监控
- 业务表单：模式选择（展开时一次性）；展开后每节点=标准组件节点，六区块+业务表单照常配置，**可增删插节点**（如读写间插 C11 SQL 校验、C22 文件对照检验、C3 分支告警路由）
- 监控归属：F34 同步任务独立列表保留，模板生成的工作流打同步标签过滤（监控视角裁定不变）

### D. 流处理类（依 F35 引擎结论实现；组件形态先行定义）

**C18 流输入组件**（海豚无，自创；源类型参数化）
- 准入：源可达（Kafka broker / binlog 主从位点 / HTTP 端点 / 文件路径）、上游（若在 DAG 中）完成
- 退出：常驻运行（Running 持续）；输出=数据流引用（供 C19）；异常→自动重连（次数上限后 Failure）
- 业务表单：源类型（Kafka / CDC(MySQL/GreatDB binlog) / HTTP 拉取 / 文件尾随）分型表单——Kafka：broker/topic/消费组/起始位点/反序列化(JSON/CSV/Avro)；CDC：数据源/库表/binlog 位点策略（最早/最新/指定）；HTTP：URL/轮询间隔/鉴权；文件：路径/编码/分隔符/滚动规则；断点策略（位点/偏移持久化）
- 页面化展示：实时消费速率/位点/滞后量浮窗

**C19 流融合组件**（意见⑩指定组件化；F39 的组件形态）
- 准入：≥1 个上游流输入组件的数据流引用
- 退出：常驻运行；输出=融合后数据流引用
- 业务表单：融合类型（union / join / 窗口聚合 / 过滤 / 字段映射）分型表单——join：两路流/关联键/窗口类型（滚动/滑动/会话）与大小/允许乱序；union：字段对齐映射；窗口聚合：分组键/聚合函数表（sum/count/avg/min/max/自定义）/窗口/水位线延迟；过滤：条件表达式；映射：字段转换表达式表（表达式进入流转换细节，与 C11 血缘转换细节同构）
- 页面化展示：吞吐/窗口触发情况浮窗

**C20 流输出组件**（海豚无，自创；**页面化展示代表组件**）
- 准入：上游数据流引用存在
- 退出：常驻运行（持续对外服务）；输出=对外 API 端点信息（输出参数）；停止→按失败策略告警
- 业务表单：输出通道（API 订阅[SSE/WebSocket/轮询] / Kafka topic / 目标库表 / 文件滚动）、API 鉴权（沿用平台会话或 token）、数据结构（字段 schema 声明）、保留窗口（内存/外部存储）
- **页面化展示：组件可展开为实时数据展示页（表格/指标卡实时刷新），供大屏联调与演示（用户意见⑩示例场景）**

### E. 变量类

**C21 变量组件**（意见②）
- 准入：上游完成（或作为起始节点）
- 退出：Success；输出=所注入变量集（供下游与条件区块引用）
- 业务表单：变量表（名 / 值 / 类型[字面量/表达式/内置时间变量] / 是否覆盖同名变量 / 作用域=工作流级）；周期/批次控制范式见方案 §5.1

## 4. 组件实现与注册机制（框架，F60/F61）

- `NodeSchema`：id / 分类 / 名称 / 图标 / 端口规则（ports(data) 动态端口，既有机制）/ `form`（业务表单字段描述）/ `page`（页面化展示声明）/ `template`（聚合模板声明，§1.5）/ 血缘声明（是否参与解析）
- Inspector 动态表单：六区块（框架自动渲染）+ 业务表单（按 schema 渲染）；变量引用控件统一（下拉已注册变量 + 表达式输入 + 预览）
- 组件注册表按阶段增长：I3 注册 A 组+C11~C14 → I4 注册 C15~C16、**C22** → I6 注册 C17、**C23**（同步模板两套，模板展开框架归 I1/F63）→ I8 注册 C18~C20 → I7 注册 C21
- 海豚对齐检查：每个组件设计文档附"海豚对应 TaskType/机制"，海豚有的对齐语义与参数命名，没有的标注自创

## 5. 论证记录（关键取舍）

| 取舍点 | 结论 | 理由 |
|---|---|---|
| 组件粒度：单组件+类型参数 vs 每类型独立组件 | **单组件+分型表单**（C17/C18/C19） | 海豚即任务类型内参数化；画布节点数可控；分型差异在表单内切换，类型枚举清晰 |
| SubProcess 子流程 | 不设（双层画布已取消，意见③） | 跨工作流复用由 C9 Dependent 承担 |
| Loop | 保留自创（用户裁定） | 前端已有 UI；迭代场景（重跑/轮询）真实存在 |
| 质量检查组件 | 本期不设（用户裁定质量后置） | I2 实证位保留，质量增量启动时以 SQL 组件+规则模板先行可满足 |
| Java 脚本组件 | 不设（既有裁定） | — |
| 文件读取独立组件 | **设（用户 09-18 裁定，推翻本表原结论）**：新增 C22 | 供用户检验数据（页面化预览网格）+ 工作流临时工作数据灵活流转（§1.4），增加编排灵活性 |
| 同步导航向导 vs 聚合组件模板 | **设（用户 09-18 意见⑬裁定）**：保留 C17 单节点 + 新增 C23 模板聚合组件，取消独立向导页 | 运行时本无区分（皆工作流实例）；模板=设计时物化展开，引擎零改动、不违反 SubProcess 不设裁定；展开后可插节点比向导灵活；单表快同步保留 C17 轻量路径（海豚 DataX 参照） |
