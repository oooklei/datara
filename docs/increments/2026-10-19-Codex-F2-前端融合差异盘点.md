## 3. 已核实结论与待补证

1. **已核实**：Datara 已有 SQL IDE 正式页面和统一 DAG 工作台；这些既有资产可以形成差异基线，但不能替代对参考产品行为和 Backend 契约的逐项验证。
2. **已核实**：可见 DataX 证据为 ETL profile 声明及 mock seed；DAG profile 明确排除 DataX。现有证据不足以宣称 Datara 已有正式 DataX 节点闭环。
3. **已核实**：Vanna 相关 Datara 页面属于验证入口且使用 mock agent；不能表述为真实 Vanna 集成已完成。
4. **待补证**：后端契约冻结后，逐功能建立“参考 UI 步骤—Datara API/schema—权限/错误/异步结果—正式页面映射—验收场景”对照；DBX 需按驱动核验对象和执行能力，DataX 需明确插件白名单/字段映射/资源权限，Vanna 需验证 Datara 权限、审计和安全确认。此处是后续立项输入，不是本轮准入或实施指令。
