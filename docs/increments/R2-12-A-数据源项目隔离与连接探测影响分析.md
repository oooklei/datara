## 身份、权限及数据边界

- Datara 业务管理账号名为 `admin`；数据库账号为 `root`。系统账号负责 Datara 的应用身份/授权；MySQL root 不作为 Datara 用户身份，也不被自动保存为任意数据源凭据。
- 既有 root 批准范围仍只覆盖旧 `datara_meta` 固定 allowlist 的只读访问。该批准不授权 root 访问任意 schema，也不放宽源端 DDL/DML。项目数据源连通探测必须绑定一个已经登记、项目有权访问的数据源；探测只执行只读会话及最小 metadata/版本查询，绝不能接受任意 URL/SQL 或运行写语句。
- 管理操作使用现有系统 token 与项目授权：系统 `admin` 可管理；项目 DEV 仅在所属项目内依 `EDIT_DEFINITION` 操作；Viewer/Analyst、跨项目、无效/过期/撤销 token 拒绝。protected validation runner 保持专用 DEV 身份，不提权为 admin。
- 用户凭据不得写日志或在读取响应中回显；本批不把既有 root 连接串/密码迁入 rebuild 配置。新增数据源 credential-at-rest 机制若现有配置不足，必须在本批设计/代码中明确，不得退化成日志明文或 API 明文输出。
- 本批现场控制页只允许在 192.168.1.9 的隔离测试资源上使用预置测试数据源；不得测试旧业务账号对非授权库的访问，不得保存或探测生产 root 凭据。任何实际共享目标配置的新增/删除均限定为本批由 runner 创建且可核对清理的 fixture。

## 本批目标与排除范围

目标：实现 project-scoped 数据源登记/列表/详情/更新/删除合同、受限连接测试及数据源 service 边界；提供独立静态测试页，以真实控件验证创建—列表—连接测试—更新—删除流程，并验证权限拒绝和密码不回显。

本批不包含：完整 schema/table/column 跨 schema tree（下一个 R2-12 子批）、最终连接池容量调优/并发性能基线（后续子批）、SQL IDE/SYNC 使用接入、导入旧数据源、旧页面融合、正式菜单、root 凭据迁移或任意 SQL 执行。

## 细化步骤

1. 影响复核：确认 I21 commit 与工作树边界；复查 R1 身份/项目 membership、现有 DataSourceDraft/probe 及目标 schema/migration 约束，记录实际暴露的权限缺口。
2. RED：新增数据源持久化、项目隔离、CRUD actor 权限、token 拒绝、探测器注入、只读探测、超时、凭据不回显、删除只影响同项目资源的 API/service tests。
3. 实现：建立 rebuild datasource record/repository/service 与 additive schema change；project_id 强制隔离；执行权限先于连接器实例化；probe 采用固定 dialect/参数化连接构造、有限 timeout、read-only transaction、精简 metadata 查询；异常响应只返回稳定 issue code。
4. 页面：建立独立 `rebuild-validation-r2-12-a.html` 和受保护 Playwright runner。预置项目/测试连接表单由 API 返回；控件级执行创建、详情、连接、更新、删除，并验证 viewer/跨项目拒绝及不回显凭据；不注册正式路由/menu。
5. 本地门禁：API 定向 RED/GREEN、rebuild 全后端 pytest、改动文件 Ruff/compileall、页面合同、Playwright syntax、diff-check；fixture 仅使用本机 SQLite/mock 连接器。
6. 远端门禁：在 1.9 先核验服务/mount/hash/schema/backup 与可用测试 datasource；确认 fixture 目标是本批创建的隔离项目记录且可审计清理；部署只更新 rebuild API source mount 和 18091 静态页，只重启 `datara-rebuild-api`。若 credential-at-rest key 缺失、无法证明 fixture 隔离或远程只读 probe 无法保证，则停在本地，不连接远端。
7. 按 browser-use 首选并对明确失败操作限时重试一次；仍阻塞时依技能转同 URL/18091 Playwright 实操，随后核对 API status/log、MySQL read-only、Web 与依赖容器健康/资源、fixture 最终删除证据。
8. 回写本影响分析、主计划、台账与 `evidence/R2/`；仅暂存本子批文件，独立提交。未实现 metadata tree/连接池/SYNC 时不得将 R2-12 或 R4 标为完成。
