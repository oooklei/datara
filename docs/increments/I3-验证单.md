## 4. 执行期间问题与修复（实测暴露，7 项）

| 问题 | 根因 | 修复 |
|---|---|---|
| 节点参数不参与变量解析（项 4 首测 PERIOD=工作流层） | resolve_tree 对业务字段调 resolve_text 传空 {}，四级链断在节点参数层 | variables.py resolve_tree 增加 node_params 参数贯通至字符串分支；resolve_node 下传节点参数 |
| 逻辑节点日志 API 报「日志文件不存在」 | master 逻辑节点（条件/延时/重试/收口）日志写容器私有 FS，未挂 datara-logs 共享卷 | docker-compose.yml datara-master 补 `datara-logs:/datara/logs` 挂载 |
| SSH 节点退出码 1 且零输出（项 1 首测 n6） | 远端 mkdir 失败（TrueNAS 根只读）时外层 shell stderr 未并入 stdout，paramiko 只见空输出 | ssh.py cmd 分组 `{ mkdir && cd && bash -s; } 2>&1`（stderr 并入 stdout）；同时修 seed 路径（下一行） |
| 02_meta_i3.sql runtime_dir seed 为 /datara/* | TrueNAS 根文件系统只读，/datara 不可创建 | seed 改 `/tmp/datara_runtime`、`/tmp/datara_tmp`（注释说明） |
| 超时任务终态=kill 应为 failure（项 7a 首测） | master 超时扫描置 FAILURE 后，worker 执行器 ctx.killed() 返回 KILL 直接落库覆盖；kill 标记无原因区分超时/停止 | queue.py set_kill 增加 reason（timeout/stop）+ check_kill 返回 str；worker handle_task 终态回写前统一转换 KILL+timeout→FAILURE（用户停止不受影响） |
| 容错转派无检测路径（项 10 首测无轨迹） | worker XAUTOCLAIM 仅启动一次（restart 间隔 idle<60s 不触发）；recover_running_instances 仅 LeaderGate 首次过闸执行 | worker 改启动 + 每 30s 周期 XAUTOCLAIM；认领时 RUNNING→fault_tolerance（5s 可观察过渡窗口）→按原 attempt 重跑 |

## 5. 实测偏差说明（与设计文档口径差异，均有依据）

| 项 | 设计文档口径 | 实测口径 | 说明 |
|---|---|---|---|
| 超时粒度 | §14 表写 10s | timeoutMin=1 → failure @71s | 引擎超时单位为**分钟**（constraints.timeoutMin，对齐海豚字段裁剪）；§14 表的 10s 为示意值。行为语义（命中→kill 标记→failure 收口+日志注明）与 §8 设计一致 |
| 重试间隔 | §14 表写 30s | retryInterval=1 → attempt=3 @153s | 引擎重试间隔单位为**分钟**（constraints.retryInterval）；153s = 2 次重试×60s + 执行耗时，语义正确 |
| 容错转派实现 | §2 对齐行「WorkerFailoverService（ZK 临时节点监听+按 host 扫描重派）…I3 同机重派，多主机归 I7」 | worker 自愈认领：启动 + 30s 周期 XAUTOCLAIM（idle>60s）认领 pending 消息 → fault_tolerance 5s 过渡 → 按原 attempt 重跑 | 同机场景下 restart 策略拉起的 worker 自认领等价于重派闭环（§3.4 注：单 worker 容器实测口径）；master 侧 ZK watch 掉线扫描重派归 I7 多主机 HA |

## 6. 工具链教训（沉淀至项目记忆）

- **TrueNAS SCALE 根文件系统只读**：1.9 上 `/datara` 等根路径不可创建（Read-only file system），仅 /tmp 及挂载卷可写；seed/脚本路径一律避开根目录
- **PowerShell 5.1 → ssh 引号链（再犯确认）**：PS 层剥引号 + 远端 zsh 二次解析，复合命令必炸；复杂远端操作一律**脚本文件 scp 执行**；PS 层禁 `&&` 用 `;`
- **mysql 容器 client 缺省 latin1**：所有经容器 client 的 SQL（含脚本 run_sql）必须 `--default-character-set=utf8mb4`，否则中文双重编码
- **master 逻辑节点日志必须与 worker 同卷**：日志 API 按共享卷路径读取，master 容器不挂 datara-logs 则条件/延时/重试日志全不可见——新增写日志的服务时同步检查卷挂载
- **Stream at-least-once 竞态防护模式**：测试驱动 run 后「_latest」抓实例必踩旧实例竞态；run_new/run_and_wait 以**基线实例 ID 集合过滤取新**，轮询 40s 无新实例即报错
- **容错过渡窗口与采样频率**：fault_tolerance 过渡 2s 会被 2s 轮询漏采，改 5s 窗口对齐前端轮询节奏；高频轨迹验证用 0.3s 采样探针
