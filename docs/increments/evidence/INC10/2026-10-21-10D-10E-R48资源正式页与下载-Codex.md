# 10D→10E / R-48 资源正式页与下载交付证据

## 交付范围

- `/p/:projectId/resources` 从占位段替换为资源正式页：项目资源列表、三种 kind 筛选、上传、不可变版本链、具体版本下载、工作流任务固定版本引用。
- kind 单一事实源冻结为 `sql/python/shell`；前端运行时预校验拒绝未知 kind，后端继续以 `RES_KIND_UNKNOWN` 拒绝未知值。
- 新增 `GET /api/v1/rebuild/resources/{resource_id}/versions/{version}/download?project_id=...`。端点先认证，再执行项目 `VIEW_ALL` 权限检查和资源项目归属检查；返回真实二进制及下载文件名。
- 引用只提交具体 `resource_version: number`，不接受 `latest`、URL、路径或 base64 引用。
