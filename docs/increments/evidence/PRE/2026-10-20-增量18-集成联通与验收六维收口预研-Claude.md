## 三、目标方案

### 3.1 分层架构

建议按「联通判据全量验收 → 门 1-8 全门收口 → 部署固化 → 验收六维关闭 → 遗留项清理」落地：

1. **联通判据全量验收**（18.1）：§7.3 七判据逐条：零 demo 零验证页 / 契约层全 GREEN / 仅连 8001 抓包无例外 / 每功能「查询→展示→操作→回写」闭环 / History 深链不落首页 / 菜单一致性 / 布局蓝本一致性。
2. **门 1-8 全门收口**（18.2）：门 1~7 逐门冻结令登记=提交号+测试 passed；门 8 试运行/正式运行行为验收全链路——借鉴归档 FE-13~FE-20 验收单格式。
3. **部署固化**（18.3）：新前端 18092 部署单确认、nginx/Dockerfile 生产配置、与 rebuild-api 8001 联调环境实测。
4. **验收六维关闭**（18.4）：冻结功能清单 / 目录契约 / 菜单继承 / API 一源 / 集成联通 / 验收六维逐维结论 + §3 功能清单状态列终版刷新 + 红线七条终验。
5. **遗留项清理**（18.5）：⭕ 待裁项状态确认、阻塞项 FV-02/T55/R3 终态登记、COPY_LEDGER / CONTRACT_REGISTRY 终版核对、A/B 类裁决清单终态。
