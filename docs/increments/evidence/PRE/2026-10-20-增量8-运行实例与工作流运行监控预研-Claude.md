## 三、目标方案

### 3.1 分层架构

建议按「后台表立项 → 后台表建模与端点 → 运行监控视角页签 → 运行监控统计视图」落地：

1. **运行监控后台表立项**（8.1）：归属域已裁定 execution（2026-10-20 用户首裁）；字段建模融合纪要⑨成功/失败记录数语义与客户参考表 `ods_data_sync_stat_detail` 表级对账语义（源/目标数据量、data_param、起止时间、dag_name），**仅参考语义不照抄表结构**。
2. **后台表建模与端点**（8.2）：按批准立项：模型 / migrations / 查询端点 / 统计写入点挂接执行链路；时间戳契约 CURRENT_TIMESTAMP 无 NULL。
3. **运行监控视角页签**（8.3）：execution 域 11 端点承接：实例列表/详情/日志/attempt 隔离视图；instance_type 三态 TRIAL/FORMAL/STREAM 枚举与筛选。
4. **运行监控统计视图**（8.4）：后台表承接：成功记录数/失败记录数/对账明细展示。

### 3.2 后台表建模设计（建议）

| workflow_run_reconcile_detail | id / run_stat_id / source_table_name / target_table_name / source_count / target_count / data_param / start_time / end_time | 对账明细（仅参考 ods_data_sync_stat_detail 语义） |
