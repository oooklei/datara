## 四、状态机（冻结）

```
定义：draft ──publish──▶ published ──disable──▶ disabled
         ▲                                       │
         └────────────── enable ─────────────────┘
  非法迁移（如 draft→disable、published→draft）→ 4092 invalidStatusTransition
Key：active ──revoke──▶ revoked（终态；rotate= revoke(old)+issue(new) 原子对）
```

| code | 常量 | 语义 |
|---|---|---|
| 1001 | invalidToken | 会话/凭证无效（identity 共用） |
| 1003 | permissionDenied | 权限拒绝（identity 共用） |

## 六、权限矩阵（冻结；复用 identity 既有权限点，零新增枚举）

- 写面（create/update/delete/publish/disable/enable/issue/rotate/revoke）：`security:manage`
- 读面（listApis/listKeys/listCallLogs）：`security:read`
- 网关面（G）：不走会话权限，走 key scope（`scopes.permissions` 须含定义的 `required_permission`，`projectIds` 须含目标项目或为空=全域）

## 七、安全红线（验收 ④；C4 冻结）

1. **原始 key 仅签发/轮换响应显示一次**（`KeyIssuance.plainKey`）；列表/详情/日志任何面零明文；
2. **库内 hash-only**（不可逆 hash，与 LLM 域 AES-256-GCM 严格分治）；
3. **调用日志不落**：原始 key、敏感 body、完整 SQL；
4. **管理面调用 fail-closed**：日志写入失败不伪造审计成功（C4）；
5. 证据纪律：验收证据不得含真实 key 明文（成对证据纪律）。
