## 二、守卫语义映射（设计→实现定稿披露）

| 语义 | 设计码 | 前端实现 |
| --- | --- | --- |
| projectId 非整数，或不在 listProjects 可见集合 | 4041 | 守卫拦截，重定向 `/`（列表页=归属源）；非整数不发请求 |
| 项目作用域子资源 not found | 4042 | 后端语义；前端 ProjectSegmentView 占位承载未知 seg，守卫不拦 seg |
| 九域授权闸门 | 403/1003 | 后端语义（app.py `project_permission_error`）；前端显隐不替代鉴权，不预判 |

归属判定唯一数据源 = `listProjects()` 成员性（后端无 `GET /projects/{id}` 单查端点、ownOrJoined 未交付，前端不假设）。拦截统一回 `/`：列表页即归属源，无 4041 专属页面。

## 三、「API 自动注入 project_id」前端形态定稿

前端不造统一拦截器——既有 API 契约层（metricsApi/memberApi 收编件）全部显式传 projectId，禁改。前端形态 = **Route props 数字化注入链**：URL `:projectId` → props 数字化 → API 契约显式 `projectId` 参数（既有先例 createMetricsContract 六方法 / memberApi 四端点）。守卫保证 URL projectId 归属合法后，注入链即为授权上下文传递。「API 注入正确」由既有正断言覆盖（projectWorkbenchView statsSpy projectId=9）。
