### 字段映射定稿表（旧 mock 八字段 → rebuild_sec_access_log）

| 旧字段（demo mock 语义） | 语义轴 | 新字段（rebuild_sec_access_log） | 新契约适配 |
| --- | --- | --- | --- |
| user | 操作者 | user_name String(128) NOT NULL，index | 命名明确化；ix_sec_access_log_user_time 复合索引 |
| action | 动作 | action String(64) NOT NULL | HTTP method 映射：GET→query / POST→create / PUT+PATCH→update / DELETE→delete；SQL 通道=execute_sql |
| target | 对象 | target String(256) NOT NULL | HTTP 请求路径，或 SQL 语句摘要（空白归一+截断 512） |
| rows | 行数 | rows_seen Integer NOT NULL default 0 | 拒绝事件强制归零；CheckConstraint ck_sec_access_log_rows（rows_seen>=0） |
| （旧无） | 结果 | result String(16) NOT NULL | 英文枚举 allow/deny（新契约范式，弃旧中文枚举）；CheckConstraint ck_sec_access_log_result |
| （旧无） | 原因 | reason String(512) NOT NULL default '' | HTTP 通道=http_status_{status}；SQL 通道=sql_execution_hook |
| ts | 时间 | accessed_at DateTime NOT NULL | server_default current_timestamp；索引 |
| （旧无） | 追踪 | request_id String(128) NOT NULL default '' | 对齐 governance AuditEventRecord 范式 |
| （旧无） | 审计 | created_at / updated_at | SecTimestampMixin（server_default+onupdate） |

索引：ix_sec_access_log_user_time(user_name, accessed_at)、ix_sec_access_log_result_time(result, accessed_at)。
