## 4. 定性结论与五步规则适用性调整

### 4.1 定性

旧实现=**情形 b)+c) 混合**：

- b) 前端承载（实证）：`/sec/audit` demo 页面 + auth.audit() 写入链 + mock seed；
- c) 旧后端无实证：api/ 全域零访问审计端点、零审计表模型——「迁移旧后端」对象不存在。

### 4.2 循先例

v3 L892 先例（G 组 API 管理/API-Key 管理：旧后端无实证 → 不属迁移项 → 新建模立项随 WBS 批次）完全同构：访问审计旧后端无实证 → **「迁移旧实现」实质=新建模立项**。

| 五步 | 原口径 | 调整口径 |
