## 4. 实施教训（测试期踩坑与修正）

- **VTU 同实例断言**：`findComponent(...).vm` 每次调用返回新 wrapper（`toBe` 报 "serializes to the same string" 但 Object.is 不等）——同实例断言改用内部实例 `$.uid` 比对（组件不销毁重建时 uid 恒定）。
- **onPickTasks name 语义**：`openTab(docId, meta, seedType)` 内 `name = meta?.name ?? docId`——pickTasks 载荷 `item.name`（Palette 行占位名）不透传，池 miss 时 Tab name 落 docId 字符串；测试用例 ② 改种池命中 id '42'（ROW9 → Tab 真名'客户画像'），断言贴近真实语义（顶栏入口载荷=画布 Tab 文档名）。
