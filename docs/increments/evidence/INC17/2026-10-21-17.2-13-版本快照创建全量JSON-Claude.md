## 二、快照语义逐行照抄（`_model_snapshot` + `_fields_of`）

迁移源实锚：`api/model.py:325-335`（`_model_snapshot`）+ `:460-463`（`_fields_of`）+ `:362-374`（路由体）。

```
snap = {
  "model":     _model_row(m, _xc_map(db)),      # 16 键 ModelRow（含 er 无关，但含 remark 等原样）
  "fields":    [_field_row(f) for f in query(DwModelField).filter(model_id).order_by(seq).all()],
  "relations": [{"id","srcModelId","tgtModelId","relType","srcFields","tgtFields","joinDesc"}
                for r in query(DwModelRelation).filter(or_(src==m.id, tgt==m.id)).all()],
}
row = DwModelVersion(model_id=m.id, version=m.version,
                     snapshot_json=json.dumps(snap, ensure_ascii=False),
                     change_note=body.changeNote.strip(), created_by=user.user_name)
```

**四处照抄要点**：

1. **`json.dumps(..., ensure_ascii=False)` 保中文原样**：若用默认 `ensure_ascii=True`，
   中文会写成 `\uXXXX` 转义。A6-14 diff / A6-15 回滚虽仍能解析，但快照文本与旧侧不再逐字一致。
   用例 3 断言原始文本含「订单明细」「备注原文」且**不含** `\\u`。
2. **`version` 取模型当前值**（非入参、非自增）：快照记录的是「存快照那一刻模型的 version」。
   配合 `UniqueConstraint(model_id, version)` → 每个 version 值至多一份快照。
   用例 2 断言 `data["version"] == 3`（种子模型 version=3）。
3. **关系取双向**（`or_(src, tgt)`）：与 A6-5 ER 保存的增量 diff 口径无关，快照始终取全量双向边。
4. **`changeNote.strip()`**：用例 4 断言 `"  带空格  "` → `"带空格"`；缺省空串合法（用例 4 第二段）。

### 2.1 快照不含 `changeNote`（候核）

`change_note` 存于**行字段**而非快照 JSON 内（旧侧 `_model_snapshot` 返回值只有
`model`/`fields`/`relations` 三键）。用例 3 断言 `"中文说明" not in raw`（说明不入快照体）。

## 三、重复快照的冲突行为（迁移忠实点，候核）

`POST` 同 `(model_id, version)` 二次建快照时：

- 旧侧**仅**注册 `ApiError` 处理器（实锚 `api/main.py:48`），**无** `IntegrityError` 分支；
  该冲突在旧侧同样**冒泡为原始 DB 错误**（HTTP 500，纯文本体）。
- rebuild 侧**照抄**该行为：**不**新增 409/8xxx 友好分支，由 `IntegrityError` 穿透到传输层。

用例 5/6 据此断言（两条互补）：

| 用例 | 断言 |
| --- | --- |
| 5 | `pytest.raises(IntegrityError)` —— 约束生效且**未被吞、未被转译**；列表仍 1 行 |
| 6 | `raise_server_exceptions=False` 下 `status == 500` 且体为纯文本 `"Internal Server Error"`，**非** `{code,msg,data}` 信封 |

**若后续 rebuild 增补 `IntegrityError` 处理器**（例如统一 500→信封），用例 6 会失败 ——
届时属**有意的行为变更**，须走变更单而非迁移照抄。

### 3.1 唯一约束按 version **值**而非行数

模型 `version` 递增后（A6-11 redraft）可再存**同 version 号**快照 —— 约束是
`(model_id, version)` 组合唯一，非「每模型仅一行」。用例 7 断言：v3 存一份 → redraft（→v4）
→ v4 可再存 → 列表 `[4, 3]` 两行。
