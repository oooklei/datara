## 三、删除语义逐行照抄（`api/model.py:239-258`）

**① 状态闸**：`if m.status in ("built", "produced")` → 8005/409「已物理化模型不可删除」。
注意与 A6-7 的 `status != "draft"` **不同**：删除只拦**已物理化**两态，`published` 可删。

**② 血缘引用防护**（仅查**本模型为上游 src** 的边）：

```
for r in query(DwModelRelation).filter(src_model_id == model_id):
    t = get(DwModel, r.tgt_model_id)
    if t: refs.append({"id": t.id, "code": t.code, "name": t.name})
if refs: raise ApiError(MODEL_IN_USE, status=409, data={"refs": refs})
```

- **单向**：只查 src 侧 → 本模型作**下游**（tgt）被引用**不**阻断删除（用例 5 断言）
- **`if t:` 守卫**：下游模型已不存在（悬空 tgt）**不**计入 refs → 可删（用例 6 断言）
- refs 元素为**三元组** `{id, code, name}`（`id` 为 int，照抄旧侧）

**③ 级联删除**（顺序照抄）：

```
query(DwModelField).filter(model_id == model_id).delete()            # 字段
query(DwModelRelation).filter(or_(src == id, tgt == id)).delete(synchronize_session=False)   # 关系双向
db.delete(m)                                                         # 模型本体
db.commit()
```

- 关系删除用 `synchronize_session=False`（旧侧同参数，照抄）
- 关系删除为**双向**（`or_(src, tgt)`），与 ② 的**单向** refs 检查有意不对称 —— 照抄，不「修正」
