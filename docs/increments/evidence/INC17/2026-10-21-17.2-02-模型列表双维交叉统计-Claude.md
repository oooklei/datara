## 三、双维交叉统计口径照抄（`api/model.py:120-152`）

`_base`（status 精确 + keyword 剥离后 code/name/owner 三字段 LIKE）复用同一谓词：

- **分层计数**：逐层 `count` 叠 `domain` 过滤（交叉）
- **域计数**：逐域 `count` 叠 `layer` 过滤（交叉）
- 主查询：叠 `layer` + `domain` → `update_time desc` → `offset/limit` 分页

## 四、`t_dw_model` 主表迁移（照抄 `common/models.py:782-808`）

`rebuild/model/models.py::DwModelRecord` 列定义/类型/默认值/注释逐项照抄：
`id/code(unique)/name/layer/type(默认明细表)/biz_domain/engine/ds_id/db_name/security_level(默认内部)/status(默认 draft)/version(默认 1)/er_pos(JSON)/last_ddl/built_at/built_by/owner/remark/create_time/update_time`。

- `last_ddl` 旧侧为 MySQL `MEDIUMTEXT`；新侧用 `Text().with_variant(MEDIUMTEXT, "mysql")` —— **保 MySQL DDL 忠实，同时让 SQLite 测试载体可编译**（rebuild 全域无 MySQL 专有类型先例，此为最小必要偏离，已如实披露）。
- `MODEL_TABLES` 追加 `DwModelRecord.__table__` → `create_all` 自动建表。
