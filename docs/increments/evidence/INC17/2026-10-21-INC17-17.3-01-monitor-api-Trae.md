## 4. 关键语义甄别（候核④实证闭环+R1 现态口径）

- **恒降级实锚链（候核④升级为实锤）**：rebuild/api/app.py 全文 grep `state\.registry` **零命中**——rebuild 侧永不赋值 `app.state.registry` → `zk_provider()` 恒返回 `getattr(None,"zk",None)=None` → `list_live_nodes(None)` 于 common/registry.py L41-42 **短路返回 `(False, [])`**（None 入参不抛异常，连 service 异常捕获都无需触发）→ rebuild 应用上 monitor 恒降级（zkAvailable 恒 False、master/worker 行恒 heartbeat="unknown"、ssh 行照常）。契约层面不违约（B3-1 降级语义本就是契约态），功能层面 master/worker 存活状态在 rebuild 应用上暂不可观测——**装配缺口**，非逻辑缺陷。
