## 二、要点① 前缀统一 `/api/v1/rebuild/...` —— ✅ 认可

**独立实锚（当前工作区实测）**：

1. **在库 frozen 先例×2**：
   - `rebuild/sshnode/api.py:1`——docstring「Frozen B7 HTTP adapter: /api/v1/rebuild/ssh-nodes」（B7 适配器已在增量骨架中冻结，语义路径自声明）
   - `rebuild/monitor/api.py:1`——docstring「Frozen B3 HTTP adapter: GET /api/v1/rebuild/monitor/nodes」
2. **显式前缀先例×2**：`rebuild/governance/api.py:184`（`APIRouter(prefix="/api/v1/rebuild/governance")`）、`rebuild/rb/api.py:40`（`APIRouter(prefix="/api/v1/rebuild/sql-ide-ddl")`）
3. **旧侧统一挂载先例**：`api/main.py:85-110` 全部 `include_router(prefix="/api/v1")`——单规则挂载为既有风格

**核验意见**：「统一 `/api/v1/rebuild/...`」非新发明，而是与库内 4 处既有实锚一致；网关/代理按 `rebuild` 段单规则匹配可一次配置。草案四分片（models/monitor/runtime-nodes/ssh-nodes）采同一模式成立。

**一处观察（不构成异议）**：B3/B7 frozen 适配器 router 本体无前缀（`APIRouter()`+`@router.get("/nodes")`），语义路径依赖挂载参数补齐（须 `prefix="/api/v1/rebuild/monitor"`）；governance/rb 则 router 内置前缀。两种模式并存，建议冻结清单附录显式约定四分片挂载方式（二选一写死），避免实施票各自发挥。

**例外确认**：`rebuild/sql_ide/routes.py:84`（`/api/v1/projects/{project_id}/sql-ide`）系项目作用域路径，不属基础设施域，不入 rebuild 段合理。
