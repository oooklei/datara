## 二、回滚语义逐行照抄（`api/model.py:396-415`）

```
m    = _get_model(db, model_id)            → None 即 8001/404（内置 msg）
src  = query(DwModelVersion).filter(id == version_id, model_id == model_id).first()
src is None                              → 8001/404（**显式 msg**「版本不存在」）
snap = json.loads(src.snapshot_json)
m.status = "draft"                        # ★ 无条件：无状态闸
m.version += 1
query(DwModelField).filter(model_id == m.id).delete()      # 全量替换
for i, f in enumerate(snap.get("fields", []), 1):
    db.add(DwModelField(model_id=m.id, seq=i, **_field_kwargs(f)))
db.commit()
saved = DwModelVersion(model_id=m.id, version=m.version,
                       snapshot_json=json.dumps(_model_snapshot(db, m), ensure_ascii=False),
                       change_note=f"rollback from {src.version}", created_by=user.user_name)
db.add(saved); db.commit()
return {"status": "draft", "version": m.version, "sourceVersion": src.version}
```

**五处照抄要点**：

1. **两次 8001 判定对象不同**：模型缺失用内置 msg；版本行缺失用显式 msg「版本不存在」。
   用例 6/7 分别断言，用例 8 断言他模型的版本 id 对本模型不可见。
2. **★ 无状态闸**：旧侧**无条件** `m.status = "draft"`，即便模型**已是 draft** 也照做，
   **不**报 8005（与 A6-10 发布闸 `status != "draft"`、A6-11 回草稿闸 `status == "draft"` 均不同）。
   用例 5 断言 draft 态模型回滚仍返回 200 且 `version` 递增。
3. **字段全量替换**（非合并）：先 delete 再按快照顺序 `enumerate(..., 1)` 重排 `seq`；
   快照外字段被删除。用例 3 断言 `now_a`/`now_b` 被清除、只剩快照字段。
4. **`sourceVersion` 取快照行的 `version` 值**（非入参 `version_id`）：用例 2 断言
   `version_id`（行 id）与 `sourceVersion`（版本号 3）不同。
5. **回滚后存新快照**：新行 `version = m.version`（递增后），`change_note` 由旧侧 f-string
   拼为 `"rollback from {src.version}"`，`created_by` 取当前操作人。用例 4 断言列表
   `[6, 3]` 两行、新行 `changeNote == "rollback from 3"`、`createdBy == "admin"`。

### 2.1 唯一约束在此天然满足

回滚先 `m.version += 1` 再建快照，故新 `(model_id, version)` 必不与既有行冲突 ——
这也是旧侧**不在**此处捕获 `IntegrityError` 的原因（对比 A6-13 建快照时的 500 冒泡）。
