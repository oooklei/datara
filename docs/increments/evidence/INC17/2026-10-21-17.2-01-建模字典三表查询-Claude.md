## 四、鉴权与错误形状

| 场景 | 状态码 | 体 |
| --- | --- | --- |
| 无 token / Bearer 缺失 | 401 | `{code:1001, msg:"invalid token", data:null}` |
| token 不在 ActiveTokenStore | 401 | 同上 |
| token 签名/过期无效 | 401 | 同上 |
| 合法 token | 200 | `{code:0, msg:"success", data:{...}}` |

- **R-32 注记**：本票无 4xxx/8xxx 业务错误码（纯读端点）；8xxx 段（8001-8010）随写端点票（17.2-03 起）在域内显式定义，**禁从 `common/resp.py` 导入常量**（R2 注记）。
- **401 用 1001 而非旧侧 1003 的说明**：旧侧 `api/auth.py:98` 抛 `TOKEN_INVALID=1003`；新侧 host 鉴权约定为 `1001`（`rebuild/dependency|metrics|resources/*` 一致）。FE `http.ts` 对 **1xxx 整段**跳登录（不区分 1001/1003），故 1001 与 FE 契约兼容。已在开工回执披露。
