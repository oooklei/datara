### 2.2 History 回退配置核验（裁示②：1.4 收口范围）

| 断言 | 判据 | 锚点 |
| --- | --- | --- |
| `router` 使用 `createWebHistory` | §2.4 冻结决策（弃 hash） | `router/index.ts` 源码含 `createWebHistory`、不含 `createWebHashHistory` |
| dev server SPA 回退 | 深层 path 直达由 vite 回落 `index.html`，不落首页 | `vite.config.ts` **不含** `appType`（即默认 `spa`） |
| SPA 单一挂载点 | History 模式无 hash 路由入口 | `index.html` 恰含 1 个 `<div id="app"`，不含 `createWebHashHistory` |
| vite dev 单线反代 | §7.1 单 BASE 拓扑 | `'/api/v1'` + `localhost:8001` 在位；不含 `LEGACY_BASE`、不含 `8000` |
| 登录守卫按 token 判定 | 守卫与 History 模式正交 | 运行时 `router.options.history` 非 null、`base` 不含 `#`、`base ∈ {'', '/'}` |

**源码核验锚点**（本票实读）：
- `src/router/routes.ts`：`routes = [{path:'/login',…},{path:'/',…}]` — 2 条，零 catch-all，零 `/api` 前缀
- `src/router/index.ts`：`createWebHistory()` + `beforeEach` token 守卫（`/login` 有 token → `/`；无 token → `/login`）

> **`base ∈ {'', '/'}` 的说明**：`createWebHistory()` 无参时 vue-router 产出 `base === ''`，非 `'/'`。
> 断言取「不含 `#` 且为空串或 `/`」的宽式判据，避免把实现细节（`''` vs `'/'`）误判为契约违背。
