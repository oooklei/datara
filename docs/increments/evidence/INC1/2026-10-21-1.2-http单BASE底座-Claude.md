## 三、实现要点

1. **单 BASE**：`BASE = '/api/v1'`（`as const`），`API_BASE = BASE` 别名；`buildUrl` 只做 `BASE + path` 拼接与查询串序列化，无第二 BASE、无分派。
2. **token 携带**：默认从 `localStorage[TOKEN_KEY='datara_token']` 读取并写入 header `'token'`（与 rebuild 域既有鉴权头同源）；`anonymous: true` 跳过（登录等匿名端点）；空 token 不写头。
3. **包络三态**（复用 1.3 冻结原语，不另立错误类型）：
   - 成功 `code === 0 / 200 / '0' / '200' / undefined` → `resolve(data)`（`data` 键缺失时返回整包络，兼容 R-39 裸 JSON）；
   - 业务错误 `code ≠ 0/200` → `throw ContractApiError{httpStatus, code, msg, raw?}`；
   - 系统错误 非 2xx → **解包前**抛 `ContractApiError{httpStatus: res.status, code: res.status, raw}`；
   - 空响应体（204）→ `resolve(undefined)`。
4. **1xxx 跳登录**：`isAuthErrorCode(code)` 判 1000–1999；命中即调用可注入 `loginRedirector`（默认 `window.location.assign('/login')`，`setLoginRedirector(fn|null)` 供 SPA 路由接管或测试注入），**跳转后仍继续抛出** `ContractApiError`（UI 捕获方式不因接线改变）。
5. **15s 超时**：`AbortController` + `setTimeout(timeoutMs ?? HTTP_TIMEOUT_MS)`，`finally` 清除定时器；abort 归一为 `ContractApiError{httpStatus: 0, code: 'TIMEOUT'}`；`timeoutMs` 可覆盖（默认 15000）。
6. **请求体**：`json` 给定 → 自动 `Content-Type: application/json` + `JSON.stringify`；`body`（FormData/Blob 等 `BodyInit`）透传且不强制 Content-Type；二者同给时 `json` 优先。
7. **查询串**：`query` 键经 `adapterKit.camelToSnakeKey` 转 wire 词形（幂等），`undefined`/`null` 剔除，值经 `encodeURIComponent`。
8. **动词便捷方法**：`getJson` / `postJson` / `putJson` / `patchJson` / `deleteJson`。
9. **依赖方向**：`http.ts → ./rebuild/adapterKit`（冻结原语，不含 fetch）→ 无环；契约层 → `../http`（`getToken`）维持 1.3 现状。
