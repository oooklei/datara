## 1. 统一接线模式（全部批次共用，DRY）

### 1.1 fetch 原语（每契约文件顶部新增，薄映射层与契约类型同文件）

```typescript
/* ---------- GREEN 实现（替换 notWired；薄映射层随冻结契约逐方法落地） ---------- */

import { camelToSnake, snakeToCamel, wireIdToNumber, numberToWireId, ContractApiError } from '../adapterKit'
import { getToken } from '../http'

/** 端点前缀：草案值，接线第 0 步以后端冻结契约路由为准逐一核对 */
const BASE = '/api/v1/rebuild/variables'

const TIMEOUT_MS = 15000

/** 统一 JSON fetch 原语：15s AbortController 超时 + token header（'token'，与 http.ts 约定同源）+ 归一错误 */
async function requestJson<T>(path: string, init?: RequestInit): Promise<T> {
  const ctrl = new AbortController()
  const timer = setTimeout(() => ctrl.abort(), TIMEOUT_MS)
  try {
    const headers: Record<string, string> = { 'Content-Type': 'application/json' }
    const token = getToken()
    if (token) headers.token = token
    const res = await fetch(`${BASE}${path}`, { ...init, headers: { ...headers, ...(init?.headers as Record<string, string>) }, signal: ctrl.signal })
    if (!res.ok) {
      const raw = await res.text().catch(() => '')
      throw new ContractApiError({ httpStatus: res.status, code: res.status, msg: `HTTP ${res.status} ${path}`, raw })
    }
    return (await res.json()) as T
  } catch (err) {
    if (err instanceof DOMException && err.name === 'AbortError') {
      throw new ContractApiError({ httpStatus: 0, code: 'TIMEOUT', msg: `请求超时（${TIMEOUT_MS / 1000}s）${path}` })
    }
    throw err
  } finally {
    clearTimeout(timer)
  }
}

/** GET：查询参数 snake_case 序列化（FE camel 参数 → wire snake 键），响应 camel 化 */
async function getJson<T>(path: string, query?: Record<string, string | number | boolean | undefined>): Promise<T> {
  const qs = query
    ? '?' +
      Object.entries(query)
        .filter(([, v]) => v !== undefined)
        .map(([k, v]) => `${encodeURIComponent(camelToSnakeKey(k))}=${encodeURIComponent(String(v))}`)
        .join('&')
    : ''
  return snakeToCamel(await requestJson<unknown>(`${path}${qs}`))
}

/** POST/PUT：请求体 camel→snake，响应 camel 化 */
async function sendJson<T>(method: 'POST' | 'PUT', path: string, body: unknown): Promise<T> {
  return snakeToCamel(await requestJson<unknown>(path, { method, body: JSON.stringify(camelToSnake(body)) }))
}

import { camelToSnakeKey } from '../adapterKit'
```

**包络形态判定（接线期开放问题 1，R2 批次第 0 步固化）**：若 BE 冻结包络为 `{code, msg, data}`，`requestJson` 在 `res.json()` 后加一层：

```typescript
const envelope = (await res.json()) as { code?: number; msg?: string; data?: unknown }
if (typeof envelope.code === 'number' && envelope.code !== 0 && envelope.code !== 200) {
  throw new ContractApiError({ httpStatus: res.status, code: envelope.code, msg: envelope.msg ?? path, raw: envelope })
}
return (envelope.data ?? envelope) as T
```

判定依据=该批次接线前与 Codex 对照冻结契约确认；R2 固化后其余批次沿用，不再逐批重复确认。
