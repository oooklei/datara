## 3. 编辑器

### 3.1 完整版 SqlEditor.vue（Monaco，对标真源）

**内核**：`monaco-editor/esm/vs/editor/editor.api.js` + `editor.worker?worker`（`MonacoEnvironment.getWorker` 单例）；**刻意不引** TS/CSS/HTML/JSON 语言服务（SQL 页 bundle 瘦身）。自定义语言 `datara-sql`（monarch）：

- 关键字 ~70 个（SELECT…CALL）+ 函数 21 个（COUNT(*)、NOW()、DATE_FORMAT…）；忽略大小写；注释 `--`、`#`（排除 `#{`）、`/* */`；字符串 `"`/`'`/反引号标识符（支持双写转义）；十六进制/浮点数。
- **`${var}` 变量独立 token `variable.datara` 分色**（深色 #e5c07b 加粗 / 浅色 #b26a00）。
- 自定义主题 `datara-dark`（底 #0e1116，base vs-dark）/ `datara-light`（底 #fbfcfe，base vs），watch theme 联动 `monaco.editor.setTheme`。

**编辑器选项**：minimap off、fontSize 13、lineNumbers on、wordWrap on、scrollBeyondLastLine false、fixedOverflowWidgets、tabSize 2、automaticLayout。

**补全 provider**（triggerCharacters `$`、`{`，模块级单例注册一次）：
1. 行前缀匹配 `/\$\{?[\w)]*$/` → 变量补全：`store.globalParams[env]`（label `${name}`，detail「全局参数（env）」，富文档：功能用法/当前值/数据来源=后端 `GET /params/global`，写入 `suggestDocMap`）；`store.builtinPreview` 14 项内置时间参数（与后端 `vars_render.py` builtin_vars 同口径，前端 dayjs 实时预览）；`${date(N)}` 函数式日期（insertText `${date(0)}`）。
2. 其余：`schemaCache[currentDb]` 表（Class）+ 字段（Field）+ SQL 关键字 + 函数。

**Hover provider**：光标落在 `${...}` 内 → date(N) 解释 / 全局参数当前值+说明 / 内置参数说明 / **未定义变量警告**「当前环境（env）均未定义，执行时将保留原文不被替换」。

**建议行悬浮富提示（G12b，自绘）**：Monaco 0.56 原生 details 不随 hover 显示 → DOM 事件委托监听 `.suggest-widget .monaco-list-row` mouseover，按 label 查 `suggestDocMap`，自绘 fixed tooltip（360px，mdToSafeHtml 白名单转义：`**b**`/`` `code` ``/`*i*`），视口越界翻转，mouseout 延迟 120ms 隐藏，MutationObserver 监听 widget 移除即隐藏；卸载全量清理。

**Lint markers（500ms 防抖）**：`POST /ide/lint {sql}` → 逐语句 `{stmtIndex, ok, error, line, col}`；前端 `splitStmtSpans` 与后端 `_split_sql` 同口径分号拆分并记录每条起始行列，将语句内相对行列映射为文档绝对位置 → `setModelMarkers('datara-lint')` Error 波浪线。**本地风控 Warning 并存**：① 未定义 `${var}`（known=全局参数+内置，date(N) 豁免）定位首现位置；② SELECT 无 LIMIT「可能全量/大结果集返回（驻留层上限 2000 行会自动截断，导出不受此限）」。lint 服务不可用不阻塞编辑。

**快捷键**：`Ctrl+Enter` runSql（**选中片段则仅执行片段**，`getSelectionOrAll`）、`Ctrl+S` saveScript(false)、`Ctrl+Shift+F` fmtSql。

**内容同步**：onDidChangeModelContent → `charCount` 更新 + 命名脚本 `updateScriptContent` + lintDebounced；外部 setText 走 `pushEditOperations`（`syncingContent` 抑制回环）；watch `activeScriptId` 切 Tab 内容隔离；watch `store.fillRequest.n`（树/结果 Tab「回显 SQL」通道）覆写当前 Tab 内容。

**脚本 Tab（G16）**：命名脚本=后端 `t_ide_script`（`/ide/scripts` CRUD）；未命名脚本=sessionStorage `datara.ide.unnamedScripts`，**上限 5 个**（超出 warning「未命名脚本最多驻留 5 个，请先保存命名脚本」），刷新丢失为明确需求；命名「未命名SQL #N」自动递增；Tab 关闭切换到邻位；`openNamedScript` 同 scriptId 已开则复用切换。

## 5. 结果区

### 5.1 完整版 ResultPanel.vue（vxe-table v4，对标真源）

**结果 Tab 组（G17）**：每次运行**按语句独立成 Tab**（`结果 #N` / `DML #N` / `错误`，title=原始 SQL，seq 全局递增）；单 Tab × 关闭 + 「一键清空」；**点击 Tab 即回显该语句原始 SQL 到编辑器**（`setActiveResult → requestFill(tab.sql)`，含渲染前原文）。每次新运行 `resultSeq=0` 重置。

**查询 Tab 主体**：
- 统计行：`共 {rowsTotal} 行 · 内存 {rows.length} 行 · {elapsedMs}ms`（筛选后另示行数）；重放翻页时黄字「重放分页可能页间漂移」。

## 7. 执行链路（准确实现）

### 7.1 完整版（ideStore + ideApi）

```
runSql(sql)
  ├─ 前置校验：running 中→warning；activeDsId null→warning；sql 空→warning
  ├─ ensureActiveTab()；logs/resultSeq 重置；logsSql = sql.split(';') 语句序缓存
  ├─ pushLog(info, `提交执行：N 条语句 · 模式=… · env=…`)
  ├─ POST /ide/execute {datasourceId, db, sql, mode: auto|manual, env: dev|staging|prod}
  │    → {taskId}（并发超限 429 由 http 层 throw msg）
  ├─ new EventSource(buildStreamUrl(taskId))
  │    URL = /api/v1/ide/stream/{taskId}?token={getToken()}   // EventSource 无法带 header，token 走 query
  │    ├─ 'log' 事件（type=start|end|error|txn）：
  │    │    start → 日志「语句 N 开始」+ rendered 渲染后 SQL + varSnapshot 变量快照（name=value(source)）
  │    │    end(kind=exec) → 新建 DML Tab（affected）+ 日志；end(kind=query) → 日志行数/耗时；WARNINGS→vars 日志
  │    │    error → 新建错误 Tab + 日志；txn → COMMIT/ROLLBACK 日志
  │    ├─ 'result' 事件 → 新建查询 Tab（columns/rows 字符串化/rowsTotal/elapsedMs），historyId 暂 null
  │    └─ 'done' 事件 → 全部未回填 Tab 回填 historyId；
  │         success→ElMessage.success「执行成功：N 条语句，Xms」；canceled→warning；failure→error
  │         historyDirtyN+1 → 历史抽屉增量刷新；finally closeStream + running=false
  └─ es.onerror：EventSource 内建断线重连，仅任务被后端清理（非 running）时主动 close
stopRun(): POST /ide/cancel/{taskId} → {canceled, killed?}
```

- **超时**：SSE 无前端超时（长连接）；http 常规请求 15s（http.ts TIMEOUT_MS）。
- **断线**：依赖 EventSource 原生重连；done 后强制关流；组件卸载 `disposeRuntime()` 关流+复位（防泄漏）。
- **取消**：done status=canceled + 日志「已发送停止指令（KILL QUERY）」（后端 KILL QUERY）。
- **结果重放分页**：`GET /ide/result/{historyId}/{stmtIndex}?offset=&limit=`（注释明确「页间可能漂移」）。
- **导出**：`GET /api/v1/ide/export?historyId=&format=csv|json|xlsx` —— 后端按 historyId **重放 SQL** 生成文件流。

### 7.2 R5A 版（rebuild/sqlIdeApi.ts）

```
POST /api/v1/projects/{pid}/sql-ide/executions {datasourceId, sql, mode:'auto', sessionId, clientRequestId} → {taskId}
GET  .../executions/{taskId}/events   （Accept: text/event-stream；错误帧 envelope 含 errorCode）
GET  .../executions/{taskId}          （轮询状态兜底 getSqlIdeExecutionStatus）
POST .../executions/{taskId}/cancel   → {accepted, status}
GET  .../results/{historyId}?resultSetId=&offset=&limit=   （重放分页，键=resultSetId）
```

## 11. 旧 IDE（成熟实现）与 1.9 新 IDE（CodeMirror 轻量版）差异最大的点（对标差距清单）

1. **编辑器内核与 SQL 智能**：旧=Monaco + 自定义 `datara-sql` monarch（`${var}` 分色）+ 表/字段补全（树缓存注入）+ 变量富文档补全 + `${var}` hover + 500ms 防抖服务端 lint 波浪线 + 本地风控 Warning（未定义参数/SELECT 无 LIMIT）；新=CodeMirror 6 仅高亮+行号+oneDark，无补全/hover/lint。
2. **多脚本会话**：旧=脚本 Tab 条（命名后端持久化 + 未命名 sessionStorage 上限 5、新建/载入/保存/另存为全链路）；新=单文本框，无 Tab 无持久化。
3. **多语句结果呈现**：旧=每条语句独立结果 Tab（结果 #N/DML #N/错误），DML 受影响行数卡片、错误详情+SQL 回显；新=单一结果集覆盖式。
4. **结果网格能力**：旧=vxe-table 虚拟滚动+列排序+列宽拖拽+单元格点击复制+7 操作符内存列筛选+内存/重放双分页（100/200/500/1000）+执行日志面板（变量快照/事务/警告，自动滚底）；新=el-table 静态+基础分页（50/200/1000）。
5. **元数据树交互**：旧=库→Tables/Views→表→列懒加载 + 列悬浮富 Tooltip（复制字段名）+ **表/视图悬浮菜单 11 项**（查询/编辑数据/DDL/行数/建列/建索引/CSV 导入/删除截断×稽核）+ 库单击切命名空间；新=五级契约树（含例程/索引/能力降级标签）但无右键/悬浮菜单/双击插入。
6. **高危操作防护与数据编辑**：旧=drop/truncate 稽核校验硬阻断、编辑数据事务弹窗（增删改≤1000 行、失败整体回滚）、CSV 导入（≤10 万行、列映射、预览）；新=全无。
7. **变量联动**：旧=`${` 补全 + hover 现值 + 未定义参数警告条 + 执行日志变量快照 + env 三环境切换贯穿补全/执行；新=无任何变量感知。
8. **历史与导出**：旧=历史抽屉（过滤/分页/逐语句详情含变量快照/编辑载入/再执行/删除）+ 导出弹窗（全部后端重放 csv/json/xlsx / 筛选子集前端生成）；新=仅只读历史表 + 回看快照，导出未接线。
