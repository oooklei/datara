## 三、迁移语义逐行照抄

```
publish(model_id):
  m = get(DwModel, model_id)          → None 即 8001/404
  if m.status != "draft":             → 8005/409「仅草稿可发布」
  m.status = "published"              # version 不动
  commit; return {"status": "published"}

redraft(model_id):
  m = get(DwModel, model_id)          → None 即 8001/404
  if m.status == "draft":             → 8005/409「当前已是草稿」   ← 闸方向与 publish 相反
  m.status = "draft"; m.version += 1  # 回草稿必递增
  commit; return _model_row(m, _xc_map(db))   ← 出参为 ModelRow
```

**三处照抄要点**：

1. **状态闸方向相反**：`publish` 拦非 draft（`!= "draft"`），`redraft` 拦 draft（`== "draft"`）。
   二者构成互逆闸门；用例 10 断言 `publish` 后 `redraft` 可通行、`redraft` 后再 `publish` 闸门重开（往返）。
2. **`publish` 不改 version，`redraft` 必递增 version**：两票对 `version` 的作用**有意不同**（旧侧原样）。
   用例 4 断言 publish 前后 `version == 4` 不变；用例 6/10 断言 redraft 后 `version` 递增。
3. **出参形状不同**：`publish` 返回 `{"status": "published"}`；`redraft` 返回完整 `ModelRow`（16 键，
   含 `id/code/name/.../remark`）。用例 6 逐键断言 `set(data)` 恰为 ModelRow 键集，非 `{"status": ...}`。

### 3.1 旧侧 `built`/`produced` 态在 publish 下的行为（候核）

`publish` 闸为 `status != "draft"` → `built`/`produced` 亦返回 8005「仅草稿可发布」（用例 4 三态覆盖）。
此与 A6-8 删除闸 `status in ("built","produced")`（允许 `published` 通过）**口径不同**，
亦与 A6-9 字段保存闸 `status != "draft"` **相同**。三处闸口径汇总见 §六候核①。

## 四、路由可达性（三段子路由，与 17.2-07 吞并风险无关）

`/models/{model_id}/publish`、`/models/{model_id}/redraft` 均为**三段**路径。
Starlette 按**段数**匹配，两段的 `/models/{model_id}` 与 `/models/er` 不可能吞并三段请求。

- 真正可吞并三段的只有「末段为**路径参数**的同段数路由」（如 `/models/{model_id}/{sub}`），
  当前 `rebuild/model/` 内**不存在**此类路由。
- 用例 11 据此断言：① 三条三段路由（A6-9/10/11）均已注册；② 各自之前**无末段为 `{...}` 的同段数路由**；
  ③ 行为验证 `publish` / `redraft` 互不串味（published → redraft 得 `draft`；
  draft 再 redraft → 409/8005；draft → publish 得 `{"status":"published"}`）。
- **勘误（自披露）**：本批用例初版将 `rivals` 过滤写成「同段数且路径不同」，
  误把 `/fields` 与 `/redraft` 互计为吞并者（字面尾段不同则永不匹配）。已修正为「末段以 `{` 开头」，
  `test_model_fields_api.py` 同形过滤一并修正（17.2-09 证据 §四原述「同段数路由」有歧义，以本版为准）。
