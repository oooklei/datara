### 公共契约

- **响应信封**：所有端点统一返回 `{code: 0, msg: "success", data: ...}`，实锚 `datara-backend/common/resp.py` 的 `ok()` 函数。
- **错误信封**：`{code: int, msg: string, data?: any}`，`code` 为业务错误码，`msg` 为可读消息。
- **时间格式**：本地时间字符串 `YYYY-MM-DD HH:mm:ss`，实锚 `common/resp.py` 的 `fmt_dt()`。
- **鉴权**：旧侧 `api.auth.get_current_user`（读）/ `require_perm("model:write"|"edit_definition")`（写）；Token 从 `token` header、Bearer header 或 query token 读取，查 Redis token 与 `t_user`。
- **新后端鉴权**：`rebuild.identity.contracts.TokenService` 令牌体系，`REBUILD_TOKEN_SECRET` 签名，`ActiveTokenRecord` 持久化。
- **路由前缀**：旧侧统一 `/api/v1`；新侧通常 `/api/v1/rebuild/...`（最终路径待冻结）。
