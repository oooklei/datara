## 二、语义逐行照抄（`api/model.py:466-481`）

```
m = _get_model(db, model_id)                 → None 即 8001/404（内置 msg）
if not engine:                               # ① 缺省（空串）才解析
    row = db.get(EngineType, m.engine) if m.engine else None
    ddl_id = row.ddl if row and row.ddl else "mysql"
else:
    ddl_id = engine                          # ② 显式 query 直接覆盖
fields = _fields_of(db, model_id)            # ③ 按 seq 升序
try:
    ddl = gen_ddl(m.code, m.name, fields, ddl_id)
except ValueError as exc:
    raise ApiError(MODEL_CODE_INVALID, str(exc), status=400)   # ④ msg = 异常原文
return ok({"engine": ddl_id, "ddl": ddl, "notes": dialect_notes(fields, ddl_id)})  # ⑤ notes 在 try 之外
```

**五处照抄要点**：

1. **`engine` 缺省的四态回退**（`engine` 为空串时才查字典；`m.engine` 空串则**不查**直接 `"mysql"`）：
   | 情形 | 旧侧取值 | 用例 |
   |---|---|---|
   | 字典行存在且 `ddl` 非空 | `row.ddl` | `test_ddl_default_engine_resolves_from_model_engine` |
   | 模型 `engine` 为空串 | `"mysql"`（不查字典） | `..._when_model_engine_blank` |
   | 字典行不存在 | `"mysql"` | `..._when_engine_row_missing` |
   | 字典行存在但 `ddl` 列空 | `"mysql"` | `..._when_ddl_column_blank` |
   显式 `engine` query 覆盖模型映射 → `test_ddl_explicit_engine_overrides_model_engine`。
2. **`fields` 按 `seq` 升序**（`_fields_of` → 本侧 `_field_row` 同口径）。
3. **`ValueError` → 8003/400 且 msg 为异常原文**（**不**用 8003 内置文案）。旧侧 `ApiError` 四元组由本侧 `ModelDomainError(code, message, status)` 承载，`message=str(exc)` 显式传入。
4. **`dialect_notes` 在 `try` 之外调用**：`engine` 非法时先被 `gen_ddl` 的 `ValueError` 拦下（8003/400），永远到不了 `dialect_notes`（旧侧同序）。
5. **不落库**：出参 `{engine, ddl, notes}`，**不写任何表** —— 不更新 `last_ddl`、不改 `status`、不动 `version`、不新增版本快照行。用例 `test_ddl_does_not_persist_any_state` 逐项断言（`status=="published"` / `version==3` / `last_ddl is None` / `built_at is None` / 快照行数 0 / 字段不变）。
