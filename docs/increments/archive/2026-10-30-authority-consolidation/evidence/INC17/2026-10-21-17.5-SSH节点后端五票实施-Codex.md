## 交付

1. `GET /api/v1/rebuild/ssh-nodes`：按 id 升序列出节点，迁移期继续回显完整 `cred`。
2. `POST /api/v1/rebuild/ssh-nodes`：空名/空 host 映射 HTTP 400/code 4103；名称预查重与数据库唯一约束双校验，竞态稳定映射 HTTP 409/code 4102。
3. `PUT /api/v1/rebuild/ssh-nodes/{node_id}`：请求体全量覆盖；不存在为 HTTP 404/code 4101；重名竞态同上。
4. `DELETE /api/v1/rebuild/ssh-nodes/{node_id}`：返回 `true`，保持不查询工作流 `execNodeTag` 引用的冻结行为。
5. `POST /api/v1/rebuild/ssh-nodes/{node_id}/probe`：Paramiko 即时 `echo ok`，不写 `heartbeat_state/last_seen`。

统一响应为 `{code,msg,data}`。4101～4103 在 sshnode 域内显式定义，未从 `common/resp.py` 导入（R2/R-32）。

## 鉴权与权限映射

五个端点均先经 `TokenService.verify`，校验 active-token 且拒绝 capability token，再逐端点调用 `authorize`：

| 操作 | 权限 |
|---|---|
| list | `VIEW_ALL` |
| create | `EDIT_DEFINITION` |
| update | `EDIT_DEFINITION` |
| delete | `EDIT_DEFINITION` |
| probe | `EDIT_DEFINITION` |

## 已登记风险

- R-34 要求迁移期完整回显 `cred`；这是明确安全债，后续掩码化/加密票会形成破坏性契约变更。
