## 二、技术要点

1. **路由与目录落位**：E 组 8 个菜单路由继承旧框架——`/meta/lineage`、`/meta/map`、`/meta/catalog`、`/meta/tag`、`/std/element`、`/ind/list`、`/ind/board`、`/ind/consistency`（权威设计 §4.2 L319）；质量五项 5 路由 `/qc/rule`、`/qc/task`、`/qc/exception`、`/qc/report`、`/qc/alarm`（§4.3 #3-7，L333-337）。页面目录 `src/views/meta/**`、`src/views/std/**`、`src/views/ind/**`、`src/views/qc/**`（WBS L423）。
2. **全部治理端点为 project-scoped**：路径均含 `/projects/{project_id}/...`（例外：`POST /legacy/i23/identity-preview` 无前缀，L495，属运维链路，前端不消费）——页面数据面强依赖增量 3 项目上下文层（§5A.11，`/p/:projectId/...` 工作区挂载）。
3. **两域鉴权形态不同，契约层须分型**：
   - governance 域：`Authorization` Bearer header 单鉴权（api.py L1770 `authenticate(authorization)` + project_permission 链）；
   - metrics 域：`token` + `authorization` 双 header + 独立 `project_authorize` 回调（metrics/api.py L45-51/L59-72）；metricsApi 契约已按此实现，governanceApi 新契约照 governance 形态对齐 T58r 经验即可。
4. **包络三态全域适用**：governance/metrics 响应均为 `{code,msg,data}`（api.py `fail(...)`/`{"code":0,...}`；metrics/api.py L74-75 `respond`）——`adapterKit.unwrapEnvelope` 冻结原语直接复用（权威设计 §5.4 L442-451；CONTRACT_REGISTRY.md L24）。
5. **血缘图数据形态**：GET lineage 返回 `{asset_id, direction, depth, nodes[...], edges[...]}`（api.py L1599-1611），服务端 BFS 控深（1-10，默认 3）——前端图组件按 nodes/edges 渲染即可，无需前端递归拉取。
6. **质量执行语义**：run 端点为**结构校验型**（expression 危险关键字扫描 → status succeeded/failed，行级四字段恒 0，engine=structural，api.py L1782-1802）——质量规则页「执行」按钮的错误态/结果态设计须如实呈现 structural 语义，不得虚构行级结果。
7. **metrics 域窗口语义**：6 端点统一 `TimeWindowRequest`（from/to/offset/limit + project_id，window_guard 校验，metrics/api.py L59-72）——指标看板页查询控件按窗口参数建模。
8. **契约落位建议**：11 冻结契约中 metricsApi 已覆盖指标看板/异常样本/质量规则链接/血缘回写（CONTRACT_REGISTRY.md L18）；**新增契约候选清单**：
   - `governanceApi.ts`（单文件，域对齐后端 router）：assets（列表/详情/资产 tags 读）、lineage（建边/图查）、standards（CRUD + check）、governance metrics（指标目录 CRUD）、quality-rules（CRUD + run + quality-runs 查询）、tags（建标 + 打标）、audit 查询——页面消费子集封装，非 28 端点全量照搬；
   - 标签定义列表（若裁定后端补 GET /tags）追加方法；
   - 一致性检查 / 质量报告 / 质量告警端点待裁定后再扩契约，RED 登记进 CONTRACT_REGISTRY 口径。
   - 落位 `datara-newweb/src/services/rebuild/`（复制准入后），每契约配 `*.contract.test.ts` 对齐 CI 门禁（CONTRACT_REGISTRY.md L28-33）。

## 四、风险与开放问题

### 4.1 裁定项单列（⭕ 用户/监督线裁定后 14.3、14.4 批 B 方可派票）

- **Q1 一致性检查承载**：I3/I9 出处已登记（§3.3 L250），但 governance 域无跨源一致性比对端点。候选：① 以 quality-rules + 绑定数据源行级执行承载（依赖 T58r 遗留① 行级采样补齐，属后端能力增量）；② 新建模独立端点。**建议监督线裁定语义归属后拆「后端票+前端票」**。
- **Q2 质量报告**：无报告端点。候选：前端聚合 quality-runs 明细呈现（零后端改动，但「报告生成」语义打折）vs 后端报告生成/查询端点新建模。影响 14.4 批 B 验收口径。
- **Q3 质量告警**：无告警端点；旧 `/dep/alarm` 已判删除（§4.3 #17）。质量告警页（`/qc/alarm`）承载面待裁定——是否复用质量规则 failed 结果作告警源、是否需告警规则/通知新建模。
- **Q4 标签定义列表 GET 缺口**：28 端点无 `GET /tags`（仅建标 L1446/打标 L1482/资产内嵌 tags L1280）。候选：前端经 assets 列表聚合先行 vs 后端补一个小端点（改动面小，governance 域内）。**建议补端点**（标签管理页主查询不应依赖聚合）。
- **Q5 检查任务深度**：现语义为「规则执行实例」（quality-runs）。若产品语义要求独立任务定义（批量调度/周期检查），需后端建模——建议 14.4 验收时按现语义收口并登记结论，不自行扩模。

### 4.2 实施风险

- **R-A 鉴权分型混淆**：governance（Bearer 单 header）与 metrics（双 header）形态不同，governanceApi 契约若照抄 metricsApi 鉴权封装会 401——契约测试须分别锁形。
- **R-B structural 执行语义误导**：run 端点行级统计恒 0（api.py L1790-1793），前端结果展示若渲染为「0 行检查通过」会误导用户——须按 `engine=structural` + summary.message 呈现能力边界。
- **R-C 端点 409/404 错误态覆盖**：run 守卫 404（规则不存在/跨项目）/409（disabled、持久化失败）（api.py L1779-1781/L1818）、i22 导入 409（悬挂引用 blocked，T58r §三 L50）——页面错误态设计须逐码覆盖，契约测试断言。
- **R-D audit 端点归属澄清**：`GET /projects/{id}/audit`（L1945）为治理操作审计查询，非 G 组「访问审计」页（后者 ⭕ 待裁 §4.3 #11）——E 组页面不应把该端点当作访问审计页数据源，避免红线 2 出处错位。
- **R-E 交付口径**：E 组退出标准要求「13 项页面全部可达且各自查询→展示闭环」（WBS L436）——3 项待裁项（#8/12/13）在裁定前无法闭环，增量整体退出标准受 Q1-Q3 裁定进度牵制，须在派票计划中显式排布。

## 六、已交付资产衔接点（T58r 经验引用）

T58r-gov-p0（`docs/increments/evidence/GOV/2026-10-20-T58r-gov-p0收口与补码.md`）为 Trae 线对 governance 域第一手经验，以下衔接点供 14.4-A 及契约层实施直用：

1. **执行端点契约形态**：POST run 201 返回 `{asset_id, **quality_run_payload(run)}`；守卫 404（不存在/跨项目）/409（disabled）；审计 action=`quality_rule.run`（T58r §二表格 L18-27）。质量规则页「执行」交互与错误态设计按此契约锁定。
2. **测试口径迁移**：后端侧 `tests/rebuild/test_governance_api.py` 3 例 run 测试（执行持久化/危险表达式 failed/守卫 404+409，T58r §二 L29-33）可作为前端契约测试错误态分支的对照口径；全量回归基线 870P/1S/0F（T58r §四 L61）。
3. **导入链路口径**（标准管理页若暴露导入入口）：idempotency_key 必填（缺失 422）+ source_digest sha256 防篡改 + 悬挂引用 409 blocked（T58r §三 L49-51）——governanceApi 标准导入方法契约须保留这三态。
