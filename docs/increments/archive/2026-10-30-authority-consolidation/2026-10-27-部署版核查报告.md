### 2.2 确认 BUG（代码级根因 + 证据）

**B-1 [高] DAG 三栏窄屏塌陷**（对应 H1）
- `WorkflowGraphWorkbench.vue` 全文 860 行 **0 个 `@media`**；三栏 flex 恒横排，左右栏 `flex:0 0 var(--dag-left/right)`（L796-839）不可收缩，唯一可收缩项为画布 `.wf-flow{flex:1}`（L832-836）
- `theme.css` 无任何宽度断点（全库断点散落 560/680/760/767/900/1100/1180 私有断点；评审 1024/768 档无实现）
- 计算：610−232(左)−340(右)−12(分割条) ≈ 26px，与 H1 精确吻合

**B-2 [高] 页内项目选择器是"死控件"，路由级切换也不刷新**（对应 H2，全域性）
- `projectId` computed 优先级 prop>路由>页内 selected（`IdeView.vue:420-426`）；全文件唯一 watch 是 sqlText（L797）——页内切换只改 selected，reload 恒取旧 projectId
- **`/p/1/ide → /p/33/ide` 同路由记录（`project-segment`）组件实例不销毁、无 `:key`、无 watch**，路由级切换同样不重载
- 同构 `data-project-select` 旧壳复制于 **18 个视图**（qc×5 / ind×3 / meta×4 / std / datasource / ide / resources / sec），问题全域存在
- 附注：SqlCodeEditor 存在**隐形 textarea 测试桥**（`data-sql-editor`，L61-67，1px clip 隐藏），自动化选择器易误判；契约测试仅做源码文本断言（`ideUxV3.contract.test.ts:11-12`），测试绿而运行时不可见

**B-3 [中] 节点堆叠**（对应 H6）
- `@dagrejs/dagre@3.1.1` 已装全库零引用；服务端回读 `positionX ?? 0` 全堆 (0,0)（L154）；新增节点纵向步进 48px < 节点高（L268-269）

**B-4 [中] IDE 对象树空态一票否决**（对应 H3）
- schemas 为空数组时整个分区 `v-if="schemas.length"` 直接消失，无空态/加载态/错误内联（`IdeView.vue:58-64`，各级分区同构）

**B-5 [低] 组件 spec 请求无取消/去重**（对应 H4）
- Palette 已有 AbortController 范式（`Palette.vue:98-123`）；Workbench `loadPaletteSpecs` 无 signal、每次 `onActivated` 重复请求（L288-299, 407）。ERR_ABORTED 为 Palette abort 中止在途 fetch 所致

**B-6 [低] 导出/取消半成品**
- 导出仅创建记录展示 exportId，`getExportDownloadUrl` 契约已备未消费（`IdeView.vue:752-753`）；"取消执行"仅置标记，`getSqlIdeExecutionStatus` 未消费

**B-7 [低] 窄屏无退出入口**
- <768px `.logout-button{display:none}`（`AppShell.vue:233`）

### 2.4 残留与债务

1. **双变量管理面并存**：IDE 用 `VariableManagementDialog`（仅 list+upsert，无删除/校验/现时值）vs 任务中心用 `VariableManagerDrawer`（含 delete + env 域）——能力不一致、modal/drawer 范式冲突
2. **E 组 18 页同构旧壳**：`routeProjectId` 三连复制（QualityRule/MetadataCatalog/LineageAnalysis 逐行同构）、无共享抽象——「状态态式不统一」的结构性成因
3. **死依赖**：`monaco-editor@0.57.0`（src 零引用）
4. **演示账号明文密码硬编码**登录页（`LoginView.vue:12-21`）
5. **e2e 编译产物双份**：llm-models/qc/sshNode 的 .spec.js 与 .ts 并存
6. **契约测试盲区**：uxV3 系测试为源码文本断言非运行时 DOM 断言
7. **token 仅内存**（`http.ts:40-41`，有意安全设计）与刷新丢会话体验冲突；`datara_token` 旧 key 保留仅作擦除；命名混用（`datara.theme` 点分隔 vs `datara_token` 下划线）
8. **Workbench spec 请求**与 Palette 双轨请求同一端点，未共享缓存
