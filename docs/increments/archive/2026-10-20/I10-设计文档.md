## 4. 后端 API（i10-1 基座 / i10-2 执行架构 / i10-3 表操作）

### 4.1 数据源扩展（api/datasource.py）

| 端点 | 说明 |
|---|---|
| `GET /datasources/{id}/meta` | G2：`SELECT VERSION()`、`@@transaction_isolation`、默认 Schema（ds.db_name）、执行超时（常量 60s）；连通失败返回明确错误 |
| `GET /datasources/{id}/databases` | G7：SCHEMATA 列表（过滤 information_schema/mysql/performance_schema/sys） |
| `GET /datasources/{id}/databases/{db}/tables?kind=table\|view&keyword=&limit=200` | G7：TABLES 按类型+keyword（服务端 LIMIT 防大 schema） |
| `GET /datasources/{id}/databases/{db}/tables/{tb}/columns` | G7/G9：COLUMNS 全元信息（name/dataType/length/nullable/key/comment/extra），一次给树与 hover 共用 |

### 4.2 执行架构重构（api/ide.py）

- **POST /ide/execute（改异步）**：body=`{datasourceId, db, sql, mode: auto|manual, txnAutoCommit}`（行上限设置已按裁定删除，返回行数由用户 SQL 自带 LIMIT 控制）；驻留层 `SCREEN_ROW_CAP=2000` 兜底截断、rowsTotal 全量计数；校验后创建任务 `taskId=uuid4().hex` → 内存注册表 `IDE_TASKS`（含状态/事件 Queue/连接/`CONNECTION_ID()`）→ 交 `ThreadPoolExecutor(max_workers=5)` 立即返回 `{taskId}`。并发超限返回 429。
- **执行线程**：单连接逐条执行（I4 语义不变：失败即停、前序结果保留）；渲染变量 → 执行 → `SHOW WARNINGS` 收集 → 结果首屏行（≤SCREEN_ROW_CAP=2000）与元信息入事件队列；历史落库含 log_text/affected_total，并补 `rendered_sql`（渲染变量后全文，分页重放/导出统一使用；存量历史回退 sql_text）。
- **GET /ide/stream/{taskId}（SSE）**：`StreamingResponse(text/event-stream)`；事件：`log`（语句开始/结束/错误/警告/变量快照明文）、`result`（单语句结果元信息+首屏行）、`done`（status/elapsedMs/historyId）；3s 心跳注释行防代理断连。
- **POST /ide/cancel/{taskId}**：置 cancel 标记 + **独立短连接**执行 `KILL QUERY <thread_id>`；执行线程捕获异常退出，状态=canceled，落库（G21 停止）。
- **事务模式（G22）**：auto=逐语句自动提交；manual=连接 `BEGIN` 起步，全成功 `COMMIT`、任一失败 `ROLLBACK`，SSE 推送事务终态。选中片段执行=前端仅提交选中文本，后端无感知。
- **变量渲染（G4）**：`common/vars_render.py` = 从 master/variables.py 抽取 `${var}` 正则渲染核心 + 内置时间参数 14 项（biz_date 默认 T-1、today、`date(N)` 函数式、month_start/end、last_month_start/end、lyear、hour、timestamp、`yyyyMMdd_HHmmss` 命名模式）；来源=全局参数（t_global_param by env）+ 内置项；`$[...]` 引擎语法保留兼容；引擎侧改为调用同一模块（行为不变，回归门覆盖）。
- **POST /ide/lint（G13）**：sqlglot.parse（方言 mysql）逐语句返回 `{stmtIndex, ok, error, line, col}`；前端防抖调用映射 Monaco markers。
- **GET /ide/result/{historyId}/{stmtIndex}?offset=&limit=**：G18 分页——按语句序号重放取 offset 段（复用导出重放链路）；重放源=hist.rendered_sql or hist.sql_text（存量回退原始 SQL）；一期口径：重放可能页间漂移（非确定性查询），文档标注。
- **历史端点**：`GET /ide/history/{id}`（全文 SQL+log_text 解析返回）、`DELETE /ide/history/{id}`（G5）；列表 payload 增 affectedTotal。
- **脚本 CRUD（G16）**：`GET/POST/PUT/DELETE /ide/scripts`（user_id 过滤 + name 唯一）。

## 8. 风险与部署注意

- **Monaco worker + Vite**：用官方 `?worker` 导入配置（不引第三方插件，减依赖风险）；IdeView 已是懒加载 chunk，bundle 增量不影响首屏。
- **SSE 过 nginx**：1.9 nginx.conf 需对 `/api/v1/ide/stream` 加 `proxy_buffering off; proxy_read_timeout 3600s;`——随 i10-5 部署一并改。
- **KILL QUERY**：必须在独立连接上执行；连接线程 ID 执行开始时 `SELECT CONNECTION_ID()` 记录。
- **分页重放漂移**：非确定性查询（无 ORDER BY）页间数据可能重复/缺失，一期接受并在 UI 提示。
- **引擎回归**：variables.py 下沉 common 后，I3 调度链变量渲染行为必须回归（跑一条含变量的工作流实例对照）。
