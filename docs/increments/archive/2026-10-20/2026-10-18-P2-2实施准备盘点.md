- **SqlExecutionPort**：注入式执行端口（Protocol），无生产实现（已登记缺口）

- **生产装配**：默认 `create_app` 不挂载桥（fail-closed），生产工厂装配随 R5-A 落地

## 4. 已登记缺口（不得声称已保障）

1. **无生产 SqlExecutionPort**：执行端口是 R5-A seam 后的 PoC 实现，生产 executeSql 端口另行装配
2. **DB 侧 layer-2 只读未落地**：仅 SQLite URI `mode=ro` 作纵深演示；只读账户/事务/最小权限未配置
3. **PoC 审计 writer ≠ 生产 writer**：PoC 用独立 SQLite durable writer；生产 DB-backed writer 属 R5-A/P2-2 范围
4. **PoC 工厂 ≠ 生产工厂**：PoC 经注入修正版工厂；生产 adapter 默认工厂已修复（10069ac）

## 5. P2-2 实施准备方向（冻结生效后）

1. **生产 SqlExecutionPort 装配**：实现 R5-A executeSql 端口，替换 PoC 端口
2. **DB 侧只读落地**：只读账户/事务/最小权限配置
3. **生产审计 writer**：DB-backed writer 替换 PoC SQLite writer
4. **生产工厂装配**：默认 `create_app` 挂载桥 + 生产端口
5. **P2-1 契约冻结生效后**：按 C1/C2/C3/C4/C5/C6 裁定实施 R5-A 语义
