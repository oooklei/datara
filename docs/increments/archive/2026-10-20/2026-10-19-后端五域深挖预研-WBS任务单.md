# 后端五域深挖预研 → WBS 任务单

> **产出时间**：2026-10-19
> **产出者**：监督员（5 个子智能体并行预研汇总）
> **对标基准**：`docs/increments/2026-10-19-纠偏重构前端权威设计.md` + 设计正本
> **目标**：后端功能全部实现并有效，为前端权威设计做扎实的基础支撑

## 一、预研方法

5 个子智能体并行只读预研，按后端域分工：
1. **工作流域**（WF）：定义/版本/发布/实例/草稿快照
2. **SQL IDE 域**：R5-A 501桩 + R5-B DDL + 端点挂载
3. **AI 助手域**：R8-A 八工具 + R8-B + LLM 端点
4. **SYNC/STREAM 域**：新域契约 + 流表模型 + 消费运行时
5. **运行实例域**：EXEC/RT/T33 fencing + 运行表六表

每个子智能体实读代码文件 + 对标权威设计，产出 WBS 任务单。
