## 2. 数据库表（3 张新表，含 create_time/update_time）

| 表 | 字段 | 说明 |
|---|---|---|
| `t_meta_table_ext` | id PK / ds_id / db_name / table_name / biz_domain / security_level(String16 默认'内部') / owner / remark；UniqueConstraint(ds_id, db_name, table_name) | 表级标注扩展；security_level 与 t_dw_model.security_level 同口径（sec 模块后续统一消费） |
| `t_meta_tag` | id PK / name(String64 unique) / cat(String16：重要性/用途/标准/安全/质量) / color(String16) / desc(String255) | 标签定义，5 分类对齐原型 |
| `t_meta_tagging` | id PK / tag_id / target_type(String16：table/field/model) / target_key(String255) / created_by；UniqueConstraint(tag_id, target_type, target_key)；Index(target_type, target_key) | 打标关系。target_key 规范：table=`{ds_id}/{db}/{tb}`；field=`{ds_id}/{db}/{tb}/{col}`；model=`model/{model_id}` |

## 3. 后端 API（/api/v1 前缀，ok()/ApiError 规范）

### 3.1 目录

```
GET  /meta/catalog/tree                     # 数据源→库→表 树（连接型数据源；内省结果缓存 60s）
                                            # 模型节点挂在「数仓模型」虚拟根下，带「模型」徽标
GET  /meta/catalog/tables?ds=&db=&keyword=&layer=&domain=&tag=&level=&page=&size=
                                            # 统一清单：内省表 ∪ 模型（合并同物理表，带「已建模」徽标）
                                            # 附 ext 标注 + 标签聚合 + 分层推导 + facet 计数
GET  /meta/catalog/table/{key}/detail       # {key}={ds_id}/{db}/{tb} 或 model/{id}
                                            # 五段：overview（列数/行数/注释/ext）/fields（内省∪模型字段）
                                            # /sample（复用 meta_ops rows，limit 100，仅连接型）
                                            # /lineage（复用现有 lineage API 合并图）/tags
PUT  /meta/catalog/table/{key}/ext          # {biz_domain, security_level, owner, remark} 全量保存
```

### 3.2 标签与打标

```
GET    /meta/tags?keyword=&cat=             # 列表（含已打标计数 cnt，实时聚合 taggings）
POST   /meta/tags                           # 新建（name 唯一，409 冲突）
PUT    /meta/tags/{id}                      # 编辑
DELETE /meta/tags/{id}                      # 删除（级联清 taggings）
GET    /meta/taggings?tag_id=&target_type=&target_key=
POST   /meta/taggings                       # {tag_ids[], target_type, target_key} 全量设置（差量增删）
```

### 3.3 资产地图

```
GET  /meta/map?view=overview|layer|domain|category&layer=&domain=&category=&limit=
                                            # {stats, nodes, edges}
                                            # stats：数据源/库/表/模型/标签 计数卡
                                            # nodes：表/模型（分层/业务域着色）；edges：t_dw_model_relation ∪ t_lineage_edge（按 code 匹配）
                                            # limit 防爆（默认 200 节点，超出按度数截断并提示）
```

### 3.4 权限

- `ROLE_PERMS` 增补 `meta:write`（admin/dev）；标注/标签/打标写操作注入；读登录即可
- 业务域标注交互沿用逆向导入惯例：输入框显示上次使用业务域，Tab 快填，最近使用下拉

## 5. 关键规则

- **分层推导**：内省表按前缀 ods_/dwd_/dws_/ads_/dim_ 推导（与 meta_ops _SYSTEM_PREFIXES 同源规范），无前缀=未分层
- **目录唯一键**：`{ds_id}/{db}/{tb}`；模型 `model/{id}` 独立命名空间；同一物理表已被模型登记时合并为一行并带「已建模」徽标，详情页签内可跳转模型
- **样本预览无脱敏**（R3）
- 内省缓存：进程内 TTL 60s（key=ds_id+db），标注/打标不依赖缓存实时性

## 6. 错误处理

| 场景 | 处理 |
|---|---|
| 数据源连接失败/超时 | 树节点标红+重试，不影响其他数据源渲染 |
| 内省超时 | 60s（对齐 meta_ops READ_TIMEOUT） |
| 标签重名 / 并发标注冲突 | 409 提示刷新 |
| 文件型数据源请求样本/内省 | 400 仅连接型支持 |
| 大库内省性能 | 树按库懒加载；清单强制分页；地图节点 limit 截断 |
| 打标对象已不存在（表被删） | 保存时校验，失效 tagging 清理并在响应中提示 |
