## 1. 契约范围与冻结效力

- 冻结对象：八工具逐一（§7）+ 统一调用信封（§2）+ 权限上下文（§3）+ 审计字段（§4）+ 错误码空间（§5）+ 超时/重试/预算策略（§6）。
- 冻结不包含：真实 LLM 接入、悬浮助手 UI 实现（R8-B）、假 Agent 测试与悬浮助手测试页的**实现**（其以本文契约为输入，属 GREEN 前证据）。
- 版本规则：`tool_version: 1`；契约级变更（字段增删、语义变化、错误码增删、策略数值调整）必须再冻结并递增版本。

## 2. 统一调用信封（传输面）

### 2.1 端点

| 端点 | 方法 | 用途 |
|---|---|---|
| `/api/v1/rebuild/ai/tools` | GET | 工具注册表发现（返回 §2.4 条目数组） |
| `/api/v1/rebuild/ai/tool-calls` | POST | 统一工具调用入口（信封路由至注册表 handler） |

单一调用端点是「统一执行/校验链路」的传输面落点：权限校验、审计落库、预算管控、错误归一均在信封层统一实现，handler 不得绕过。

### 2.2 请求信封

```json
{
  "tool_call_id": "string（FE 生成，ULID/uuid，幂等与追踪键）",
  "tool": "search_schema | validate_sql | run_sql | get_workflow | validate_workflow | inspect_workflow_run | get_task_metrics | get_lineage",
  "tool_version": 1,
  "params": { "…每工具独立 schema，见 §7" },
  "page_context": {
    "context_type": "PROJECT | WORKFLOW | NODE | SQL | DATASOURCE | VARIABLE | RUN | METRICS | METADATA | LINEAGE",
    "context_ref": "object（按 context_type 携带对应实体标识，§11 十类；可为 null——悬浮入口无页面上下文时）"
  }
}
```

### 2.3 响应信封

```json
{
  "tool_call_id": "string（回显）",
  "tool": "string（回显）",
  "tool_version": 1,
  "status": "SUCCESS | ERROR",
  "result": { "…成功时按工具 §7 返回结构" },
  "error": {
    "code": "§5 错误码",
    "message": "string",
    "details": "object（可选，结构化错误明细）",
    "retryable": "boolean（FE 重试决策唯一依据）"
  },
  "audit_id": "string（本次调用的审计记录 ID，成功与失败均返回）",
  "server_time": "ISO-8601（数据库生成时间戳）"
}
```

### 2.4 工具注册表条目（GET /tools 返回项）

```json
{
  "name": "string",
  "version": 1,
  "description": "string",
  "enabled": "boolean",
  "required_permissions": ["权限点（词形待 N-C 冻结面，§8）"],
  "timeout_ms": 10000,
  "retry_policy": { "max_attempts": 2, "backoff_ms": 500 },
  "budget": { "…见 §6" }
}
```

## 3. 权限上下文

信封层由 Backend 注入并校验，FE 只读不自行断言：

```json
{
  "user_id": "string",
  "roles": ["ADMIN | DEVELOPER | OPERATOR | VIEWER"],
  "project_id": "number（调用目标项目）",
  "granted_permissions": ["string（本次调用经校验通过的权限点列表）"]
}
```

- 四角色词形锚设计正本 §13.4；权限点枚举词形为 N-C（P2）冻结面，本文仅冻结「`required_permissions` / `granted_permissions` 字段存在且为权限点字符串数组」这一结构，不冻结具体权限点词形（§8 联动）。
- 权限不足统一返回 `PERMISSION_DENIED`（retryable=false），不泄露存在性信息差异（无权与不存在同码，details 仅记 audit 侧区分）。

## 4. 审计字段

每次工具调用（成功与失败）写一条审计记录，字段冻结如下：

| 字段 | 类型 | 说明 |
|---|---|---|
| audit_id | string | 主键（ULID/uuid） |
| tool_call_id | string | 请求信封回链 |
| tool / tool_version | string / int | 工具标识与版本 |
| user_id / roles / project_id | — | 权限上下文快照 |
| request_payload | jsonb | **请求参数全量原值快照**（Q11 裁定：业务数据敏感值忠实原值，不脱敏、不打码；内部系统审计可追溯优先） |
| outcome | SUCCESS \| ERROR | 调用结果 |
| error_code | string? | 失败时 §5 错误码 |
| started_at / finished_at | timestamp | **数据库生成时间戳**（§13.13/客户要求 #8） |
| latency_ms | int | 服务端耗时 |
| budget | jsonb | 实际预算消耗（rows_returned / truncated / timeout_ms 等） |
| refs | jsonb | 关联实体 ID（execution_id / run_id / workflow_id / datasource_id 等，按工具） |

红线：审计不替代各域业务日志；`run_sql` 的 SQL 执行另受执行域自身审计约束（统一执行链路附带），本文 `request_payload` 快照为工具调用层最低保真要求。

## 5. 错误语义（统一错误码空间）

| 错误码 | 层级 | 语义 | retryable 默认 |
|---|---|---|---|
| TOOL_NOT_FOUND | 信封 | tool 不在注册表 | false |
| TOOL_VERSION_MISMATCH | 信封 | tool_version 与注册表不符 | false |
| TOOL_DISABLED | 信封 | 工具被禁用 | false |
| INVALID_PARAMS | 信封 | 参数 schema 校验失败（details 携带逐字段错误） | false |
| PERMISSION_DENIED | 信封 | 权限上下文校验未通过 | false |
| BUDGET_EXCEEDED | 信封 | 预算策略越界（§6） | false |
| NOT_FOUND | 资源 | 目标实体不存在（project/workflow/run/datasource/lineage entity） | false |
| DEPENDENCY_UNAVAILABLE | 执行 | 下游依赖不可达（datasource 连接失败、存储不可用等） | true |
| EXECUTION_TIMEOUT | 执行 | 执行超预算超时（§6） | true（幂等工具） |
| EXECUTION_FAILED | 执行 | 执行失败（语法错、引擎报错等，details 携带引擎侧信息） | false |
| EXECUTION_CANCELLED | 执行 | 执行被取消 | false |
| INTERNAL_ERROR | 系统 | 未归类内部错误 | false |

错误归一规则：handler 抛出的域内错误必须在信封层映射为上表词形，禁止新增未登记错误码；`details` 结构按工具在 §7 定义，映射规则变更须再冻结。

## 6. 超时 / 重试 / 预算策略（§13.14）

数值为 v1 默认（冻结后调整须再冻结）：

| 工具 | timeout_ms | 重试策略 | 预算 |
|---|---|---|---|
| search_schema | 10000 | 幂等，max_attempts=2，backoff 500ms | limit≤100/页，cursor 翻页深度不限 |
| validate_sql | 10000 | 幂等，max_attempts=2 | SQL 长度≤100 KB |
| run_sql | 30000（params.timeout_ms 仅可收敛不可放宽） | **不自动重试**（非幂等，副作用风险） | row_limit≤1000（超出 truncated=true），执行时长≤timeout |
| get_workflow | 5000 | 幂等，max_attempts=2 | — |
| validate_workflow | 15000 | 幂等，max_attempts=2 | 复用统一 validate_graph 链路容量约束（不另设节点数上限，继承实现；若后续需硬上限须再冻结） |
| inspect_workflow_run | 5000 | 幂等，max_attempts=2 | include_tasks 时任务明细≤1000 条（超出 truncated） |
| get_task_metrics | 10000 | 幂等，max_attempts=2 | time_window≤90 天 |
| get_lineage | 10000 | 幂等，max_attempts=2 | depth≤5，nodes≤500（超出 truncated=true） |

- 重试由调用方（FE/假 Agent）按 `retryable` 与上表执行；信封层不代为重试。
- 预算越界在执行前拦截返回 `BUDGET_EXCEEDED`（可静态判定的项：长度/行数/深度/时间窗），执行中越界返回 `EXECUTION_TIMEOUT` 并尽力返回部分结果（工具语义允许时，如 run_sql 的部分行）。

## 7. 八工具逐一契约

> 每工具五要素：参数模型 / 返回结构 / 错误语义 / 权限上下文 / 审计要点。通用信封、错误码、权限结构、审计字段见 §2-§6，此处只列差异。

### 7.1 `search_schema` — 元数据检索

| 要素 | 契约 |
|---|---|
| 参数 | `project_id`(必填)；`keyword?`；`schema_name?`/`table_name?` 过滤；`include_columns?`(默认 false)；`limit`(默认 20，≤100)；`cursor?` |
| 返回 | `entries[]`（`kind: TABLE\|VIEW`、`schema_name`、`table_name`、`table_comment?`、`columns?[]`（name/type/nullable/comment）、`digest`）+ `next_cursor?` |
| 错误差异 | NOT_FOUND（project 不存在）；DEPENDENCY_UNAVAILABLE（元数据存储不可达） |
| 权限 | 项目元数据读 |
| 审计要点 | refs 含 project_id；budget 记 entries 数与 truncated |
| 红线 | 数据链路复用 R5-A 元数据目录（rebuild/sql_ide/metadata 同源），不另建第二套元数据服务 |

### 7.2 `validate_sql` — SQL 校验

| 要素 | 契约 |
|---|---|
| 参数 | `project_id`(必填)；`datasource_id`(必填)；`sql`(必填)；`dialect?`（缺省由 datasource 类型推导） |
| 返回 | `valid: boolean`；`issues[]`（`severity: ERROR\|WARN\|INFO`、`line`、`column`、`message`、`code`）；`lint_ref`（digest） |
| 错误差异 | INVALID_PARAMS（SQL 长度超 §6 预算）；DEPENDENCY_UNAVAILABLE（datasource 不可达） |
| 权限 | SQL 校验（编辑域权限点，词形待 N-C） |
| 审计要点 | request_payload 含 sql 原值（Q11 口径）；refs 含 datasource_id |
| 红线 | 与 R5-A `lintSql` 同一校验链路 |

### 7.3 `run_sql` — SQL 执行

| 要素 | 契约 |
|---|---|
| 参数 | `project_id`、`datasource_id`、`sql`(均必填)；`dialect?`；`row_limit`(默认 200，≤1000)；`timeout_ms`(默认 30000，≤30000 仅可收敛) |
| 返回 | `execution_id`；`columns[]`（name/type）；`rows[][]`；`row_count`；`truncated: boolean`；`duration_ms`；`sql_statement_digest` |
| 错误差异 | EXECUTION_FAILED（语法错/引擎报错，details 来自执行引擎）；EXECUTION_TIMEOUT；EXECUTION_CANCELLED；PERMISSION_DENIED（执行权限点缺失——写语义由权限点管控，契约层不区分只读/可写） |
| 权限 | SQL 执行权限点（词形待 N-C）；写操作权限点由 N-C 冻结面裁定 |
| 审计要点 | request_payload 含 sql 原值与 row_limit；refs 含 execution_id/datasource_id；budget 记 rows_returned/truncated |
| 红线 | 与 R5-A `executeSql` 统一执行链路（§11 不另建引擎）；**不自动重试**（§6） |

### 7.4 `get_workflow` — 工作流定义读取

| 要素 | 契约 |
|---|---|
| 参数 | `project_id`(必填)；`workflow_id` 与 `name` 二选一（同传以 id 为准）；`version?`（缺省=当前最新） |
| 返回 | `workflow_id`、`name`、`version`、`publish_status: 'DRAFT'\|'PUBLISHED'`（**N-A 联动**）、`node_count`、`edge_count`、`updated_at`、`latest_run?`（run_id/status/started_at） |
| 错误差异 | NOT_FOUND（工作流/版本不存在） |
| 权限 | 工作流读 |
| 审计要点 | refs 含 workflow_id |
| 联动 | `publish_status` 词形与 N-A 发布流契约同批裁定，若 N-A 裁定变化则本字段随批调整（再冻结范围仅此字段） |

### 7.5 `validate_workflow` — 工作流校验

| 要素 | 契约 |
|---|---|
| 参数 | `project_id`(必填)；`definition`（inline 图 JSON：nodes[]/edges[]）**或** `workflow_id`+`version`（二选一） |
| 返回 | `valid: boolean`；`issues[]`（`node_id?`、`edge_id?`、`severity: ERROR\|WARN\|INFO`、`code`、`message`） |
| 错误差异 | INVALID_PARAMS（definition 与 workflow_id 二选一未满足/格式非法） |
| 权限 | 工作流校验 |
| 审计要点 | inline 校验时 request_payload 含 definition 快照 |
| 红线 | 复用统一 `validate_graph` 校验链路（与定义保存路径同校验器，Backend 能力索引已锚 `wf_definition.py`） |

### 7.6 `inspect_workflow_run` — 运行记录诊断

| 要素 | 契约 |
|---|---|
| 参数 | `project_id`、`run_id`(必填)；`attempt?`（缺省=最新 attempt）；`include_tasks?`(默认 false) |
| 返回 | `run_id`、`status`（**Q9 枚举**：`queued\|running\|cancelling\|succeeded\|failed\|cancelled`）、`cancel_requested?: boolean`（**Q9 独立字段**）、`attempt_id`、`started_at`/`finished_at`、`tasks?[]`（task_id/node_id/type/status/`rows_ok`/`rows_failed`/`rows_skipped`/started_at/finished_at） |
| 错误差异 | NOT_FOUND（run/attempt 不存在） |
| 权限 | 运行记录读 |
| 审计要点 | refs 含 run_id/attempt_id |
| 联动 | 行统计三值（成功/失败/跳过）对应客户要求 #9 与 §9 统计口径；状态词形已按 Q9 裁定冻结 |

### 7.7 `get_task_metrics` — 任务统计

| 要素 | 契约 |
|---|---|
| 参数 | `project_id`(必填)；`run_id?` 与 `time_window?{from,to}` 二选一；`group_by?: 'task_type'\|'status'\|'day'` |
| 返回 | `buckets[]`（`key`、`total`、`succeeded`、`failed`、`cancelled`、`skipped`）、`p95_duration_ms?` |
| 错误差异 | INVALID_PARAMS（run_id/time_window 二选一未满足）；BUDGET_EXCEEDED（时间窗>90 天） |
| 权限 | 统计读 |
| 审计要点 | refs 含 run_id 或时间窗 |
| 红线 | 读统计四表（设计正本 §9）**不推导、不补算**（与 R7 消费侧同款红线）；collector 未接通前该工具返回 `DEPENDENCY_UNAVAILABLE`，不返回构造数据 |

### 7.8 `get_lineage` — 血缘分析

| 要素 | 契约 |
|---|---|
| 参数 | `project_id`(必填)；`entity_type: 'TABLE'\|'COLUMN'`；`entity`（`schema.table` 或 `schema.table.column`）(必填)；`direction: 'UPSTREAM'\|'DOWNSTREAM'\|'BOTH'`(默认 BOTH)；`depth`(默认 3，≤5) |
| 返回 | `root`（entity 标识）；`nodes[]`（id/type/label）；`edges[]`（source/target/kind?）；`truncated: boolean` |
| 错误差异 | NOT_FOUND（entity 不在血缘存储）；BUDGET_EXCEEDED（depth>5） |
| 权限 | 血缘读 |
| 审计要点 | refs 含 entity/direction/depth |
| 红线 | 读血缘存储**不推导**（与 R7 同款红线）；数据源复用既有血缘域（`lineage.py`/治理血缘），不另建第二套血缘引擎 |
