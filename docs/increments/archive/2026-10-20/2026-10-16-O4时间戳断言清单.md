## 1. 正本口径（逐字要点）

- L89：以下运行表**全部**必须由数据库默认生成**非空** `created_at`、`updated_at`、`generated_at`，并在 I2 的远程真实 MySQL 测试中**逐表断言**；**不得只验证其中四张**。

## 3. 「不得只验四张」红线说明

正本 L89 明确红线：**不得只验证其中四张**。即 `workflow_result_stat`、`task_instance_data_stat`（及其分段/样本表）、`workflow_instance` 等常被先验的统计四表之外，**上表 15 张运行表必须逐表、全量断言**，包括：

- 六张执行链表：`workflow_instance`、`task_instance`、`task_instance_attempt`、`task_instance_log`、`task_instance_output`、`task_instance_variable_runtime`；
- 四张统计表：`workflow_result_stat`、`task_instance_data_stat`、`task_data_stat_segment`、`task_data_error_sample`；
- 一张事件表 + 四张流运行表：`execution_event`、`stream_job_attempt`、`stream_checkpoint`、`stream_metric_snapshot`、`stream_failure_event`。

任何一张缺席，即视为 O4 未闭环；I8 建的流运行表（12-15）不得以「由 I8 建表」为由豁免，必须复用 I2 固化的时间戳迁移模板与 I9 完整性稽核（正本 L109）。

## 4. I2→R2 远程逐表断言执行步骤

1. **建立只读连接**：使用只读账号（仅 SELECT/SHOW 权限），或会话级 `SET SESSION TRANSACTION READ ONLY = 1`；全程禁止 DDL/DML，禁止写探针行到远程真实库（默认值生效断言在测试库执行，见步骤 4）。
2. **逐表结构断言**（information_schema，不动数据）：
   ```sql
   SELECT COLUMN_NAME, IS_NULLABLE, COLUMN_DEFAULT, COLUMN_TYPE, EXTRA
     FROM information_schema.COLUMNS
    WHERE TABLE_SCHEMA = DATABASE()
      AND TABLE_NAME = '<table>'
      AND COLUMN_NAME IN ('created_at','updated_at','generated_at');
   ```
   期望：三列均存在、`IS_NULLABLE = 'NO'`、`COLUMN_DEFAULT` 非空（`EXTRA` 含 `DEFAULT_GENERATED` / `on update CURRENT_TIMESTAMP`）。
3. **逐表数据断言**（建议语句模板，对已有行统计非空率与单调关系）：
   ```sql
   SELECT
     COUNT(*)                                                        AS total_rows,
     SUM(created_at  IS NULL)                                        AS null_created_at,
     SUM(updated_at  IS NULL)                                        AS null_updated_at,
     SUM(generated_at IS NULL)                                       AS null_generated_at,
     SUM(created_at > updated_at)                                    AS monotonic_violations
   FROM <table>;
   ```
   期望：`total_rows > 0` 时四个 null/violation 指标全为 0。业务时间字段确认后追加一列，如 `SUM(started_at IS NULL)` 与 `SUM(started_at < created_at)`。
4. **默认值生效断言**（仅测试库）：`INSERT INTO <table> (<最小列集>) VALUES (...);` 不提供三类时间戳列，随后 `SELECT created_at, updated_at, generated_at FROM <table> WHERE <探针条件>;` 验证三列由 DB 默认填充非空；执行后删除探针行（仅测试库允许）。
5. **超时与安全注意**：大表统计前加 `SET SESSION MAX_EXECUTION_TIME = <ms>` 或驱动层语句超时（建议 ≤ 30s），必要时先取 `MAX(id)`/时间界缩小扫描范围并分批 `LIMIT` 断言；只 SELECT 时间戳列与主键，不拉取敏感业务数据；结果落盘前脱敏；远程网络抖动时逐表重试并记录，不因单表超时跳过（跳过=红线违规）。
