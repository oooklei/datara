## 5. 工具链教训（沉淀至项目记忆）

- PowerShell 5.1 经 ssh 传参时**剥离全部内层双引号**（四层引号链）；远端复杂命令一律走脚本文件 scp 上传执行；Write 工具输出 LF，远端脚本**禁用 sed 行尾处理**（`s/\r$//` 经引号剥离变 `s/r$//` 灾难性损坏）
- gstack 无头浏览器（Windows）：浏览器与服务器**均不跨调用持久**；chain 模式冷启动经 PS 管道 stdin 会超时 → 用 `node execFileSync` 以 argv 传 chain JSON；复杂 UI 流程用**单条 mega-js**（IIFE）+ fetch 补丁自采 API 状态日志；SPA hash 往返等价刷新重挂载；Element Plus 消息盒关闭后 DOM 残留（隐藏），必须 `getBoundingClientRect().height>0` 过滤可见盒再操作
- 截图路径白名单校验对本机子目录中文路径拒绝 → 本轮以 JSON 断言 + network/console 日志为证据（shots 目录暂无截图，后续增量如需截图证据提前解决路径规则）
