## §3 跨切面差异（每条附 BE 证据位置）

### A. 宿主 project-scoped runtime factory/provider 缺口（Codex 18:11 心跳自述核对：**属实**）

心跳自述："R4-SYNC 仍缺宿主 project-scoped runtime factory/provider"。B 侧证据（18:45 实测）：

1. `rebuild\api\app.py:99`：`create_app(..., sync_runtime_factory=None, ...)` —— 默认 **None**；
2. `rebuild\api\app.py:637`（`create_sync_router`）与 `:646-651`（`create_sync_runtime_router(..., runtime_factory=sync_runtime_factory)`）—— 仅透传该参数，生产代码无装配；
3. `rebuild\sync\runtime_api.py:279-288`：`def _runtime(runtime_factory)` —— factory 为 None / 构造抛异常 / 返回 None 时统一 `return None, _error(503, 5031, "sync runtime adapters are not configured")`（即五条 runtime 端点对 FE 恒 503）；
4. `rebuild\sync\runtime_api.py` 模块 docstring 逐字：*"``runtime_factory`` must return a configured runtime sharing durable checkpoint state across requests. It is intentionally optional so hosts without approved source, target, and checkpoint adapters fail closed with HTTP 503."*；
5. `rebuild\sync\sql_runtime_factory.py:8-10` docstring 逐字：*"Concretely, the host must construct a project-scoped connection provider that resolves ``TableRef.datasource_id`` under ``context.project_id``, inject it into this factory, and pass the factory itself to ``create_app``."*；
6. `SQLSyncRuntimeFactory`（sql_runtime_factory.py:30 `class SQLSyncRuntimeFactory`）本体已就绪（要求注入 `connection_provider/schema_provider/checkpoints`，sql_runtime_factory.py:39-58），但 correction-plan 树内 grep `SQLSyncRuntimeFactory` 仅命中测试（`tests\rebuild\test_sync_sql_runtime_factory.py:101/144/157/166`）与 app.py 参数透传 —— **生产装配点不存在**。

结论：P1 收敛的前置条件是宿主注入 project-scoped factory（`SQLConnectionProvider`/`SchemaProvider` 协议见 sql_adapters.py:36-45）。

### B. mutable revision vs immutable plan version/digest（**本轮实测：BE 已实现不可变 pin，原差异消解**）

1. **不可变版本层已存在**：`SyncPlanVersionRecord { project_id, plan_id, version, digest, document }`（persistence.py:47-63，digest 为 64 位 sha256，persistence.py:211 `_digest`）；`SyncPlanRepository.get_version(..., digest=...)` 支持 digest 校验读（persistence.py:76-90）；`version = plan.revision + 1`（persistence.py:108）。
