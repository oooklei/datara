## ② 技术要点

**T1 三分类承载与类型推导（§5A.2，权威设计 L493-504）**：`DagProfileType` 收窄三类型（wf/sync/stream），`TYPE_LABEL` 去 etl 项，类型推导 `SYNC_TAG→sync、STREAM_TAG→stream、否则 wf`（L502）。流处理工作流**不设菜单**，统一 DAG 画布设计和试运行（L504）；客户自建分类参照旧前端目录树机制（L501）。旧前端实证：`TaskCenterView.vue` 401 行内含视角页签/画布多 Tab/`SYNC_TAG/ETL_TAG/STREAM_TAG → TYPE_LABEL` 推导（权威设计附录 A L1035），`STREAM_TAG` 为旧 services 具名导出（`StreamListView.vue` L16 import）。

**T2 类型专用组件过滤（§5A.3 L510）**：流类组件（C18~C20、page_board）= 流处理工作流专用；组件列表/表单 schema 一律由后端组件规格端点下发，新前端零私设（L508）。

**T3 观摩承载形态（§5A.9 L548-552）**：观摩 = 流处理工作流形态（画布工作流 tab）+ **运行监控视角观测**（L551）；观测面真源 = R8 已 GREEN 的 11 端点。

**T4 后端观测面现状（GREEN 实证）**：
- 挂载：`rebuild/api/app.py` L936-937 以 `prefix="/api/v1/rebuild/stream"` 挂载 `build_stream_router`（import 见 L43）。
- 11 端点（`rebuild/stream/api.py` L87-239）：`POST /jobs`（注册）、`GET /jobs`、`GET /jobs/{id}`、`GET /jobs/{id}/attempts|checkpoints|metrics|recovery-events|failure-alert`、`POST /jobs/{id}/transitions|observe|failures`；统一包络 `{code,msg,data}`，token/Bearer 双鉴权（L60-80）。
- 数据模型（`models.py` L181-188 `STREAM_TABLES`）：六表 = stream_job / stream_job_attempt / stream_checkpoint / stream_metric_snapshot / stream_failure_event / stream_recovery_event；八状态机 CREATED/STARTING/RUNNING/PAUSED/STOPPING/STOPPED/FAILED/RECOVERING，非法迁移 4002 由 repository 侧校验（L14-16）；DEP-05 裁定 attempt 独立建表（L9-13）。

## ④ 风险与开放问题

### 裁定项（单列，报监督线）

- **Z1 观摩推流通道缺口**：新后端 11 端点**全部为 REST 查询型，无 SSE/WS 推流端点**（T4 实证）；旧前端 SSE 大屏形态（C20 api 通道 hint、BoardPage/StreamDataPage 的 EventSource）依赖旧后端 `/api/v1/stream-jobs/{id}/data?mode=sse`（旧线契约，禁复制）。可选：a) 后端补 SSE 端点（立项报批）；b) 观摩面首版用 `observe`/`metrics` REST 定时轮询（EventSource 单持连方纪律可后补）；c) 混合。**影响 13.2 实现路径，须先裁定。**
- **Z2 契约层写方法扩展**：流工作流「运行」需要 job 生命周期驱动（register + transitions 端点已 GREEN 但契约层无方法，T5）。a) 扩展 streamApi.ts 增加 register/transition 写方法（GREEN 文件扩展 + 契约测试新增）；b) 生命周期由 workflow 试运行/运行链路内联驱动、前端维持只读。**须裁定后 D4 才能动。**
- **Z3 流类组件 spec 归属**：C18~C20/page_board 的 spec 是否已在新后端组件规格端点**未实证**；若缺，按 §6.2 五步规则列迁移候选报裁定（组件语义从旧 dag.ts 对标提炼，前端零私设）。
- **Z4 流表新域处置（13.3 本体）**：现状实证 = rebuild 全域 grep `stream_table|背压|backpressure|StreamTable` 零命中；stream 域仅观测面（生命周期+七模式生产器+指标快照+日志型告警），**无实时流处理引擎**（C19 融合算子执行语义在旧线 worker/stream，见大盘盘点 L39 行注记）。选项：a) 补建模立项报批（引擎/流表/背压拆解方向：流表 DDL 与物化建模 → C19 算子执行引擎 → 背压/反压观测指标扩充）；b) 登记阻塞，观摩面首版以 simulate 源 + 指标透传闭环。**报监督线裁定。**
