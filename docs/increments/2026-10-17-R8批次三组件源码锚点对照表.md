## 4. 复刻映射

### 4.1 → R8-A 八工具（契约冻结 v1，工具边界不缩水）

| R8-A 工具 | 三组件参照锚点 | Datara 落位 |
|---|---|---|
| search_schema | Vanna `get_related_ddl`/`get_similar_question_sql` 向量检索思想（base.py:L419-L486）+ OM `/v1/tables`、`/v1/databaseSchemas` 实体面（TableResource:L98）+ DH SchemaMetadata/Container aspect 面 | 数据源对象树 + 治理元数据检索；直查 Datara 元数据表，不引外部 ES/图存储 |
| validate_sql | Vanna `is_sql_valid` 自回环入口（base.py:L238-L260） | SQL 预检查 + 变量消解后校验（沿 R2 run-snapshot 语义） |
| run_sql | Vanna `generate_sql` 与 `run_sql` 分离思想（生成与执行解耦） | R5-A 执行 API，共享执行引擎，不另建引擎（设计 §11） |
| get_lineage | OM `/v1/lineage` REST（LineageResource:L92-L115）+ DH UpstreamLineage aspect 边结构 + `LineageService.validateDatasetUrns` 校验思想（非法 URN 拒边） | 血缘域设计态/运行态边查询，入参校验语义照搬 |
| get_workflow / validate_workflow / inspect_workflow_run / get_task_metrics | **原生域，三组件无对应能力**——无外部参照，按 Datara 工作流/运行/统计契约实现 | R8-A 冻结契约直连 Datara Backend 原生域 |

### 4.2 → R8-B 悬浮助手与通道语义

- Vanna Flask/FastAPI **SSE/WebSocket/poll 三通道**（routes.py:L17-L137 / L17-L183）= R5-A SSE 通道语义与 R8-B 助手交互通道的同构参照。
- OM **Python SDK 封装模式**（sdk/api/lineage.py:L31-L74）= AI 工具调用后端 SDK 化的参照（认证+端点+模型统一封装）。
- OM 血缘→ES 延迟批刷 + retry outbox（LineageUtil:L39-L67）= 高频写路径异步化的工程参照（Datara 治理域可借鉴的边界）。

### 4.3 OM vs DH 择一对照（建议，不裁定）

| 维度 | OpenMetadata | DataHub |
|---|---|---|
| 建模中心 | REST 实体中心（EntityResource 泛型资源 + JSON Schema 契约 openmetadata-spec） | aspect + 图关系中心（PDL 建模 + `@Relationship`） |
| 与 Datara 节奏同构性 | **高**——Backend 契约冻结 + REST 面即工具面，锚点可直接映射 | 中——接入需 aspect 体系转译 |
| 建模表达力 | 标准 CRUD + 扩展字段面 | **强**——fineGrainedLineages（列级）、IsPartOf/DownstreamOf 关系建模 |
| 血缘写入可靠性 | 延迟批刷 + retry outbox（工程化更细） | GMS 入口校验（简单直接） |

**建议：OM 为主参照**（契约形态同构、锚点直接可映射、双语言 SDK），**DH aspect 建模思想作血缘边结构设计参照**（列级细粒度边 + 关系声明式建模）。裁定按既定安排随 R8 批次或 A5 同批提请用户批准（心跳 #36 已声明）。
