## 三、缺陷清单

> 分级：P0＝阻断级；P1＝重要能力缺失/语义错误，影响设计主线收口；P2＝次要缺口或证据不足。
> 计数：**P0 0 项；P1 4 项；P2 7 项**。

### P0（阻断）

- 无。变量域主链路（global/project/env/tmp 解析、五诊断码、补全、预览、快照、权限 + project 隔离、env 泄名防护）可用且测试通过。

### P1（重要）

- **P1-1 run 作用域不可解析** —— `_owner_key_for`（`service.py` L221-230）无 run 分支，`${run.xxx}` 恒返回 `None` → `UNDEFINED`；最高优先级级失效。证据：`service.py` L221-230；`catalog` L189-205 owners 列表亦不含 run。
