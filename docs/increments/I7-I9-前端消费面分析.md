## 2. Legacy 前端消费面盘点（只读结论）

- **真实通道（可参考契约模式）**：`views/dag/InstanceRunsView.vue`（I3 实现）— 经 services 桶消费 `InstanceRow`/`DefinitionMeta`/`TaskStateEvent`/`InstanceFinishedEvent` 契约 + `datasourceApi.listTmpData`。事件驱动（TaskState/InstanceFinished）+ 列表刷新模式是 I7 验证页的直接参照。
- **纯 mock（demo 标记，I8/I9 从零建真实面）**：`stream/StreamDetailView.vue`、`ind/IndBoardView.vue`、`qc/QcReportHubView.vue` 全部依赖 `services/mock/dataStore` 或无 API — F56a 演示态不可作为契约依据，但其布局（速率卡、窗口表格、告警列表）可作 UI 蓝本。
- **血缘可视化**：`views/LineageView.vue` 基于 `graph/workbench/GraphWorkbench.vue` + `lineageProfile` 前端图计算 — I9 的"运行回写血缘"展示可复用 GraphWorkbench 做渲染层，数据源换 rebuild 血缘接口。

## 3. 契约期待草案（UI 侧）

- **I7 schedule**（前缀 `/api/v1/rebuild/schedule/*` 草案）：触发注册/列表（含 trigger 类型与 next-fire）、实例队列视图（并发/优先级/misfire 状态）、超时重试事件流、Alert 记录。
- **I8 stream**（`/api/v1/rebuild/stream/*` 草案）：job/attempt/checkpoint/metric 查询、观摩查询接口（对齐 A7 Step 5 返回结构：生产速率、消费速率、积压、偏移、窗口结果、成功失败跳过、错误样本）、故障恢复与漂移注入事件。
- **I9 metrics**（`/api/v1/rebuild/metrics/*` 草案）：4 表的查询端点（分页 + 时间窗）、质量规则结果→统计/告警链查询、血缘回写查询（SQL/同步/工作流运行维度）、`unknown`/`estimated` 标记透传（A7 Step 1 口径）。
