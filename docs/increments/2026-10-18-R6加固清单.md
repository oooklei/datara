## 3. 分批验收顺序与关门条件（沿 evidence §6 + 预研收敛）

1. **先 P0 retry + failover 语义裁定**（C1/C2/C3）——两者共用 attempt/run/幂等约束，不得分开设计后再拼接；
2. **再 P1 backfill**（C4/C5）——冻结 batch/date/timezone/order/parallelism 契约后实现逐日实例追踪与恢复；
3. **最后 P2 priority**（C6）——任务与队列语义稳定后裁定映射与公平性；不与补数或 R6 查询 API 混为一个需求；
