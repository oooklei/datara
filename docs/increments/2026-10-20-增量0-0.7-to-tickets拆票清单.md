### T0.7-3 代理与路由票

**工作面**：History 路由模式 + vite 单线代理 8001 + 端口建议 18092 + deploy 首版设计。

**交付物**：
1. 路由模式设计：
   - `createWebHistory()`（§2.4 决策落实），弃用 hash 模式；
   - nginx `try_files $uri $uri/ /index.html` History 回退；
   - 前端路由不占用 `/api` 前缀（§2.4 约束）；
   - 登录守卫设计（无 token → /login；已登录访问 /login → 回首页）。
2. vite 单线代理设计：
   - `/api/v1` → `http://localhost:8001`（新后端，唯一上游，§7.1）；
   - `changeOrigin: true`；
   - **无第二上游、无旧后端 8000 代理**（红线 1）。
3. 端口设计：dev server.port = 18092（§7.1 建议端口，待部署单定）；旧前端 18091 不冲突。
4. deploy 首版设计：
   - `deploy/nginx.conf`：`/api/v1/` → `datara-rebuild-api:8001` 单源反代（docker DNS resolver 动态解析，L1 借鉴旧 nginx.conf）+ History 回退 + SSE 推流 location（禁缓冲 + 长读超时）+ 静态资源长缓存；
   - `deploy/Dockerfile`：nginx:1.27-alpine + COPY dist + COPY nginx.conf（同旧前端模式，dist 本地/CI 构建）。

**验收锚**：
- §7.1 拓扑三行逐行对照：8000 不进新前端调用链路 / 8001 唯一事实源 / 18092 新端口；
- 代理配置与 §7.1 示意逐行对照（`/api/v1 → localhost:8001`）；
- History 模式决策（§2.4）落实，nginx try_files 回退显式固化；
- 路由不占 `/api` 前缀约束写入设计；
- nginx 单源：所有 `/api/v1/` 请求落 8001，无第二后端旁路（红线 1 / §7.3 判据）；
- SSE location 设计（禁缓冲 + 长读超时）继承旧前端实证。

**前置依赖**：T0.7-1（目录契约确定 router/deploy 文件位置）。
**边界**：不实现具体路由表（归增量 1.4 / 2.1）；不实现 http.ts 底座（归增量 1.2）；nginx/Dockerfile 仅设计不实跑（实跑归增量 1.5）。
