## 1. DBX 架构总览（亲核）

DBX 是 Tauri 应用（Rust 后端 + Vue 3 前端），核心分三层：

| 层 | 路径 | 职责 |
|---|---|---|
| Tauri 命令层 | `src-tauri/src/commands/`（77 文件） | 前端↔后端桥接，async 请求-响应 |
| Core 库层 | `crates/dbx-core/` | 连接池、查询执行、schema 元数据、持久化 |
| 前端应用层 | `apps/desktop/` | CodeMirror 6 编辑器 + Vue 3 组件 |

### 1.1 连接池分级（`crates/dbx-core/src/connection/mod.rs:106`）

`PoolKind` 枚举 28 变体，覆盖：
- **SQL 数据库**：Mysql(含 OceanBase Oracle mode)、Postgres、Sqlite、Rqlite、Turso、CloudflareD1、DuckDbWorker、ClickHouse、SqlServer
- **搜索/向量**：Elasticsearch、Easysearch、Solr、Meilisearch、VectorDb
- **时序/指标**：InfluxDb、InfluxDb3、VictoriaMetrics
- **NoSQL**：MongoDb、DynamoDb、Redis、HBase
- **特殊**：Salesforce、Agent（守护进程驱动）、ExternalDriver（JDBC/插件）、PluginConnection、MessageQueue、Nacos、Consul、Mqtt

### 1.2 查询执行模型（`crates/dbx-core/src/query/mod.rs`）

- **执行模式**（`QueryExecutionMode`）：`Standard`（默认）、`Simple`（SQL Server SHOWPLAN 绕过结果集探测）、`PostgresReadOnlyTransaction`（隔离只读事务）
- **执行选项**（`QueryExecutionOptions`）：max_rows/fetch_size/page_size/row_offset/max_result_bytes/result_key_columns/table_data_preview/catalog/result_session_id/client_session_id/timeout_secs(默认30s)/await_cancel_completion/execution_id/use_transaction/continue_on_error/execution_mode
- **错误模型**（`QueryExecutionError`）：Agent/DuckDb/Canceled/Timeout/Sql/SqlWithPosition/Legacy 七类类型化错误

### 1.3 对象模型（`crates/dbx-types/src/types.rs:209-233`）

- `ObjectSourceKind`：13 变体（View/MaterializedView/Procedure/Function/Trigger/Event/Sequence/Synonym/Job/Package/PackageBody/Type/TypeBody），**不含 Table/Index**
- `ObjectSource`：{name, object_type, schema, source, editable}，`editable` 为驱动侧声明位

### 1.4 Schema Provider 路由（`crates/dbx-core/src/schema/providers/native.rs:81-109`）

`list_objects` 按 PoolKind 分发：MySQL（OceanBase Oracle/Manticore/SHOW metadata/默认）、Postgres（QuestDB/Cloudberry/默认），未匹配返回 `None`。

### 1.5 前端编辑器（`apps/desktop/src/components/editor/QueryEditor.vue`）

CodeMirror 6 + 60+ composable 模块（`lib/editor/`），含：语句边界（`useQueryEditorStatementBoundaries`）、语义补全（`sqlCompletion.ts` 245KB）、SQL 格式化（`sqlFormatter.ts` 35KB）、语义分析（`sqlAnalysis.ts` 42KB）、Vim 键位、拖拽表名、hover 查询、诊断、 intention popup 等。

## 3. 冲突歧义清单（D9：冲突以 DBX 为准）

| # | 冲突点 | DBX 立场 | Datara 原版立场 | 判定 |
|---|---|---|---|---|
| C1 | 编辑器内核 | CodeMirror 6 + composable 体系 | Monaco + 自研 Monarch `datara-sql` | **DBX 为准**；原版 Monarch 语言资产作为语义参照移植 |
| C2 | 语句运行粒度 | 语句边界精确切分+缓存；执行单元以语句完整性为准 | 选中优先/全文兜底 | **DBX 语义为准**：选区仅作输入范围，不得产生半截执行单元 |
| C3 | 对象枚举粒度 | 13 变体 ObjectSourceKind + 只读门控 | INFORMATION_SCHEMA 库/表/字段三层 | **DBX 为准**；R5-A MetaTree 9 类为收敛子集 |
| C4 | 连接模型 | 池化分级+驱动进程化 | pymysql 短连接 | **DBX 为准**；短连接仅保留测连语义 |
| C5 | 凭证存储 | SecretCodec AES-256-GCM 信封 + SQLite 密文列 + 密钥三来源 + 迁移状态机 | 明文存储 | **DBX 为准**+Datara 安全基线加严 |
| C6 | 执行生命周期 | Tauri await 请求-响应阻塞式 | 异步 taskId+SSE | **DBX 语义为准**：单连接串行+一次性返回；SSE 为传输适配层 |
| C7 | 编辑器交互工程 | composable 巨阵（补全/悬停/拖拽/Vim/诊断） | Monaco 原生+轻封装 | **DBX 为准**；Monaco 特有能力逐项评估移植 |
