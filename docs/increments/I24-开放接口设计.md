## 1. 总体架构

```
对外请求 → X-API-Key 校验（sha256 查 key + enabled + bound_apis 含该 api + api enabled）
        → 执行（复用既有服务：streamdata / qc / catalog）
        → 写 t_open_log（状态码/耗时/错误）+ t_open_key.calls_count / last_called_at
失败语义：缺 Key 或无效 401；Key 停用 403；API 停用或未绑定 403；参数非法 400
```

## 2. 数据库表（3 张新表，含 create_time/update_time）

| 表 | 关键字段 |
|---|---|
| `t_open_api` | code(unique) / name / category(流数据、数据质量、元数据) / path / method(GET) / desc / params_json / resp_example_json / status(enabled、disabled) / calls_count；种子 6 个 |
| `t_open_key` | name / key_hash(sha256 unique) / key_prefix(String16 展示 sk-xxxx…) / bound_apis(JSON api code 数组，空=不可调用) / status(enabled、disabled) / calls_count / last_called_at / created_by / remark |
| `t_open_log` | ts / key_id / api_code / path / params_json / ip / status_code(200、401、403、400、500) / duration_ms / error_msg；Index(ts)、Index(key_id) |

## 3. 后端

**管理 API（api/open.py，require_perm "open:write"=admin）**：

```
GET/PATCH /open/apis[/{id}]      # 目录+启停+说明维护（API 定义=代码实现，不可新增）
POST /open/apis/{id}/test        # 测试调用：服务端内部执行（绕过 Key），写日志 ip=内部
CRUD /open/keys[/{id}]           # 创建（secrets.token_hex，sk- 前缀，一次性返回明文）/绑定 API 范围/启停/删除
GET  /open/keys/{id}/stats       # 统计卡（总次数/近 7 天/按 API 分布）
GET  /open/logs?status=&key_id=&api=&page=   # 调用日志（失败标红）
```

**开放端点（open_gateway 依赖，无 require_perm，统一响应 {code, message, data, took_ms}）**：

| 分类 | 端点 | 数据源 |
|---|---|---|
| 流数据 | GET /open/v1/stream/sources、GET /open/v1/stream/messages | streamdata 既有存储 |
| 数据质量 | GET /open/v1/quality/reports、GET /open/v1/quality/exceptions | I21 t_qc_report / t_qc_exception |
| 元数据 | GET /open/v1/meta/tables、GET /open/v1/meta/tables/{key} | I19 目录（内省∪模型） |

- 权限：管理操作=`open:write`（admin）；日志查看登录即可
- 审计：Key 增删改/启停、API 启停写 logger（audit.open）；调用本身即 t_open_log

## 5. 关键规则

- bound_apis 空=Key 存在但不可调用任何 API（403 NOT_BOUND）
- 一套 Key 可绑定三类 API（既定）
- Key 明文不落库不落日志；创建响应为唯一明文出口
- 测试调用不校验 Key 但记录日志（ip=内部）
- limit ≤ 500；全端点只读

## 6. 错误处理

| 场景 | 状态码 |
|---|---|
| 缺失/无效 Key | 401 INVALID_KEY |
| Key 停用 | 403 KEY_DISABLED |
| API 停用 | 403 API_DISABLED |
| 未绑定 | 403 NOT_BOUND |
| 参数非法 | 400 |
| 上游数据服务异常 | 500 附 error_msg（日志可见） |

全部落 t_open_log。
