- 审计对象：`datara-web/src`（App.vue / router / components / composables / styles / stores / graph/workbench 壳层）
- 审计方式：只读源码研究，未修改任何源代码
- 日期：2026-10-28 · 定位：新前端（datara-newweb）壳层方案对标收口的权威细节源

## 附C · 对新前端的最关键 8 条收口建议

1. **壳层铁律**：100vh 锁死 + `.page` 单滚动容器 + 全局细滚动条；body 永不滚。
2. **弹窗/抽屉零封装但有纪律**：宽度档位（表单 440-640 / 向导 780 禁遮罩 / 超宽 86%+5vh）、嵌套必 `append-to-body`、表单弹窗 `destroy-on-close`、确认框三板斧（中文按钮/prompt 命名/distinguishCancelAndClose）。
3. **页签=页内机制**：query.tab 单向 replace 深链 + 旧路径 redirect 透传保书签 + 画布 Tab 上限 5 + 关闭三选 + 快照清理时序（nextTick）。
4. **KeepAlive 只用在画布**，且必须配齐三护栏：onActivated 归位重载 + keydown 重挂、owner 过滤浮窗、防抖槽按 docId 隔离的 canvas-state。
5. **快捷键护栏三条**：isTypingTarget / 归属拦截 / 生命周期重挂；`?` 帮助浮窗内容与 handler 同源维护。
6. **会话语义待裁定**：旧版 token 仅内存（刷新即登出）+ account 却持久化——新前端必须明确 token 持久化策略，并保留"account 随 token 恢复防只读降级"的教训；1xxx 错误段踢登录、header `token`、15s 超时是硬契约。
7. **持久化键命名空间已成事实标准**：`datara.*`（全局）、`datara.wb.*`（工作台）、`canvas-state:{docId}`（画布会话态），新前端沿用命名空间便于灰度与迁移。
8. **AI 助手容器形态**：右下悬浮球（z 2000）+ 46% 右抽屉，全站唯一全局 AI 入口，壳层级挂载。
