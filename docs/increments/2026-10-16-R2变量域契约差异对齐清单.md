## §3 逐差异明细

### P1（阻塞契约冻结或接线）

**D1. checkReference：表达式级校验语义缺失（FE #4）**
- FE 入参是**表达式文本**（variableApi.ts:110），期望 5 种诊断码（:47）；BE `validate` 入参是**变量名列表**（variables/api.py:136-137），仅产出 UNDEFINED（service.py:145-148 `missing = sorted(set(references) - available)`）。
- 可拼合面：SYNTAX 已由 FE 本地 `parseVariableReferences` 覆盖（variableApi.ts:152-181，含未知作用域/缺点号/空名归类，测试 :70-73）；UNDEFINED 可映射 BE missing。
- 无对应面：TYPE_MISMATCH（BE `value_type` 无类型校验，repository.py:164-165 仅长度）、SCOPE_INVISIBLE（BE 端点无 context 维度）、CYCLE（BE 无引用图概念）。
- 需 Codex 裁定：BE 是否提供表达式级端点，或 FE/BE 分工表冻结。见 Q3。

**D2. previewResolution 无对应端点（FE #5）**
- 现值预览+来源展示为设计 §5 八项能力之二（design doc L216-217）。BE 侧七级链求值引擎已存在（service.py:99-143 `resolve`），但未以「单表达式 → 解析值+来源+诊断」形态暴露；validate 的 `values` 全量回传（api.py:147）可作数据源，但按名不按表达式。
- 注意红线：敏感变量现值不得回显——BE `public_value` 打码（service.py:56-57）是现成守卫。见 Q4/Q11。

**D3. getRunSnapshot：查询端点缺失 + 行模型三字段缺口（FE #6）**
- 数据已在 run 级落库（execution/models.py:21-24；写入 workflow_run.py:82-85；一致性校验 coordinator.py:351-357），但：无 HTTP 查询端点（variables/api.py 与 workflows/run_api.py 均无快照行查询）；行模型缺 `expression/resolvedAt/attemptNo`（storage_payload 行仅 name/type/source/sensitive/value|secret_ciphertext，service.py:77-89）。
- **B2 缺口 #6 编入**：`variable_snapshot_id/sha256` 在 BE 已有完整落点（列+run payload 透出 run_api.py:120-122），但 FE `VariableSnapshotEntry`（variableApi.ts:70-79）无对应字段——冻结时需定进入快照查询响应的哪一层（行级/包级）。见 Q5。

**D4. value_type 枚举三套口径（B2 缺口 #11 编入）**
- FE 草案 4 值 `'string'|'number'|'boolean'|'json'`（variableApi.ts:21-22，注释自述「以后端契约为权威」）；BE 为**自由字符串**（service.py:40 默认 "string"，repository.py:164-165 仅校验 1-32 字符，无枚举约束）；设计 §13.5 给 8 值 `STRING/INTEGER/DECIMAL/BOOLEAN/DATE/DATETIME/JSON/ARRAY`（design doc L686-694）并要求定义扩展 `default_value/nullable/format/timezone/business_calendar`（L698-706，BE 均无对应列）。
- 此差异同时阻塞 D1 的 TYPE_MISMATCH 诊断（无类型全集则无类型不匹配判定基线）。见 Q6。

**D5. saveVariable 的 scope 路由与权限模型（FE #2）**
- FE 单方法任意 scope（variableApi.ts:108、视图 :264-269 表单可选七级+tmp）；BE 拆双端点且 global 仅 ADMIN（api.py:93-99），project 需 `EDIT_DEFINITION`（api.py:49）；BE 无 description 入参；FE 期待返回 `{saved, scope, name}` vs BE `_definition_payload`（api.py:185-193）。
- 另：BE 有 DELETE（api.py:67-80）而 FE 契约无删除方法——冻结时确认 FE 是否补方法或确认删除暂不走 UI。见 Q2/Q12。

**D6. 快照 attempt 维度语义（FE #6 签名）**
- FE `getRunSnapshot(instanceId, attemptNo?)` 且行含 `attemptNo`（variableApi.ts:70-79）；BE 快照是 **run 级一次性不可变**（WorkflowRunService.start 生成，workflow_run.py:69-85；coordinator reconcile 校验 :351-357），`TaskAttemptRecord`（execution/models.py:54-72）无变量快照列，attempt 重试不产生新变量快照。
- 需裁定：attemptNo 参数为「校验性透传/忽略」还是 BE 规划 attempt 级快照。见 Q7。

## §4 跨切面证据（BE 实证位置）

### A. 七级作用域语义
1. **链序完全一致**：BE `VariableScope` StrEnum 七值（service.py:13-20）+ `_PRECEDENCE`（:23-31）与设计 L207-209、FE `VARIABLE_SCOPE_PRIORITY`（variableApi.ts:16）逐字对齐（run > task > workflow > project > global > env > builtin）。
2. **胜者算法**：`resolve` 按 `priority[scope]` 索引取链上位者，同名同作用域重复报错（service.py:99-114）；输入顺序无关（test_runtime_contracts.py 有逆序一致性断言 :46-47——本次仅 Grep 命中佐证，未逐行通读）。
3. **持久化收窄为 global/project**：models.py:16-17 CHECK 约束；repository.py docstring :34 逐字 *"Persist definitions while leaving task/workflow/run/env/builtin inputs transient"*。
4. **run 作用域运行时注入**：启动入参 variables 构造 RUN 作用域定义（workflow_run.py:69-72）。
5. **workflow/task/env/builtin 的定义装配点**：本次阅读范围（variables/、execution/workflow_run.py、coordinator.py 快照重构段）内未找到这四个作用域的定义输入来源。**待核**——不臆测 BE 是否已有规划。
6. tmp：BE 枚举无（见 D10）。

### B. 类型系统
- BE `value_type`：自由串（service.py:40 默认；repository.py:164-165 长度校验）；`VariableDefinition.value` 为 Any、JSON 编解码（repository.py:173/:223）。

- FE TYPE_MISMATCH 诊断在 BE 无实现基础（D1/D4）。

### C. 快照机制
1. **身份**：`snapshot_id = sha256 前 32 位 hex`（service.py:143 `digest[:32]`）、完整 64 位 `sha256`（:142）、`precedence_version = "datara-variable-precedence-v1"`（:97）。

3. **落库**：run 级四列（execution/models.py:21-24）；写入点 workflow_run.py:82-85。
4. **校验**：coordinator 重构快照后 sha256/snapshot_id/precedence_version 三重比对，不符即 `WorkflowCoordinationError`（coordinator.py:351-357）。
5. **透出**：run payload 三字段（run_api.py:120-122）。
6. **表名**：设计指定 `task_instance_variable_runtime`（design doc L225）全库 grep 无匹配；实际为 run 级 JSON 列。FE 不直接依赖表名，但行模型 expression/resolvedAt 缺失（D3）。

### D. 补全机制

### E. 敏感值红线（BE 已闭环，FE 可依赖）
