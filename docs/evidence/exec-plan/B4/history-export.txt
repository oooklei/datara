交付范围
--------
1. S8 历史抽屉升级（IdeView.vue，§6.7 核心子集）：
   - 过滤行：关键字输入回车应用（sqlText/db/status 包含匹配，前端内存过滤）+ 刷新按钮（重新 listHistory）
   - 分页 20 条/页（前端内存分页，上一页/下一页 + 页码指示；删除后末页单条自动回退）
   - 行内容升级：#全局序号 / 状态徽标（succeeded 绿 is-ok / canceled·timed_out 黄 is-warn / failed 红 is-fail，
     全 token 配色）/ 库（null 显示「默认库」）/ 语句数·耗时 / 格式化时间（ISO→YYYY-MM-DD HH:mm:ss）/ SQL 预览
   - 四操作（§6.7 拆分语义）：查看=行点击就地展开逐语句详情（toggle）；编辑=载入编辑器不执行；
     再执行=仅当前数据源可用（跨源按钮禁用），confirm「按当前模式再次执行该历史 SQL？」后重跑；
     删除=confirm「确认删除该条执行历史？」后软删 + 刷新
   - 逐语句详情双源：
     a) 本会话执行捕获——runSql 重置缓冲，SSE result/log（query/exec/error）按 stmtIndex upsert，
        done 落历史时以 historyId 固化（内存 Map，不受 normalizeResponse 键改写影响）
     b) 重载条目重放——内存无捕获时按语句序 sqlText.split(';') 逐条 fetchResultPage(historyId, null, 0, 1, stmtIndex)
        探测快照（查询有快照→「N 行」；非查询/快照过期→回退显示历史终态）
   - done 增量刷新：执行完成后 loadHistory + historyPage 重置第 1 页（§6.7 historyDirtyN 联动的 R5A 等价实现）
2. S7 快照回显（六点联动收尾）：runSql 时固化变量快照（编辑器 ${scope.name} 引用清单 + 现时解析值，
   previewResolution best-effort），随 historyId 存档，在历史详情中以「变量快照：${global.rate} = 42」回显。
   六点现状：补全/hover/分色（B4-b 已交付）、未定义警告（checkVariableReferences + lint provider）、
   全局参数抽屉（GlobalParamDrawer 挂载）、快照回显（本票）——六点齐。
3. 契约扩展（sqlIdeApi.ts，唯一改动点）：fetchResultPage 增加可选 stmtIndex 参数并放宽 resultSetId 为 string|null，
   resultSetId 未知时以 ?stmtIndex=&offset=&limit= 重放（后端 fetch_page 本就支持 stmt_index fallback，零后端改动）。
4. G11 补项（同批追加）：「示例查询」按钮（data-sample-query）落编辑器头，一键填充 `SELECT 1 AS ok;`
   仅填充不执行；票据文案核查——views 层无面向用户「R5-A/增量 16」文案（仅代码注释），去票据文案完成；
   空/错/加载三态既有（结果空态 ide-result-empty / 错误条 ide-err / 树空态 data-no-*）。
   快捷键三件套核查——Ctrl+Enter/Ctrl+S/Ctrl+Shift+F 已在位（IdeView L1769 起，ideShortcuts.contract.test.ts 7 用例）。
