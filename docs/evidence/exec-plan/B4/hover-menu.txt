二、依赖踩坑（5 条）
------------------------------------------------------------
1. normalizeResponse 键改写：HTTP 适配层全局 snake→camel。字符串数组不受影响，但对象键
   会改写——rows 必须用数组形态传输（已在后端固化并注释），列映射数据用 listColumns 的
   items.name（键不变、值不变）规避。
2. TableDataError 转译边界：参数校验（ValueError）必须在事务 try 块外完成，否则被
   except Exception 吞掉转成 STATEMENT_EXECUTION_FAILED，前端无法区分「请求错」与「执行失败」。
   apply/import 均改为「先编译计划（校验）→ 再事务执行」两阶段。
3. happy-dom 无原生 prompt/alert/confirm：vi.spyOn(window, 'prompt') 报 undefined；
   组件侧须用裸全局调用（prompt()/confirm()/alert()），测试侧 vi.stubGlobal 挂 globalThis，
   两者才解析到同一函数。
4. S9 树默认展开第一个根节点：测试里再点 source:7 会触发折叠（onNodeClick expanded→collapse），
   mountWithTree 必须直接从 db 节点开始。
5. r6 token 规则（ideView 契约用例）：IdeView.vue 源码禁 hex 色字面量。新样式
   #3a9d5d/#fff/#d9a400/#c0392b 全部改 var(--success)/var(--card)/var(--warn)/var(--danger)。
