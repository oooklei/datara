# 逐门验收矩阵模板

> 用途：G 组门禁验收（FE-13 ~ FE-19）逐门验收矩阵登记。
> 规则：每门一任务；FE 侧动作 = 验收执行 + 冻结令登记（提交号）；「前置依赖」列登记的后端/用户解阻事件不属 FE 实施范围，仅作派发门禁。
> 禁止在解阻前判定门通过。

---

## 一、验收矩阵格式

| 字段 | 说明 |
|---|---|
| 门号 | 门 1 ~ 门 7 |
| 门名称 | 设计 §10 原文 |
| 验收任务 | FE-13 ~ FE-19 |
| 前置解阻事件 | 后端/用户操作项（非 FE 职责） |
| FE 侧关键动作 | 验收执行 + 冻结令登记 |
| 验收标准 | 可核验的通过条件 |
| 状态 | PENDING / BLOCKED / PASS |
| 验收日期 | 实际验收日期 |
| 证据 | vitest / Playwright / 登记表 |
